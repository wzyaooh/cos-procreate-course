# 匿名使用统计（可选）

自建的轻量统计：记录每台设备打开了哪些页面、在前台看了多久、课程读到哪一节、用了哪些功能、搜了什么，并提供一个带密码的看板。数据只存在你自己的服务器上，不接入任何第三方。

**默认是关闭的。** fork 本项目的人不开启的话，页面里不会加载统计脚本，也不会启动统计服务。

## 记录什么

| 类别 | 内容 |
|---|---|
| 设备 | 随机生成的设备编号（存在浏览器 localStorage 里，32 位十六进制）；设备类型、系统、浏览器（从 User-Agent 判断，原始 UA 不保存）；屏幕尺寸；是否从主屏幕打开；语言和时区 |
| 访问 | 每次访问（隔 30 分钟以上算新的一次）、打开了哪些页面、从哪里来（站内页面或外部网站的域名） |
| 时长 | 每页在**前台**、并且 10 分钟内有过操作的时间。切到后台、锁屏、闲置都不计 |
| 阅读 | 课程和问题速查读到了哪一节（小节标题滚到屏幕上半部分时记一次） |
| 功能 | 标记课程完成、勾选作业和自检清单、打开目录和用目录跳转、回到顶部、拖动修图前后对比、资料库筛选、导出导入和清空进度、关闭备份提醒、打印 |
| 搜索 | 站内搜索的关键词和结果数（停止输入 1.5 秒后记最后一次） |
| 外部链接 | 点了哪些资料链接 |
| 进度 | 已完成的课和作业数量（读自本机的学习进度） |

**不记录**：IP 地址（统计服务不记访问日志）、姓名、账号、联系方式、照片和作业内容。不用 Cookie，不做浏览器指纹。所有打开网站的设备都会被统计，网站上不提供关闭开关。

## 数据保留

- 按设备的原始记录（设备、访问、每条事件）保留 `STATS_RETENTION_DAYS` 天，默认 2 天，之后自动删除。
- 每 5 分钟把原始记录汇总成「每日汇总」：每天的设备数、访问数、时长、每页时长、小节阅读、功能使用、搜索词、外部链接、设备类型分布。每日汇总**一直保留**，里面不含设备编号（去重设备数用 HyperLogLog 估算，误差约 3%）。
- 所以看板上：选的时间范围原始记录都还在（比如「今天」）时，所有设备数都是直接数出来的，是精确值；范围里有超过保留期的日子时，设备数用每日汇总估算，看板上会标「估算」。「设备」页和设备详情只显示保留期内的设备。

## 开启

在服务器项目目录的 `.env` 里：

```bash
# 1. 生成看板密码的哈希（会提示输入两次密码，输入时不显示）
python3 tools/stats_password.py
# 把输出的两行 STATS_PASSWORD_HASH=... 和 STATS_SECRET=... 贴进 .env
```

`.env` 里还要改这几行：

```
COMPOSE_PROFILES=stats
STATS_ENABLED=1
STATS_RETENTION_DAYS=2
```

然后：

```bash
docker compose up -d --build
```

打开 `https://你的域名/stats/`，输入密码就能看到看板。登录状态保存 30 天；连续输错 10 次会锁 15 分钟。

改密码：重新运行 `tools/stats_password.py`，替换 `.env` 里那两行，`docker compose up -d` 重启统计服务。换了 `STATS_SECRET` 以后所有已登录的设备都要重新登录。

## 看板

| 页面 | 内容 |
|---|---|
| 概览 | 设备数、新设备、访问次数、页面浏览、总时长和人均时长、主屏幕打开比例、现在在线；每天的设备数和时长趋势；设备类型和浏览器分布；看得最久的页面 |
| 课程 | 学到哪一模块；每天学完的课；每节课的设备数、浏览、总时长、人均时长、标记完成次数；点一节课看各小节的读到率 |
| 功能和搜索 | 各功能的使用次数和设备数；搜索词（可以只看没有结果的）；外部资料点击 |
| 设备 | 保留期内每台设备的类型、系统、浏览器、最近访问、时长、学完几课、最后看的页面；点一行看这台设备每次访问的时间线 |

右上角可以切换今天、7 天、30 天、90 天、全部。导出 CSV：`/stats/api/export.csv?t=daily`（还有 `pages`、`search`、`events`）。

## 实现

- 前端：`static/js/track.js`（约 3.5KB gzip），页面加载完成后才运行，事件攒起来每 20 秒或离开页面时用 `sendBeacon` 一次发送；发送失败不影响网站。
- 后端：`stats/app.py`，只用 Python 标准库和 SQLite，数据在 Docker 卷 `stats_data` 的 `/data/stats.db`。网站容器里的 Caddy 把 `/api/e` 和 `/stats*` 转给它。
- 自测：`python3 stats/selftest.py`。
- 备份数据：`docker compose cp stats:/data/stats.db ./stats-backup.db`
