## 先弄懂：约定是双方的保护 {#why}

### 大多数纠纷来自"以为说好了" {#why-agree}

接单出问题，很少是因为谁故意坑谁，多半是双方心里想的不一样：

- 你以为"自然一点"是只去痘，对方以为是皮肤修得像滤镜一样；
- 你以为"改几次"是两三次，对方以为是改到满意为止；
- 你以为"两周"是从收到原图算，对方以为是从聊天那天算。

这些事只要事先写成文字、双方都确认过，到时候翻出来看就行，不用吵。**约定越具体，双方越省心**。

### 报价卖的是时间和结果 {#why-price}

![报价的组成](diagrams/m8/p-quote.svg "单张价由基础工时、难度、沟通返修、附加项四块组成")

这节课不给具体价格。城市、水平、平台、客户不同，价格差别很大，给出的数字很快就不适用。下面讲**怎么算**，算出来的数你自己填。

一张图的报价可以拆成四块：

| 块 | 是什么 | 怎么估 |
|---|---|---|
| 基础 | 你修这一类图要几个小时 × 你的时薪 | 统计自己同类作业的用时（[第 1 步](#price)） |
| 难度 | 合成、手绘特效、大幅修比例这些额外的时间 | 也按用时算，或者按"基础的几成"加 |
| 沟通和返修 | 来回确认、按约定改的那几次 | 第一次接单时记下实际花了多少时间 |
| 附加 | 加急、商用、交分层文件 | 见下面 |

**附加项为什么要另算**：

- **加急**：要把别的安排往后挪，或者熬夜。
- **商用**（店家宣传、商品图、印刷售卖）：图被用来赚钱，用途和范围都更大，还牵涉出镜和摄影的授权（[案例三](#case-commercial)）。
- **交分层文件**：.procreate 或 PSD 里有你所有的做法，等于把手艺一起交出去，对方以后也能自己改。

**时薪怎么定**：可以参考你所在城市同类兼职的收入水平，再看和你水平差不多的后期公开的价目。新手可以比别人低一些练手，但要写清楚一张包含什么，不要因为便宜就什么都做。

### 尺度要用图来确认 {#why-scale}

"自然一点""精修一下"每个人理解都不一样。[0.3 课的沟通表](lesson:m0-03#brief)要问修图尺度，这一项最好**配图**问：同一张图修三档，让对方指着选。

![尺度样张](diagrams/m8/p-scale.svg "同一张图修轻、中、重三档，每档写清做了什么")

### 返修和新需求不一样 {#why-revise}

| | 返修 | 新需求 |
|---|---|---|
| 是什么 | 没达到约定的地方，或约定范围内的微调 | 约定里没有的东西 |
| 例子 | 脸再亮一点；手臂边上有残影；肤色再暖一点 | 换个背景；改成暖调；再加两张；脸型再瘦一圈（约定里写了不改脸型） |
| 怎么处理 | 算在约定的次数里 | 另外报价，或者换掉约定里的某一项 |

把这张表放进约定里，对方提意见时自己也能对照，不用你每次去解释。

## 第 1 步：算出你的报价思路 {#price}

:::step 统计作业的实际用时
1. 打开一张作业，打开 [[操作 > 画布 > 画布信息]]。
2. 左边点「统计」，看「跟踪时间」，这是这件作品在 Procreate 里打开着的总时长。
3. 记进下面的表。至少统计 3 张，同一类的取平均。

![画布信息的统计](diagrams/m8/u-stats.svg "画布信息 › 统计 › 跟踪时间")

看到：表里每类图至少有一个平均用时。
:::

:::warn 跟踪时间只能当参考
跟踪时间算的是作品**打开着**的时间，中途放着不动、去喝水也会算进去；在 Lightroom 里调色的时间则不算。所以它比你实际动手的时间多一些，又少算了 Lightroom 那部分。下一次修图时可以自己掐表对比一次，知道偏差有多大。
:::

**用时统计表**

| 例：5.4 比例修正 | 精修 + 比例 | | | |

:::step 定下"一张"包含什么
把基础价包含的内容写成清单，不在清单里的就是另算的。例如：

- **包含**：选片建议；曝光和白平衡；去痘、去杂毛、淡化黑眼圈；假发和服装校色；轻微的光影；按约定的风格统一调色。
- **另算**：换背景、合成；手绘光效、粒子特效；拉腿以外的形体修改；去掉大面积路人；加急；商用；分层文件。

清单写得越细，报价越不容易吵。

看到：一份分成"包含"和"另算"两栏的清单，每一项都是具体的修图内容，没有"等""之类"这种说不清的词。
:::

:::step 算出报价的公式
用文字写下来，不用急着填数字：

> 单张价 = 同类平均用时 × 时薪 + 难度另算的时间 × 时薪 + 返修预留时间 × 时薪
> 加急、商用、分层文件：在单张价基础上另加，比例自己定

一组照片可以按张报，也可以按组报（比如"9 张一组"），按组报时要写清楚每张包含的内容，以及超出 9 张怎么算。

看到：笔记里有一条写成文字的报价公式，公式里每一项都能在你的用时统计表里找到依据。
:::

## 第 2 步：确认修图尺度 {#scale}

沟通表本身用 [0.3 课](lesson:m0-03#brief)的那张。这里加一步：用你的作品做三档样张。

:::step 用模板的图层组做三档
如果你按 [8.2 课](lesson:m8-02#template)做了模板，三档样张几乎不用多花时间：

1. 找一张你修过的作品，复制一份。
2. **轻**：只打开「精修」组，其他组左边的勾都去掉，用 [[操作 > 分享 > JPEG]] 导出。
3. **中**：再打开「光影」「调色」组，导出。
4. **重**：全部打开，包括「特效」组和换背景的图层，导出。
5. 按 [8.3 课](lesson:m8-03#compare)的方法，把三张拼成一张图，每档下面写一句"做了什么"。

看到：一张图上并排三档，每档都写着做了哪些、没做哪些。
:::

:::step 让对方选，并写进约定
把样张和沟通表一起发给对方：

- 选哪一档；
- 这一档里有没有**不想要**的（比如选了"中"，但不要拉腿）；
- 沟通表里的"不能改的地方"。

把对方的选择原话抄进约定的"修图尺度"一栏。

看到：约定的"修图尺度"一栏里是对方的原话：选了哪一档、这一档里不要什么、哪里不能改。
:::

## 第 3 步：约定修改次数 {#revisions}

在约定里写清这四件事：

| 写什么 | 例子 |
|---|---|
| 包含几次 | 每张包含 2 次修改。常见做法是一到三次，你按自己的时间定 |
| 什么算一次 | 对方把这一轮的意见**一次性汇总**发过来，算一次。零散发来的，合并成一轮 |
| 超出怎么办 | 第 3 次起每次另算，或按单张价的几成算 |
| 什么不算返修 | 见[上面的表](#why-revise)，属于新需求的另报价 |

:::step 让意见标在图上
文字描述"左边那里亮一点"很容易误会。请对方在图上圈出来：对方会用 Procreate 的话，把 JPEG 发过去让他画；不会的话，让他在手机相册的标记功能里圈好截图发你。

你自己整理时，在 Procreate 里新建一层「返修标注」，用「技术笔」、红色，把每一处圈出来、写编号，再在聊天里按编号一条条确认。

![返修标注](diagrams/m8/u-review.svg "在单独的图层上圈出要改的地方，写编号")

看到：每处要改的地方都有一个编号，聊天记录里有和编号对应的说明。
:::

:::step 每轮一个版本号
改完把「返修标注」层关掉，导出时版本号加一（v1 → v2），按 [0.3 课的命名规范](lesson:m0-03#delivery)命名，并在聊天里写一句这一版改了什么："v2：1. 脸提亮；2. 手臂残影修掉。"

看到：对方手上每一版都有版本号，改了什么一看就知道。
:::

## 第 4 步：约定交付格式 {#format}

| 交付物 | 格式 | 写进约定的说明 |
|---|---|---|
| 高清成品 | JPEG，sRGB，原尺寸 | 导出方法见 [8.3 课](lesson:m8-03#export) |
| 发布用的版本 | JPEG，按平台测试后的尺寸 | 要不要给、给哪几个平台的 |
| 预览图 | JPEG，带水印，可以缩小 | 确认和返修时用，不能拿去发布 |
| 分层文件 | .procreate 或 PSD | 默认不给；要的话另算。PSD 能在 Photoshop 里打开，保留图层和混合模式 |
| 命名 | 角色_日期_序号_版本 | 见 [0.3 课](lesson:m0-03#delivery) |
| 交付方式 | 网盘链接 | 链接保留多久 |

:::step 给预览图加水印
1. 在成品的副本上打开 [[操作 > 添加 > 添加文本]]，输入"预览图 @你的名字 请勿转载"。
2. 用变换把文字放大、斜着放在画面中间，压过人物，但别完全挡住脸，对方还要看效果。
3. 点文本图层右边的「N」，把「不透明度」从 40% 左右开始调，字刚好看得清、又不挡住修图效果就停。
4. 导出 JPEG。可以先用 [8.3 课](lesson:m8-03#export)的方法把长边缩小一些。

![预览水印](diagrams/m8/u-watermark.svg "添加文本后，在图层的 N 里把不透明度调低")

看到：图上有一行半透明的字，能看清修图效果，但拿去发布会很明显。
:::

:::why 为什么要给预览图加水印
先付定金、确认样片、返修，这几步里图在对方手上。没有水印的高清图可能还没付尾款就被发出去了。加水印的预览图够对方看效果，终稿在约定的时间交。
:::

## 第 5 步：约定交付时间 {#time}

![交付节点](diagrams/m8/p-timeline.svg "确认约定、定金、样片、批量、返修、终稿，每个节点写日期")

:::step 估算要多少天
用文字算一遍，再加上余量：

> 需要的天数 ≈ 张数 × 单张平均用时 ÷ 每天能修图的小时数 + 返修的天数 + 余量

**余量**是给意外留的：生病、考试、对方晚回消息。新手留多一点。

算法举例（数字是假设的）：9 张 × 单张 2 小时 ÷ 每天 3 小时 = 6 天，加返修 3 天、余量 2 天，一共约 11 天。

看到：你算出了一个天数，并且写明了其中返修几天、余量几天。
:::

:::step 按节点写日期
不要只说"两周交"，要按节点写：

1. **确认约定**：哪天双方确认。
2. **收定金**：比例双方商量。
3. **样片**：先修 1 张，几天内交。**样片确认之前不开始批量修**，方向错了只返工一张。
4. **批量修**：样片确认后几天内交全部 v1。
5. **返修**：对方收到 v1 后几天内汇总意见，你收到意见后几天内交 v2。
6. **终稿**：收尾款后几天内交高清无水印版。

再写一条**顺延规则**："对方每晚确认一天，后面的节点一起往后顺延一天。"

看到：约定里六个节点都有具体日期，最后一行是顺延规则。
:::

## 第 6 步：写成接单说明和合作约定 {#contract}

**接单说明**是公开的，放在主页或作品集里（[8.3 课](lesson:m8-03#page)），让想约你的人先看。**合作约定**是每一单单独填的，双方在聊天里确认，截图留存。两份都可以用浏览器的打印功能打印这一页。

**接单说明（模板）**

| 项目 | 内容 |

## 三个完整案例 {#cases}

### 案例一：漫展返图 9 张，从询价到交付 {#case-full}

:::compare
before: diagrams/m8/case-revise-before.svg | v1：对方觉得脸太暗，手臂边上有残影
after: diagrams/m8/case-revise-after.svg | v2：按标注修改，脸提亮，残影修掉
:::

**情况**：一位 coser 发来漫展场照原图 40 张，想修 9 张，喜欢冷调，问多少钱、多久能好。

**诊断**：先问清楚再报价。按 0.3 课的沟通表问完，再看原图：大部分是俯拍，要拉腿；有 3 张背景里路人很多；她希望两周内拿到。

**做法**（次数、天数、预设数量都是这一单的示范，你的按自己的用时和对方的照片定）：

1. **报价**：查用时统计表，"精修 + 比例"这类平均用时最多。9 张按这一类算基础；3 张去路人按"难度另算"加时间；两周不算加急，不加。把"一张包含什么、另算什么"一起发给她。
2. **尺度**：发三档样张，她选"中"，但说"不要磨皮，痣保留"。原话抄进约定。
3. **约定**：修改每张 2 次；样片 3 天、全部 v1 再 7 天、返修 3 天；定金收到后开始。她在聊天里回复"确认"，截图。
4. **样片**：先修她最喜欢的那张，交带水印的预览图。她觉得冷得太过，把预设的「数量」从 100 降到 75，再交一次，确认方向。这一轮是在确认样片，不算修改次数。
5. **批量**：用 [8.2 课](lesson:m8-02#use)的模板和预设修完 9 张，交 v1 预览图。
6. **返修**：她一次性发来意见，其中一张："脸太暗，手臂边上有一圈白边"。你在「返修标注」层上圈出 1、2 两处，按编号确认后修改，交 v2。另一个意见是"能不能把第 7 张换成海边背景"，这属于新需求，按另算报价，她决定不加。
7. **终稿**：收尾款后，交高清无水印 JPEG（sRGB、原尺寸），按 `角色_日期_序号_v2` 命名，网盘链接保留 30 天。

**为什么是这个顺序**：先样片后批量。样片阶段调整方向只花一张图的时间；如果直接修完 9 张才发现她觉得太冷，就要改 9 张。

:::warn 这类订单容易翻车的地方
- 没有先交样片：9 张都按你理解的冷调修完，对方觉得太冷，全部返工。
- 零散的意见各算一次：对方今天说一条、明天说一条，次数很快就"用完"了，双方都不高兴。约定写清"一轮汇总算一次"，并在开始返修前提醒对方把意见汇总好。
- 换背景当返修做了：做完以后下一单对方也会这么要求。新需求按另算处理，态度客气、规则一致。
:::

### 案例二：对方一直说"再改改" {#case-endless}

**情况**：已经交了 v3，两次修改都用完了。对方说"还是差点感觉，再改改"，但说不出具体哪里。

**诊断**："差点感觉"不是一条能执行的意见。问题多半在一开始：尺度和风格没有用图确认，对方心里的样子和你修的不一样。

**做法**：

1. 不直接动手改，先问具体：请对方找 1～2 张"想要的感觉"的参考图，或者在 v3 上圈出最不满意的地方。
2. 对照参考图，用 [8.1 课](lesson:m8-01#step-color)的方法取色比较，找出差别，比如参考图暗部更青、亮部更暖。
3. 告诉对方：约定的 2 次已经用完，这次属于第 3 次，按约定另算；如果这次的方向是你最初就没理解对，可以主动说明这次不收费。
4. 下一单开始前，把"风格要配参考图"写进你的接单说明。

:::warn 这类情况容易翻车的地方
- 不问就改：没有方向地再修一版，大概率还是"差点感觉"，只会多费一轮。
- 一句"次数用完了"就拒绝：规则要守，但先帮对方把问题说具体，往往一轮就解决了。
:::

### 案例三：店家想用来做宣传 {#case-commercial}

**情况**：一家假发店看到你作品集里的一张图，想拿去做店铺首页的宣传图，还想再约几张。

**诊断**：这是商用。这张图里有出镜的肖像，有摄影师拍的照片，还有你的后期，三方的权利都牵涉进来（见 [0.3 课](lesson:m0-03#rights)）。

**做法**：

1. 先告诉店家：用这张图做宣传，需要出镜和摄影也同意，你不能一个人答应。
2. 分别问出镜和摄影：同不同意，有没有条件（比如署名、报酬）。
3. 约定里写清用途和范围：用在哪里（店铺首页、商品详情、印刷海报），用多久，要不要署名。
4. 价格按"商用"附加项另算；新约的几张照常走第 1～6 步。

:::warn 这类合作容易翻车的地方
- 只有你同意就给了图：出镜和摄影事后发现，你会同时得罪三个人。
- 用途没写清：说好放首页，后来印在了包装上。约定里要写清用在哪里、用多久。
:::
