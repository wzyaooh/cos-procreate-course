## 先弄懂 {#why}

### 手指管命令，笔管画 {#why-hands}

[0.1 课](lesson:m0-01#settings)让你打开了「禁用触摸操作」。打开以后，**手指不会在画布上画出东西，只用来做手势**；画、擦、涂抹只认 Apple Pencil。这样分工以后，左手负责缩放、撤销、取色，右手拿笔一直不离开画面，修图的节奏就快了。

### 撤销记录怎么存 {#why-undo}

![撤销记录](diagrams/m1/p-undo.svg "最多 250 步；回到图库或退出 App，记录整条清空")

- 每做一个操作，Procreate 记一步，**最多能撤销 250 步**（[手册「手势快捷」](https://help.procreate.com/cn/procreate/handbook/interface-gestures/gestures)写明的上限）。
- 在变换工具里拖了很多下，点变换图标确认退出后，这些拖动**合成一步**，撤销一次全部回去。
- **回到图库或者退出 Procreate，撤销记录整条清空**，作品按现在的样子保存。之前删掉的图层、擦掉的头发再也撤不回来。

由此得出两条习惯：**做擦除、合并、液化这类改动大的操作之前，先复制一份图层**；**修到一半要回图库，先确认现在的状态是你想要的**。

## 第 1 步：10 个常用手势 {#list}

![手势表](diagrams/m1/p-gestures.svg "修图最常用的 10 个手势，可以截图存着")

| 手势 | 作用 | 修图里什么时候用 |
|---|---|---|
| 两指轻点 | 撤销；两指按住不放，连续撤销 | 每天用几百次 |
| 三指轻点 | 重做 | 撤销多了 |
| 两指捏合 / 张开 | 缩小 / 放大画布 | 修睫毛、发丝时放大 |
| 两指捏住转动 | 旋转画布 | 顺着手腕的方向画弧线 |
| 两指快速捏合 | 画布适应屏幕 | 修完一处，马上看全图 |
| 三指往下滑 | 打开「拷贝并粘贴」菜单 | 复制选区到新图层 |
| 三指来回擦 | 清除当前图层的全部内容 | 一层画乱了，整层重来 |
| 四指轻点 | 全屏，隐藏界面 | 修完看整体效果 |
| 手指按住画布 | 吸管，取这里的颜色 | 补色前先取周围的颜色 |
| 画完笔尖停住 | 速创形状：线变直、圈变圆 | 画标尺、辅助线 |

下面挑几个容易做错的，分步练。

:::step 撤销和重做
1. 随便画几笔。
2. **两根手指同时**在画布上轻点一下，最后一笔消失。手指并拢或分开都行，关键是同时落、同时抬。
3. 两指按在画布上不抬起，停一会儿，会一步步连续往回撤，手指离开就停。停多久开始连续撤销，可以在 [[操作 > 偏好设置]] 的「快速撤销延迟」里调（手册：从无延迟到最长 1.5 秒）。
4. 三根手指同时轻点，重做一步。

![撤销](diagrams/m1/u-undo.svg "两指轻点撤销，上方会提示撤销了什么")

看到：每撤销一次，画布上方会弹出一条提示，说明撤销了什么操作。
:::

:::why 两指轻点没反应
- 点得太慢：两指在屏幕上停留久了，会被当成捏合缩放。要快点快抬。
- 一根手指先到：会被当成单指操作。
- 在 [[操作 > 偏好设置 > 手势控制]] 的「常规」里打开了「禁用撤销并重做」，关掉它。
:::

:::step 快速捏合：一下看全图
1. 两指张开，把画布放大到只看得见一只眼睛。
2. 两指放在屏幕上，**快速**往里一捏，马上松手。

![快速捏合](diagrams/m1/u-fit.svg "快速捏合后松手，画布刚好铺满屏幕")

看到：画布自动缩放到刚好整张显示在屏幕里，并且摆正。动作慢了只会普通缩小，要的就是"快"。
:::

:::step 三指下滑：拷贝并粘贴菜单
1. 三根手指放在画布上，一起往下滑一小段。
2. 屏幕上方弹出一排按钮：剪切、拷贝、全部拷贝、复制、剪切并粘贴、粘贴。
3. 点「复制」，当前图层的内容会复制成一个新图层。有选区的时候，只复制选区里的部分。

![拷贝并粘贴菜单](diagrams/m1/u-copypaste.svg "三指下滑打开拷贝并粘贴菜单")

看到：图层面板里多了一层。点画布空白处可以关掉菜单。
:::

**这几个按钮怎么选**：「复制」和「剪切并粘贴」直接生成新图层，修图最常用；「拷贝」「剪切」只是放进剪贴板，要再点「粘贴」才会出来；「全部拷贝」把所有看得见的图层合成一张拷贝下来，适合"把现在的效果复制一份当新起点"。

:::step 三指擦触：清除图层
1. 新建一个图层，随便画几笔。
2. 三根手指贴着画布，左右来回快速擦几下。

![三指擦触](diagrams/m1/u-scrub.svg "三指左右来回擦，当前图层被清空")

看到：**当前选中的图层**内容全部消失，其他图层不受影响，图层本身还在。
:::

:::danger 千万别
在原图层上三指擦。这个手势很容易误触，擦掉的是整层。修图前按 [5.4 课](lesson:m5-04#prepare)的方法把原图层复制一份并锁定；锁定的图层擦不掉。误擦了马上两指轻点撤销，别回图库。
:::

:::step 四指全屏
四根手指同时轻点画布，工具栏和侧栏全部滑走。再四指轻点一次，或点左上角出现的小图标，退出全屏。

![全屏](diagrams/m1/u-fullscreen.svg "四指轻点隐藏界面")

看到：画面上只剩作品本身，适合修完对着整张图检查。
:::

:::step 取色
1. 一根手指按住画布不动，约半秒后出现一个圆环吸管（等多久可以在 [[操作 > 偏好设置 > 手势控制]] 的「吸管」里调延迟，以实际界面为准）。
2. 圆环上半圈是正在取的颜色，下半圈是当前颜色。拖到要取色的位置，松手就选中。
3. 也可以点一下侧栏中间的小方块（修改钮），再点画布取色。

![吸管](diagrams/m1/u-eyedrop.svg "按住画布出现吸管；也可以用侧栏的修改钮")

看到：右上角的颜色圆点变成你刚取的颜色。
:::

:::why 补色为什么一定要先取色
皮肤、布料的颜色很难凭眼睛调准。从旁边干净的地方取色再补，颜色才接得上。取的位置要离补的地方近，因为光照不同，一件衣服左右两边的颜色都可能不一样。
:::

:::step 速创形状：画直线
画一条线，画到头**笔尖不要抬起**，停住约一秒，线会自动变直（等待时间可以在 [[操作 > 偏好设置 > 手势控制]] 的「速创形状」里调延迟，以实际界面为准）。画圈停住会变成椭圆，这时另一根手指按住屏幕，会变成正圆。

看到：画布上方出现「编辑形状」之类的提示（以实际界面为准），点它还能拖动线的端点。
:::

## 第 2 步：精细调滑块，存常用档位 {#sliders}

:::step 精细调和保存
1. 按住侧栏的尺寸滑块，**手指先往右边拖开**，再上下移动。手指离滑块越远，滑块动得越慢，能调得越细。
2. 按住滑块时会弹出一个预览窗，显示当前数值。点预览窗右上角的「+」，把这个数值存成一个档位，滑块上会出现一条细线。
3. 以后点那条细线，或者把滑块拖到细线附近，就回到这个数值。

![精细调滑块](diagrams/m1/u-slider-fine.svg "拖开再上下移；按住时点「+」存档位")

看到：滑块上多了一条细线。每支笔的尺寸和不透明度各能存 4 个档位，绘图、涂抹、擦除分开存（[手册「绘图、涂抹与擦除」](https://help.procreate.com/cn/procreate/handbook/brushes/paint-smudge-erase)写明）。想删掉一个档位，点那条细线，预览窗里的「+」会变成「−」，点它。
:::

**建议存的档位**（以软画笔为例，都是经验起点值，用几次觉得不顺手就改存别的数）：不透明度 10% 左右（加深减淡、补肤色）、30% 左右（腮红、阴影）、100%（涂蒙版，拉到上限）。存好以后不用每次瞄着百分比慢慢拖。尺寸档位和画布大小有关：同一个尺寸百分比，在大画布和小画布上画出来的粗细不一样，所以尺寸按你常修的照片尺寸去存。

## 第 3 步：改成自己顺手的手势 {#custom}

:::step 打开手势控制
1. 打开 [[操作 > 偏好设置 > 手势控制]]。
2. 左边是功能，比如「吸管」「清除图层」「拷贝并粘贴」；右边是能触发它的手势，打开开关就能用。「□」指侧栏的修改钮。
3. 改完点「完成」。

![手势控制](diagrams/m1/u-gesture-ctrl.svg "左边选功能，右边开关手势")

看到：同一个手势只能给一个功能用。两个功能抢同一个手势时，旁边会出现黄色警告图标，要关掉其中一个。
:::

**修图常见的两种改法**：

- **怕误清图层**：在「清除图层」里只留「擦触」，别再给它加其他手势。
- **常取色**：在「吸管」里同时打开「触摸并按住」和「轻点 □」，左手点修改钮、右手点画布，取色最快。

## 两个完整案例 {#cases}

### 案例一：修一缕飞出来的假发，手不离笔 {#case-flow}

**情况**：一张半身照，假发顶上有一缕杂毛翘出来，背景是渐变的灰墙。

**诊断**：要做的是放大、取色、盖掉杂毛、看全图，来回好几轮。如果每一步都去点按钮，一大半时间花在找按钮上。

**做法和手势**：

1. 两指张开，把杂毛放大到占屏幕三分之一左右。
2. 新建一个图层（[1.4 课](lesson:m1-04)），左手按住杂毛旁边的墙面，吸管取色。
3. 右手用软画笔（[1.3 课](lesson:m1-03)）盖掉杂毛。画歪了就左手两指轻点撤销，不用停笔。
4. 盖完左手两指**快速**捏合，看全图：墙面颜色有没有接上。
5. 不满意就两指张开回到原处，重复第 2～4 步。
6. 最后四指轻点进全屏，看最终效果。

**为什么是这个顺序**：放大修、缩小看，是修图最基本的循环。手势让这个循环每轮只要两三秒。

:::warn 这类操作容易翻车的地方
- 放大太多：盖的颜色在局部看着对，缩小一看是一块色斑。每盖几笔就快速捏合看一次。
- 取色取在杂毛上：取到的是头发的颜色，越盖越明显。取色点要在杂毛外面、紧挨着它的墙面上。
:::

### 案例二：三指误擦了一层 {#case-undo}

**情况**：花了二十分钟在「修补」图层上补背景，手掌一蹭，整层被三指擦触清空了。

**诊断**：这是「清除图层」，撤销记录里只算一步。关键是**还没离开这张作品**。

**做法**：

1. 不要点图库，不要切到别的 App。
2. 两指轻点一次画布，看顶上的提示是不是"撤销 清除……"，图层内容应该回来了。
3. 回来了以后，在这层上向左轻滑，点「复制」备一份；再按第 3 步去「手势控制」检查「清除图层」的手势设置。

**为什么不能先回图库**：回到图库，撤销记录清空，这一层就真的没了。

:::warn 这类情况容易翻车的地方
- 慌了连点好几下撤销：撤过头了就三指轻点重做回来。
- 以为 iPad 有"自动备份"：Procreate 自动保存的是**当前状态**，也就是已经被清空的那一层。
:::
