## 先弄懂：头发是怎么长的 {#why}

修假发最常见的失败，是补上去的头发"像贴纸"。原因几乎都是：没按头发本来的结构去画。所以先看结构。

### 方向：从发根往发梢，连续地变 {#why-flow}

![头发的生长方向和发束结构](diagrams/m5/p-hair-flow.svg "左：头发从发旋和发际线出发，方向是连续变化的。右：一组发束从发根到发梢的样子")

- 每一根头发都从**发根**（发旋、发际线，假发是发网上的缝线）出发，往**发梢**走。
- 相邻的头发方向几乎一样，只会**慢慢转向**。如果有一小撮和周围的方向差了很多，眼睛立刻会注意到它。
- 所以补发丝之前，先看要补的位置**左右两边的发丝往哪走**，新画的线要夹在两者的方向之间。

### 结构：一组一组的，不是一根一根平铺 {#why-clump}

头发会粘在一起，在照片里看到的是**一束一束**：

| 部位 | 明暗 | 为什么 |
|---|---|---|
| 发束之间的缝 | 最暗 | 被两边的发束挡住了光 |
| 发束本身 | 中间调 | 这是假发本来的颜色 |
| 发束中段的弧顶 | 最亮（高光带） | 头是圆的，弧顶正对着光 |
| 发根 | 偏暗 | 被上面一层头发挡光 |
| 发梢 | 变细、分成几根 | 发束到末端散开 |

还有一条很重要：**所有发束的高光，在同一个高度连成一条带子**（动漫里常画的"天使环"就是这个）。因为光从同一个方向来，头又是一个球，高光自然落在同一圈上。

由此得出补发丝的顺序：**先画暗缝，再画发束，最后在同一高度补高光**。这三层对上了，补的头发就会和原来的融在一起。

### 补的发丝为什么像贴纸 {#why-sticker}

![三种补发丝的画法](diagrams/m5/p-strand.svg "左：粗细一样、平行等距。中：方向和底下的发束不一致。右：起笔粗、收笔尖，三五根一组，长短不一")

对照这张图，补上去像贴纸，通常是下面一种或几种原因：

1. **粗细一样**。真头发从发根到发梢是渐渐变细的，用没有压感的笔、或者下笔力度不变，画出来就是一根根铁丝。
2. **方向不一致**。新画的发丝和底下的发束有夹角，像是另外贴上去的一层。
3. **太整齐**。间距一样、长度一样、全部平行。真头发是成组的，组和组之间有空隙，偶尔还有一两根交叉。
4. **颜色不对**。从别的地方吸的颜色，或者凭感觉调的颜色，和要补的位置光照不一样。
5. **比原图清晰**。照片里的头发多少有一点虚，新画的线边缘太硬，一放大就看得出来。

### 发际线为什么会穿帮 {#why-hairline}

![发际线的三种状态](diagrams/m5/p-hairline.svg "左：真发际线，越往外越稀、越短。中：贴片边是一条硬线，胶还会反光。右：盖住硬线、补上细碎的短发以后")

真人的发际线不是一条线，而是一段**过渡**：后面的头发密，越往前越稀，最前面是很细很短的小碎发。假发的问题在于：

- 发网或贴片（蕾丝）的边缘是**一条硬线**，颜色和皮肤也差一点；
- 粘贴片的胶会**反光**，在额头上留下几块亮斑；
- 假发本身的发际线太整齐，没有那段由密到稀的过渡。

所以修发际线要做两件事：**把硬线和反光去掉**，再**把过渡补出来**。只做第一件，发际线会变成一条很干净的线，看着还是假。

### 杂毛：哪些去，哪些留 {#why-fly}

| 情况 | 处理 | 理由 |
|---|---|---|
| 横穿脸、眼睛、嘴唇的头发 | 去掉 | 抢视线，像脏东西 |
| 飞出轮廓很远、在背景上很显眼的 | 去掉 | 让人一眼看到"毛躁" |
| 压在头发上、方向乱的几根 | 用涂抹梳顺 | 不用去掉，梳进旁边的发束里就行 |
| 紧贴轮廓的少量细发丝 | **留几根** | 全去光了，头发会变成一块硬边的头盔，像抠出来贴上的 |

## 动手前：图层怎么分 {#prepare}

:::step 复制原图并锁定，建好三层
1. 按 [5.4 课](lesson:m5-04#prepare)的方法复制原图层，把下面的原图锁定，上面那层改名叫「修补」。克隆、涂抹都在这一层上做。
2. 点图层面板右上角的「+」新建两层，从下往上依次改名为「补发丝」「发丝高光」。

看到：图层面板从下往上是：原图（带锁）、修补、补发丝、发丝高光。
:::

:::why 为什么克隆要在「修补」层上做，不能在空图层上
克隆是从**当前图层**上取样再涂到当前图层上的。空图层上没有像素，取不到东西。补画的发丝和高光放在单独的图层上，是为了画坏了可以单独擦、单独调透明度，不会碰到照片本身。
:::

## 第 1 步：去杂毛 {#flyaways}

:::step 背景上的杂毛：用克隆盖掉
1. 点「修补」层，打开 [[调整 > 克隆]]。
2. 把圆盘拖到杂毛**旁边**一块干净的背景上。圆盘离杂毛 1～2 个指节宽就够了，越近，亮度和颜色越接近。长按圆盘，等它放大一下，上方出现「克隆锁定状态」，取样点就锁住了。
3. 克隆用的是你当前选的画笔。点右上角的画笔图标，选「气笔修饰」里的「中等画笔」或「软画笔」。
4. 「画笔尺寸」调到比杂毛稍宽一点（一般 5%～15%），「强度」保持 100%。
5. 沿着头发外轮廓，一小段一小段地涂，只盖住杂毛。涂到离发束很近的地方就停，别把发束的边也盖掉。
6. 涂完一段，如果背景的明暗变了（比如从墙走到了门框），就重新拖动圆盘、重新锁定。

![克隆去杂毛](diagrams/m5/u-hair-clone.svg "圆盘放在杂毛旁边的背景上，锁定以后沿轮廓小段涂抹")

看到：轮廓外面的杂毛没有了，背景是连续的，看不到一块块颜色不同的补丁；头发外轮廓上还留着一些细发丝。
:::

:::step 横在脸上的头发：从同一侧的皮肤取样
方法和上一步一样，但取样点要放在**同一侧脸**、和那根头发**差不多高**的皮肤上。脸的两侧光照不同，从另一边取样，补出来会是一块明显更亮或更暗的皮肤。

看到：头发去掉的地方，皮肤的明暗和周围连起来了。
:::

:::step 压在头发上的乱毛：用涂抹梳进发束
1. 点右上角的手指图标（涂抹），在画笔库里选「气笔修饰」里的「软画笔」。
2. 左边侧栏下面那个滑块（不透明度）对涂抹来说就是强度，从 30% 左右开始：拖一下能把乱毛带走、发束纹理还在就合适，糊了就往下调。上面那个滑块是尺寸，调到比一组发束窄一点。
3. **顺着周围发束的方向**拖动，从发根往发梢。就像拿梳子把那几根乱毛梳进旁边的发束里。

看到：方向乱的那几根不见了，被"梳"进了旁边的发束，发束本身的纹理还在。
:::

:::warn 易错
- 涂抹的方向和发束不一致：会把头发抹成一团糊。只顺着方向拖。
- 强度太高：一笔下去整片糊掉。强度宁可低，多拖几次。
- 轮廓外面一根不留：头发会像剪纸。紧贴轮廓的细发丝留几根。
:::

## 第 2 步：补发丝 {#strands}

用在：杂毛去掉以后露出的空缺、发束之间太稀的地方、要遮住的真发、要加的美人尖和鬓角。

:::step 选一支有压感变化的细笔
1. 点「补发丝」层，再点右上角的画笔图标，打开画笔库。
2. 选「着墨」里的「工作室笔」。它的粗细跟着压力变：压重粗、压轻细，抬笔时会自然收尖，正好画头发。想要更细更尖，可以换同组的「细尖」。
3. 新版 Procreate 的画笔库分「Procreate 库」和「经典库」，「着墨」在「经典库」里。
4. 线条抖的话，在画笔上再点一次打开「画笔工作室」，在「稳定性」里把「流线」的数量调高一点（20%～40% 左右）。画笔工作室的用法见 [1.3 课](lesson:m1-03)。

![画笔库：着墨里的工作室笔](diagrams/m5/u-brush-lib.svg "画笔名称和排序以实际界面为准")

看到：用这支笔在空白处试画一笔，起笔粗、收笔细，末端是尖的。
:::

:::step 在要补的位置旁边取三个颜色
1. 手指长按画布，出现吸管，把它拖到要补的位置旁边，松手就选中了这个颜色。吸管上半圈是要取的新颜色，下半圈是当前颜色。
2. 分别取三个颜色：
    - **暗**：发束之间的缝；
    - **中**：发束本身；
    - **亮**：旁边发束的高光带。
3. 每取到一个，打开右上角的颜色面板，轻点底部调色板里的一个空格子，把它存成色卡。画的时候点色卡就能来回切换，不用每次重新吸。

![长按画布取色](diagrams/m5/u-hair-pick.svg "在补的位置旁边各取一次：暗、中、亮")

看到：调色板里多了三个色卡，从暗到亮，都是这顶假发的颜色。
:::

:::why 为什么一定要在旁边取色
同一顶假发，向光的一侧和背光的一侧差别很大。在头顶取的颜色拿去补后脑，明暗就对不上。
:::

:::step 先画暗缝，再画发束
1. 尺寸调到 1%～3%（以和旁边一根发丝一样粗为准），不透明度 80%～100%。
2. 先用**暗色**，在要补的区域里画几条发束之间的缝：顺着方向，稍微粗一点。
3. 换**中间色**，在缝和缝之间画发丝：
    - 每一笔都从**发根**起笔，往**发梢**画。起笔压重，越往后越轻，最后快速抬笔，线尾就是尖的。
    - **三五根一组**，组里的线挨得近、方向几乎一样；组和组之间留一点空。
    - 长短不一，偶尔让一根斜着跨过另一根。
4. 每画完一组，缩小画布看一眼方向对不对。

![沿发束方向画](diagrams/m5/u-hair-paint.svg "从发根起笔，往发梢画；三五根一组")

看到：补的区域里能看出一束一束的结构，暗缝、发束连在一起，方向和两边的头发连得上。
:::

:::step 补的线太清晰，就稍微虚一点
放大到和原图一样的比例看。补的线明显比旁边的头发锐利的话：

1. 在「补发丝」层上打开 [[调整 > 高斯模糊]]。
2. 一根手指在画布上**轻轻往右滑一点点**，上方的蓝条显示模糊程度，通常 1%～3% 就够了。和旁边的头发一样清晰就停。
3. 点一下调整图标（魔棒）确认。

看到：补的线边缘和原图一样柔和，放大也看不出是新画的。
:::

## 第 3 步：补高光（「添加」模式） {#highlight}

### 为什么用「添加」 {#why-add}

「添加」模式是**把这层的亮度加到下面的颜色上**：这层画得越亮，下面就被提得越亮；画的是暗色，几乎没有变化。效果和光照上去一样，而且提亮后的颜色**带着下面头发本来的色相**，不会发灰。

所以高光不用纯白画，用第 2 步取的**亮色**画。用纯白在「添加」层上画，很容易一下就亮到发白。

:::step 把「发丝高光」层设成「添加」
1. 点「发丝高光」层右边的字母（默认是 N），打开混合模式列表。
2. 往下找到「添加」，点一下。列表上面的「不透明度」从 40% 左右开始，画上高光以后再按亮度增减（下一步）。
3. 点列表外面任意处关掉。

![高光层设成添加](diagrams/m5/u-hair-layers.svg "图层从下往上：原图、修补、补发丝、发丝高光（添加）")

看到：「发丝高光」层右边的字母变了，不再是 N。
:::

:::step 在高光带的高度画短线
1. 换成调色板里的**亮色**，尺寸和补发丝时一样或稍粗。
2. 找到旁边原来的高光带，在**同一个高度**画短线：方向和发丝一致，中间粗、两头尖，一组发束上画两三笔就够。
3. 只画在发束的弧顶上，暗缝里不画。高光带在发束之间是断开的，不是一整条横线。
4. 太亮就降低这层的不透明度，不够亮就在同一处再叠一笔。

看到：补的发丝上有了一段高光，和左右原来的高光在一条带子上，没有比原来的更白。
:::

:::warn 易错
- 高光的高度和原来的不一样：整片头发上会出现两条光带，像花纹。
- 高光太亮太宽：头发看起来像塑料丝。降低不透明度，线画细。
- 用「滤色」代替「添加」也可以，效果更柔和、提得没那么亮。两种都试一下，选和原图更像的那种。
:::

## 第 4 步：补美人尖 {#peak}

美人尖是额头正中间发际线往下的那个尖角。很多角色设定里有，cos 照里却经常没有。

:::step 复制一块发际线附近的头发
1. 点「修补」层，点选取工具（S 形图标），底部选「手绘」。
2. 在额头正中间，圈一块发际线**上方**的头发，往下要包括一小段发际线的边缘。
3. 点底部的「拷贝并粘贴」，这块头发会复制到一个新图层上。

![手绘选取复制一块头发](diagrams/m5/u-peak-sel.svg "圈的范围要包括一段发际线边缘")

看到：图层面板里多了一层「从选区」，画面上暂时看不出变化。
:::

:::step 用「弯曲」拉出尖角
1. 点箭头图标（变换工具），底部选「弯曲」，复制出来的那块头发上会出现网格。
2. 拖网格**下边的中间**往下，拉出一个尖角。尖角往下的距离，大约是额头高度的 1/8～1/6；左右两端保持在原来的发际线上。
3. 尖角太宽，就把下边两侧的点往中间收一点。
4. 点一下变换图标确认。

![弯曲拉出美人尖](diagrams/m5/u-peak-warp.svg "只拖下边中间，左右两端不动")

看到：额头中间的发际线往下凸出一个尖角，上面接着原来的头发。
:::

:::step 用蒙版把上边缘融进去
1. 在这层上轻点两次，打开「图层选项」，点「蒙版」，上面会多一个蒙版层。
2. 选中蒙版层，用黑色的「软画笔」，不透明度从 30% 左右开始，在这块头发的**上边缘和两侧**轻轻涂，涂到看不出这块头发的边就停。蒙版的用法见 [1.5 课](lesson:m1-05)。

看到：看不出这块头发是贴上去的，只看到发际线中间多了一个尖。
:::

:::step 在尖端补细碎的短发
回到「补发丝」层，换细一点的尺寸（比补发丝时小一档），不透明度从 60% 左右开始，短发比后面的发丝淡、但还看得出就行：

- 在尖角最前端画几根**很短**的发丝，方向朝下、往尖端聚拢；
- 尖角两侧的发丝斜着往外；
- 越靠前越稀，最前面只有两三根。

最后打开 [[操作 > 画布 > 水平翻转画布]]，看尖角是不是歪了。稍微不对称没关系，真人本来也不对称；明显歪向一边就用变换挪一下。

看到：尖角的边缘不是一条硬线，而是由密到稀的一小片短发。
:::

## 第 5 步：遮住露出来的真发 {#real-hair}

先看真发和假发的**深浅**差多少，再决定用哪种方法。

| 情况 | 方法 | 为什么 |
|---|---|---|
| 真发比假发深很多（黑发戴银白、浅粉假发） | 克隆假发盖住，再补发丝 | 改颜色只能换色相，深的还是深的，变不成浅色 |
| 深浅差不多，只是颜色不同（黑发戴深棕、深蓝假发） | 剪辑图层 +「颜色」模式改色 | 明暗本来就对，只要换颜色 |
| 发网露出来 | 克隆 | 发网的网格纹理画不出来，只能盖 |

:::step 深浅差很多：克隆盖住
1. 在「修补」层打开 [[调整 > 克隆]]。
2. 圆盘放在旁边**方向一样**的假发发束上，锁定。
3. 顺着发丝方向，把露出的真发盖住。涂一段就换一次取样点，免得同一束头发重复出现。
4. 盖完回到「补发丝」层，按第 2 步在接缝上补几组发丝，让它们跨过接缝。

看到：鬓角处是假发的颜色，发丝的方向和上面的连起来了。
:::

:::step 深浅差不多：只换颜色
1. 在「修补」层上点选取工具，底部选「自动」，轻点露出来的真发。
2. 手指按住不放，左右拖动调整「选区阈值」：选区会用反差色显示，刚好盖满真发、不漏到皮肤就松手。
3. 点「拷贝并粘贴」，真发复制到单独一层。
4. 在它上面新建一层，轻点两次打开「图层选项」，点「剪辑蒙版」；再把这层的混合模式改成「颜色」。
5. 当前颜色选第 2 步存的**中间色**，在这层的「图层选项」里点「填充图层」。

![自动选取露出的真发](diagrams/m5/u-real-hair-sel.svg "轻点以后按住拖动，调整选区阈值")

看到：露出的那一块变成了假发的颜色，但明暗和纹理还是原来的。还有色差的话，见 [5.6 课](lesson:m5-06)的校色方法。
:::

**鬓角太短、角色设定里鬓角更长**：在「补发丝」层上从鬓角的发根往下画，方向朝下、稍微往脸的方向弯，越往下越细、越稀。

## 第 6 步：发际线贴片的边 {#lace}

:::step 先去胶的反光
在「修补」层用克隆，取样点放在反光旁边**同样亮**的额头皮肤上，画笔尺寸比反光稍大，一下一下点涂盖掉。

看到：额头上没有亮斑了，皮肤的明暗是连续的。
:::

:::step 再盖住贴片的硬线
1. 继续用克隆，取样点放在硬线**下方**一点点的皮肤上。
2. **沿着硬线的走向**涂，不要来回横扫。
3. 贴片那一圈的颜色和皮肤不一样（偏白、偏粉）的话：在「修补」上面新建一层，模式改成「颜色」，吸额头的肤色，用「软画笔」、不透明度从 20% 左右开始，在贴片区域涂几遍，贴片和旁边额头颜色一样就停。

看到：看不到那条线了，额头从下到上是同一种肤色。
:::

:::step 最后补发际线的过渡
在「补发丝」层，用第 4 步最后那种细、淡的短发，沿着整条发际线补一排：

- 靠头发的那边画得**密一些、长一些**，往额头方向越来越**稀、短**；
- 方向和后面的发丝一致；
- 有几根稍微跑出来，落在额头上，比一条整齐的边自然。

看到：发际线由密到稀，没有一条硬边。
:::

## 第 7 步：改发型轮廓 {#shape}

假发戴出来和设定不一样（太蓬、少一撮、多翘起一撮），按大小选方法：

- **太蓬，要往里收**：用 [[调整 > 液化]] 的「推」模式，从外往里推轮廓，参数和注意事项照 [5.4 课第 6 步](lesson:m5-04#liquify)。背景有直线的话，先把人物和背景分层，不然背景会跟着弯。
- **少一撮、缺一块**：用手绘选取复制一组形状接近的发束，「拷贝并粘贴」，用变换的「弯曲」把它弯成需要的形状，放到位置上，再加蒙版把发根融进去，最后在接缝上补几组发丝。
- **多翘起一撮**：在「修补」层用克隆把它盖掉（背景上用背景取样，头发上用头发取样），再在原来的位置补几根细发丝，免得剩下一个整齐的缺口。

## 修完检查 {#check}

:::check 怎么判断做对了
- **缩小看**：把画布捏到手机屏幕那么大，看第一眼有没有哪一块头发颜色、方向不对。
- **翻转看**：[[操作 > 画布 > 水平翻转画布]]，看久了会习惯的问题，一翻就能看出来。
- **开关图层**：反复点「补发丝」「发丝高光」右边的勾选框，对比补之前和补之后。
- **放大看**：补的发丝起笔粗、收笔尖；高光在同一高度；发际线由密到稀。
:::

## 三个完整案例 {#cases}

### 案例一：银白长直假发，头顶杂毛、鬓角露黑发 {#case-fly}

:::compare
before: diagrams/m5/case-fly-before.svg | 修之前：头顶飞出十几根杂毛，两侧鬓角露黑发
after: diagrams/m5/case-fly-after.svg | 修之后：杂毛去掉，鬓角用补画的发丝盖住
:::

**照片情况**：室外逆光拍的半身照。逆光把轮廓外的杂毛照得发亮，头顶一圈都是；本人是黑色短发，鬓角收得不干净，两侧各露出一小块。

**诊断**：杂毛分两种，一种飞在背景上，一种压在刘海上横着走。鬓角是"真发比假发深很多"的情况，不能用改颜色的办法。

**修法和数值**（这张示范照片的数值，你的照片会不同，按画面判断）：

1. 复制原图并锁定，建「修补」「补发丝」「发丝高光」三层。
2. 背景上的杂毛：克隆，「中等画笔」，画笔尺寸 8%，圆盘离杂毛约一个指节，每涂 3～4 厘米换一次取样点。紧贴轮廓的细发丝留下 5～6 根。
3. 刘海上横着的杂毛：涂抹，「软画笔」，强度 40%，顺着刘海往下梳，横毛顺进刘海就停。
4. 鬓角：克隆，取样点放在上方同方向的发束上，把黑发盖住；然后在「补发丝」层用「工作室笔」尺寸 2%（以和旁边发丝一样粗为准）补了三组发丝，每组 4～5 根，跨过克隆的接缝。
5. 「发丝高光」层「添加」、不透明度 45%，在刘海原来的高光带高度给补的发丝加了几笔亮色，亮到和原来的高光一样就停。
6. 「补发丝」层高斯模糊 2%，糊到和原图一样虚就停。

**为什么是这个顺序**：先去杂毛，再补发丝。反过来的话，去杂毛时克隆会把新画的发丝也盖掉。

:::warn 这类照片容易翻车的地方
- 逆光下杂毛很亮，克隆取样点离得远，补出来的背景会比周围暗一块：取样点尽量近。
- 银白假发的高光本来就接近白色，高光层不透明度一高就过曝：从 30% 左右开始，不够再加。
- 鬓角只盖不补，会剩一块很平的银色：一定要在接缝上补几组发丝。
:::

### 案例二：背头角色，补美人尖 {#case-peak}

:::compare
before: diagrams/m5/case-peak-before.svg | 修之前：发际线平直，没有美人尖
after: diagrams/m5/case-peak-after.svg | 修之后：补出美人尖，边缘有细碎短发
:::

**照片情况**：正脸近景，粉色背头假发，额头整个露出来。角色设定里有明显的美人尖，但假发的发际线是平的。

**诊断**：发际线本身没有穿帮，只是形状和设定不一样。需要"加"，不需要"盖"。

**修法和数值**（这张示范照片的数值，你的照片会不同，按画面判断）：

1. 在额头中间用「手绘」圈了一块约两指宽的头发，包括下面一小段发际线，「拷贝并粘贴」。
2. 变换选「弯曲」，把网格下边中间往下拖，尖角往下约额头高度的 1/7。两侧的点往里收了一点，让尖角窄一些。
3. 加蒙版，黑色「软画笔」不透明度 40%，涂复制块的上边缘和两侧，直到看不出边。
4. 「补发丝」层，「细尖」尺寸 1%（以和旁边短发一样细为准）、不透明度 60%，在尖角两侧和最前端画了二十多根短发，越往前越稀。
5. 水平翻转画布检查，尖角稍微偏左，用变换往右挪了一点。

**为什么是这个顺序**：先用复制的真实头发搭出形状，再用手画的短发做边缘。整块都用手画，发丝的纹理和原图对不上；只复制不画边缘，尖角是一条硬线。

:::warn 这类照片容易翻车的地方
- 尖角拉得太长，像额头上插了一根箭头：设定图里再夸张，往下也不要超过额头高度的 1/5。
- 尖角边缘没有补短发，是一个硬的 V 字：一定要做第 4 步。
- 复制的那块头发里带着高光，弯曲以后高光也跟着变形：选一块没有高光的区域来复制。
:::

### 案例三：发际线贴片翘边、胶反光 {#case-lace}

:::compare
before: diagrams/m5/case-lace-before.svg | 修之前：贴片边一条硬线，胶有反光
after: diagrams/m5/case-lace-after.svg | 修之后：硬线和反光去掉，发际线有过渡
:::

**照片情况**：用闪光灯拍的近景。紫色背头假发，前额用了贴片，贴片的边在额头上看得出一条线，颜色比皮肤白一点；胶在闪光灯下反出两块亮斑。

**诊断**：三个问题：硬线、色差、反光。先去反光，因为反光会干扰判断皮肤本来的颜色。

**修法和数值**（这张示范照片的数值，你的照片会不同，按画面判断）：

1. 克隆去反光：取样点放在反光正下方的额头，画笔尺寸比亮斑大一圈，「强度」拉到上限 100%，点涂到亮斑完全盖住。
2. 克隆盖硬线：取样点在硬线下方约 2 毫米，沿着线走，一共换了 4 次取样点。
3. 新建「肤色统一」层，「颜色」模式，吸额头中间的肤色，「软画笔」不透明度 25%，在贴片那一条上涂了三遍，直到和额头中间颜色一样。
4. 「补发丝」层沿整条发际线补短发，靠头发那边密、往前稀。

**为什么是这个顺序**：先盖硬线和统一颜色，最后补短发。短发要画在已经修好的皮肤上，先画的话，克隆时会把它们盖掉。

:::warn 这类照片容易翻车的地方
- 克隆时把发际线的头发也盖掉了一截，发际线整体往后退：圆盘始终放在线的下方，只往上涂到硬线为止。
- 颜色统一层涂出了发际线，把头发也染成了肤色：涂之前先用选取工具的「手绘」圈出额头，有选区的时候，笔刷只能画在选区里面。
- 闪光灯照片的额头本来就亮，修完要和脸颊比一下，别把额头修得比脸颊还亮。
:::

## 下次拍的时候 {#prevent}

| 做法 | 解决什么 |
|---|---|
| 出门前用定型喷雾把假发表面压一遍，随身带小梳子 | 杂毛 |
| 真发全部收进发网，发网选和假发接近的颜色 | 鬓角、后颈露真发 |
| 贴片的边剪成不规则的细锯齿，贴好以后用粉底或遮瑕盖一下边 | 贴片硬线 |
| 少用正面直闪，或者在额头上补一点定妆粉 | 胶的反光 |
| 逆光拍之前先检查一遍轮廓外的杂毛 | 逆光把杂毛照得特别明显 |
