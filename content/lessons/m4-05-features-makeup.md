## 先弄懂 {#why}

### 三庭五眼：用来找偏差，不是用来套模板 {#why-ratio}

![三庭五眼](diagrams/m4/p-face-ratio.svg "三庭：发际线到眉毛、眉毛到鼻底、鼻底到下巴三段差不多长；五眼：脸宽约等于五个眼睛宽")

三庭五眼是画人像常用的比例参照：

- **三庭**（竖向）：发际线到眉毛、眉毛到鼻底、鼻底到下巴，三段差不多长。下庭稍长一点（大约 1 : 1 : 1.1）通常更上镜。
- **五眼**（横向）：从左脸边到右脸边，大约是五个眼睛的宽度：两眼之间正好放下一只眼，眼尾到脸边各一只眼。

真人的脸不会完全标准，标准反而没有特点。修图里用它只做一件事：**找出"明显偏了"的地方**。比如：一只眼睛比另一只低、小一圈；一边嘴角比另一边低；一边下颌比另一边宽。这些多半是拍摄角度、表情或镜头畸变造成的，不是本人的样子，轻轻修回来，人会显得端正。

### 为什么要改得很轻 {#why-light}

人认脸，靠的就是五官之间的距离和比例。改动超过一定程度，熟人一眼就会觉得"不像了"。经验上：

- 每一处改动**不超过一个眼睛宽的 1/10**（移动、放大都算）。
- 改完和原图来回开关对比，还认得出是本人。
- 脸型、五官大小这种改动，修之前一定先问 coser（[0.3 课](lesson:m0-03#brief)的修图尺度）。

:::warn 实际修图时的顺序
这节课放在 4.3、4.4 之后，是为了先学会皮肤和光影。但实际修一张图时，**五官校正属于"形"**，应该和 [5.4 课](lesson:m5-04)的比例修正一起，在皮肤之前做（[4.1 课](lesson:m4-01#list)的清单顺序）：液化和变换会移动像素，先修皮肤再液化，修过的地方会被拉变形。妆面才放在光影之后。
:::

### 妆面为什么要用不同的混合模式 {#why-modes}

补妆最怕的是"画上去的颜色把下面的纹理盖死"：唇纹没了、睫毛根没了、皮肤变成一块平涂。两种混合模式能避免这个问题（[1.4 课](lesson:m1-04)讲混合模式）：

- **正片叠底**：只会让下面变暗，不会变亮。白色在正片叠底下完全看不出来，越深的颜色压得越暗。它像在照片上叠一层透明的有色玻璃纸，下面的纹理、明暗都透得出来。适合**眼线、修容、腮红**这种"往皮肤上加一层颜色"的妆。
- **颜色**：保留下面的明度（亮暗），只换上这一层的色相和饱和度（[4.1 课](lesson:m4-01#why-gray)的灰度观察层用的也是它）。唇纹、唇部的高光和暗部都由下面决定，只是颜色换了。适合**改唇色、给眉毛换色**。
- **正常**：直接盖住下面。只用在必须"画出新东西"的地方，比如补画缺掉的眉毛，而且要降低不透明度、最后再模糊一点，让它和照片融在一起。

| 项目 | 图层模式 | 不透明度 | 画笔 | 为什么 |
|---|---|---|---|---|
| 眼线 | 正片叠底 | 70%～90% | 软画笔，尺寸 1%～3% | 深色叠在睫毛根上，睫毛和皮肤纹理还透得出来 |
| 唇色 | 颜色 | 40%～60% | 软画笔，配合选区 | 只换颜色，唇纹和唇部高光保留 |
| 唇色加深（需要时） | 正片叠底 | 10%～20% | 同上 | 颜色模式不会让唇变深，要深一点再叠这层 |
| 修容 | 正片叠底 | 10%～20% | 软画笔，大尺寸 | 低饱和的灰棕色往下压，像真实的修容粉 |
| 腮红 | 正片叠底（要明显）或颜色（只要色调） | 15%～30% / 20%～40% | 软画笔，大尺寸 | 正片叠底会带一点暗，更像粉；颜色模式只加粉调，不压暗 |
| 眉毛 | 正常 | 60%～80% | 细的笔刷，尺寸 0.5%～1% | 要画出新的眉毛，盖住下面；最后整层轻微模糊 |
| 眉毛改色（cos 常用） | 颜色 | 50%～80% | 软画笔 | 把黑眉毛改成和假发同色，保留眉毛的毛流 |

表里的不透明度和尺寸都是经验起点范围：从小的那一头开始，看起来像妆、又看不出边缘就停，后面每一步都写了具体看什么。笔刷尺寸的百分比和画布大小有关，同一个百分比在不同尺寸的画布上效果不一样，以看到的效果为准。

## 动手前：准备「五官」层和妆面图层 {#prepare}

:::step 合并出一张「五官」层
液化和变换只作用在当前一层上。如果你已经有去瑕疵、补色、光影好几层，直接在其中一层上液化，各层就对不上了。先合并出一张：

1. 关掉灰度观察层（不然会把黑白的效果也合进去）。
2. 三指在画布上往下滑，弹出拷贝并粘贴菜单，点「全部拷贝」（拷贝整个画面合在一起的样子）。
3. 再三指往下滑，点「粘贴」。得到一个新图层，改名「五官」，放在光影层上面。
4. 下面那几层先关掉可见性，留着备用。

看到：画面看起来没变，图层面板里多了一层「五官」，它就是当前画面的合并版。
:::

:::tip 更好的做法
按 [4.1 课](lesson:m4-01#list)的顺序，在修皮肤之前就做完五官校正，就不需要这一步合并了。
:::

## 五官校正 {#face}

:::step 第 1 步：画辅助线，找偏差
1. 新建一层，改名「辅助线」，选一个亮色（比如亮绿色）和细的笔刷。
2. 画一条**竖线**：从两眉中间经过鼻梁、人中，到下巴中间。画到底停住约一秒，线会自动变直（速创形状）。
3. 画一条**横线**贴着一只眼睛的内、外眼角；再画一条贴着两边嘴角。
4. 看：另一只眼睛的眼角在不在这条线上？两只眼睛离中线的距离一样吗？嘴角两边一样高吗？

![画辅助线](diagrams/m4/u-guides.svg "辅助线层：一条竖的中线，一条贴眼角的横线")

看到：偏差一眼就看出来，比如"左眼比右眼低一点、小一圈"。把它记下来。
:::

:::tip 用三庭五眼量一下
想检查三庭，可以在辅助线层上从发际线、眉毛、鼻底、下巴各画一条横线，看三段长度差多少。假发刘海挡住发际线时，只比中庭和下庭。量的目的是找偏差，量出来"下庭稍长"是正常的，不需要改。
:::

:::step 第 2 步：用选区移动或放大一只眼睛
1. 点「五官」层。点左上角的 S 形图标（选取），底部选「手绘」。
2. 沿着眉毛下方、眼尾外侧、眼袋下方、鼻梁侧面圈一圈，把眼睛连同周围一圈皮肤圈进来。圈大一点，接缝才落在没有细节的皮肤上。
3. 点底部的「羽化」，把滑块往右拉一点，让选区边缘变软。
4. 点「拷贝并粘贴」，眼睛被复制到一个新图层上。
5. 点箭头图标（变换），选「等比」：用一根手指往上挪一点点；拖角上的点放大一点点（不超过 105%）。插值用「双立体」（[5.4 课](lesson:m5-04#legs)讲过）。点一下箭头图标确认。
6. 用软橡皮（低不透明度）把新图层边缘擦柔一点，再两指捏合两个图层，合并回「五官」层。

![选取一只眼睛](diagrams/m4/u-eye-sel.svg "手绘选取 → 羽化 → 拷贝并粘贴 → 变换微调")

看到：两只眼睛一样高、大小接近，眼睛周围看不出接缝。
:::

:::why 为什么移动五官用选区，不用液化
液化推眼睛时，会把虹膜、眼白、睫毛一起推变形，眼睛容易变歪、变椭圆。选区加变换是把整只眼睛"原样搬动"，形状不变。液化只用来修轮廓。
:::

:::step 第 3 步：液化收轮廓
1. 在「五官」层上打开 [[调整 > 液化]]，模式选「推」。
2. 尺寸比要推的地方稍大；**压力从 10% 左右开始**，比推身体（[5.4 课](lesson:m5-04#liquify)）还要轻，推一下轮廓刚好动一点就对了，一般不超过 15%；失真、动力都是 0。
3. 从外往里，一次只推一点：一边下颌比另一边宽，就推宽的那边；脸颊一边鼓出来，就推鼓的那边。
4. 推过头，在退出液化之前换成「重建」刷回来，或者点「调整」降低强度。

![液化收轮廓](diagrams/m4/u-liquify-face.svg "推模式，小压力，从外往里一点一点推")

看到：脸的左右轮廓接近对称，下颌线是顺的，没有凹坑。背景如果被带弯了，按 [5.4 课](lesson:m5-04#why-bend)的办法处理。
:::

:::danger 千万别
用液化「展开」把眼睛放大、用「捏合」把鼻子缩小到明显变形。大眼小鼻的效果在照片里很容易显假，而且五官一变，人就不像了。
:::

## 妆面 {#makeup}

按这个顺序补：**眼线 → 唇色 → 修容 → 腮红 → 眉毛**。先补"线"（眼线），再补"面"（唇、修容、腮红），最后补眉毛，因为眉毛的颜色和粗细要和整张脸的妆一起看。每一项都在「五官」层上面新建一层。

开着参考窗口（[4.1 课](lesson:m4-01#ref)）的「图像」模式放设定图：在参考图像窗口里长按，可以直接吸设定图上的颜色。

### 眼线 {#liner}

:::step 补眼线
1. 先处理晕开的旧眼线：在「五官」层上用 [[调整 > 克隆]]，从旁边干净的皮肤取样，把晕到下眼睑的黑色盖掉（方法同 [4.3 课](lesson:m4-03#clone)）。
2. 新建一层，改名「眼线」，模式改成「正片叠底」。
3. 长按睫毛根部最深的地方吸色。吸到的通常是深棕或深灰，比纯黑自然。
4. 画笔用「软画笔」，尺寸从 1% 左右开始，画出来比睫毛根略粗就行（笔刷尺寸的百分比和画布大小有关，同一个百分比在不同尺寸的画布上效果不一样，以看到的效果为准。）；左侧栏不透明度从 70% 左右开始，颜色和原来的眼线一样深就停，一般不超过 90%。
5. 从内眼角开始，**贴着睫毛根**画到眼尾。眼尾顺着下眼睑的延长线往上挑一点，越往外越细：快画完时手上慢慢减轻力度。
6. 另一只眼睛照着画。画完两只眼睛对比：眼尾挑起的角度、长度要一样。

![补眼线](diagrams/m4/u-liner.svg "正片叠底图层，吸睫毛根部的深色，贴着睫毛根画到眼尾")

看到：眼线是一条贴着睫毛根的深色线，放大能看到睫毛还在下面。
:::

:::tip 眼尾不够细
用软橡皮、不透明度 30% 左右，在「眼线」层的眼尾末端轻轻擦，让它变尖、变淡。整体太浓就降低图层不透明度。
:::

### 唇色 {#lip}

:::step 换唇色
1. 在「五官」层上用「手绘」选取沿唇线圈住嘴唇。羽化一点点，边缘不要太硬。
2. 新建一层，改名「唇色」，模式改成「颜色」。
3. 颜色从设定图上吸（参考窗口里长按）；没有设定图，就选你想要的唇色。
4. 软画笔，不透明度拉满，在选区里涂满嘴唇。选区外面涂不上，所以可以放心涂到边。
5. 点一下选取图标取消选区。把「唇色」层的不透明度从 40% 左右开始往上调，看起来自然为止，一般不超过 60%。
6. 唇色看起来不够深：再新建一层「唇色加深」，模式「正片叠底」，同样的选区和颜色，不透明度从 10% 左右开始，够深就停，一般不超过 20%。

![换唇色](diagrams/m4/u-lip.svg "选区圈住嘴唇，在颜色模式图层上涂设定图的唇色")

看到：嘴唇换了颜色，唇纹和唇上的高光还在，唇线清楚，颜色没有溢到皮肤上。
:::

:::warn 易错：唇色像贴了一块纸
- 选区没有羽化，或者羽化太少，唇线一圈硬边。重新选区时羽化多一点，或者在「唇色」层边缘用软橡皮擦一下。
- 用「正常」模式涂唇色，唇纹和高光全被盖住。换成「颜色」模式。
- 嘴角是唇色最淡的地方，涂得和唇中间一样浓会显得假。嘴角用软橡皮擦淡一点。
:::

### 修容和腮红 {#blush}

:::step 修容
1. 新建一层「修容」，模式「正片叠底」，不透明度从 10% 左右开始，关掉这层对比能看出轮廓收了一点就停，一般不超过 20%。
2. 颜色选一个低饱和的灰棕色（比皮肤深、偏灰）。
3. 软画笔调到很大，在**颧骨下方**斜着扫一笔，方向和 [4.4 课](lesson:m4-04#map)光影地图的暗区一样；下颌两侧、发际线边缘各轻扫一笔。

看到：颧骨下方多了一层很淡的阴影，看不出边缘；关掉这层对比，脸的轮廓稍微收了一点。
:::

:::step 腮红
1. 新建一层「腮红」，模式「正片叠底」，不透明度从 15% 左右开始，一般不超过 30%。只想加粉调、不想变暗，就用「颜色」模式，从 20% 左右开始，一般不超过 40%。都是看到脸有气色、又看不出边缘就停。
2. 颜色对照设定图选；没有设定，选偏粉或偏桃色、饱和度不高的颜色。
3. 软画笔，尺寸要大到一笔就能盖住整个腮红区域。
4. 位置：微笑时脸颊最鼓的地方（笑肌），往太阳穴方向斜着扫开。很多二次元角色的腮红画在眼睛正下方、横着一片，按设定图来。
5. 两边各扫 1～3 笔，扫完翻转画布看两边是不是一样大、一样高。

![修容和腮红](diagrams/m4/u-blush.svg "腮红、修容各一层，正片叠底，大号软画笔")

看到：腮红和修容是一片柔和的颜色，看不出边缘。缩小看，脸更有气色，轮廓也更清楚。
:::

:::why 修容和 4.4 课的加深有什么不同
4.4 课的加深只管明暗，是在补"光"；修容是在补"妆"，带颜色（灰棕）。如果 4.4 课已经把颧骨下方压暗了，修容可以很淡甚至不加，不然会压两次，脸颊发脏。
:::

### 眉毛 {#brow}

:::step 补画眉毛
1. 新建一层「眉毛」，模式「正常」，不透明度从 60% 左右开始，补的毛和原来的眉毛一样深就停，一般不超过 80%。
2. 长按吸原来眉毛最深处的颜色，再在颜色面板里稍微调亮一点点。
3. 画笔用细的硬边笔刷（比如「着墨」里的「技术笔」），尺寸从 0.5% 左右开始，画出来和一根真眉毛差不多粗就行（笔刷尺寸的百分比和画布大小有关，同一个百分比在不同尺寸的画布上效果不一样，以看到的效果为准。）。
4. **一根一根画**，顺着眉毛的生长方向：眉头的毛往上竖，眉身往外斜着倒，眉尾往外往下。每根都是很短的一笔，起笔重、收笔轻。不要画成一整条色块。
5. 画完打开 [[调整 > 高斯模糊]]，手指从 1% 左右开始往右滑，补画的毛和照片的清晰度一致就停。模糊的百分比也和画布大小有关，同一个百分比在不同尺寸的画布上效果不一样，以看到的效果为准。
6. 对比两边眉毛的高度、粗细、眉峰位置。

![补画眉毛](diagrams/m4/u-brow.svg "细画笔，顺着毛流一根根画；最后整层轻微模糊")

看到：缺的地方补上了，近看是一根根的毛，不是一块色。
:::

:::tip cos 常见：眉毛改成假发色
角色是粉发、银发时，黑眉毛会很突兀。新建一层，模式「颜色」，吸假发的颜色，在眉毛上涂，不透明度从 50% 左右开始，眉毛颜色接近假发就停，一般不超过 80%。眉毛的毛流和明暗都还在，只是颜色变了。银发、白发这种很浅的颜色，「颜色」模式提不亮黑眉毛，要先在下面加一层正常模式的浅色，再叠颜色层。
:::

## 检查 {#check}

:::check 四个检查
- **开关对比**：把所有妆面图层一起关掉、打开，来回看。妆是"补回来"了，还是"换了一个人"？
- **对称**：打开辅助线层，看两边眼线、腮红、眉毛的位置；再水平翻转画布看一次。
- **放大**：眼线下的睫毛、唇纹、腮红区域的毛孔都还在。
- **灰度**：打开灰度观察层，妆面没有把 4.4 课的光影打乱，比如腮红没有在颧骨高光上压出一块暗斑。
:::

## 三个完整案例 {#cases}

### 案例一：漫展后半场，妆花了 {#case-makeup}

（对比图见本课开头。）

**照片情况**：下午拍的场照，左眼眼线晕到下眼睑，唇色被暖灯冲淡，左边眉尾掉了一截，脸颊没有气色。设定图是红唇、粉色腮红。

**诊断**：五官本身没问题，不需要校正；要补的是眼线、唇色、眉毛和腮红。

**修法和数值**（这张示范照片的数值，你的照片数值会不同，按画面判断）：

1. 眼线：克隆盖掉左眼下晕开的黑色；「眼线」层正片叠底 80%，吸睫毛根的深棕，软画笔 2%，两只眼睛都补，眼尾上挑约 15°。
2. 唇色：手绘选区圈嘴唇，羽化一点；「唇色」层颜色模式，图层不透明度约 55%，颜色从设定图吸；再加「唇色加深」正片叠底约 15%。
3. 腮红：「腮红」层正片叠底约 25%，粉色，笑肌位置斜着各扫两笔。
4. 眉毛：「眉毛」层正常 70%，技术笔 0.8%，补左边眉尾约 15 根；高斯模糊 1.5%。
5. 修容：4.4 课已经压过颧骨下方，这张不加。

**为什么这个顺序**：眼线先补，因为它决定眼睛的形状，后面的腮红位置要跟着眼睛走；唇色和腮红要一起看颜色是否协调；眉毛最后，粗细和浓淡要配合整个妆的浓度。

:::warn 这类照片容易翻车的地方
- 只补了晕开的那只眼睛，两边眼线一粗一细。补一边就要对照另一边，通常两边都要描一遍。
- 唇色直接用设定图的颜色、不透明度拉满，像画上去的。设定图的颜色是插画色，照片里要降低不透明度才自然。
:::

### 案例二：一只眼睛小一圈，头微歪 {#case-asym}

:::compare
before: diagrams/m4/case-asym-before.svg | 修之前：左眼低、小一圈，头微歪
after: diagrams/m4/case-asym-after.svg | 修之后：眼睛对齐，头回正
:::

**照片情况**：外景，coser 头往一边微微偏，左眼看起来比右眼低、小一点。翻转画布后更明显（[4.1 课](lesson:m4-01#flip)）。

**诊断**：辅助线一画：右眼眼角连线延长过去，左眼的眼角低了大约半个瞳孔的高度，左眼宽度小了大约 8%。头歪了约 3°。

**修法和数值**（示范照片的数值，你的照片按辅助线量出来的差距定）：

1. 头先回正：手绘选区圈住头和脖子上半段，羽化，拷贝并粘贴，变换旋转约 3°，克隆补背景（[5.4 课](lesson:m5-04#head)的思路）。
2. 再画辅助线，重新量一次：头转正后，左眼只低了大约 1/4 个瞳孔。
3. 左眼：手绘选区圈眼睛和周围皮肤，羽化；拷贝并粘贴；等比放大约 104%，往上挪到眼角对齐辅助线；边缘擦柔后合并。
4. 液化：头转正后右边下颌显得宽一点，推模式压力约 12% 往里收一点点。

**为什么这个顺序**：先处理大的（整个头的角度），再处理小的（一只眼睛）。头歪本身就会让两只眼睛看起来一高一低，先转正，剩下的偏差才是真正要修的，改动也更小。

:::warn 这类照片容易翻车的地方
- 为了"对称"把眼睛放大到和另一只完全一样。真人两只眼睛本来就有一点差别，修到差别不明显就停。
- 选区圈得太贴着眼睛，挪完以后眼皮上的褶皱对不上，出现断层。选区要圈大一点，接缝落在平的皮肤上。
:::

### 案例三：按角色设定补眼下腮红和眼影 {#case-character}

**照片情况**：角色设定是眼睛下方横着一片粉红腮红、眼尾一抹红色眼影。coser 的妆在照片里只剩一点点。

**诊断**：这是角色妆，位置和颜色都以设定图为准，不按真人化妆的习惯来。

**修法和数值**（示范照片的数值，你的照片会不同）：

1. 腮红：「腮红」层颜色模式，图层不透明度约 35%，颜色从设定图吸；软画笔调大，在两只眼睛正下方横着扫，范围从眼睛中间到眼尾下方。再叠一层正片叠底约 10%，让颜色有一点厚度。
2. 眼影：新建「眼影」层，正片叠底约 40%，红色；软画笔尺寸约 3%～5%，从眼尾往外、往上晕开一小片，比眼线范围大。
3. 对照设定图看颜色和位置，再翻转画布确认两边对称。

**为什么这个顺序**：腮红范围大，先定下来；眼影在眼尾，要和腮红的颜色衔接，后补更好调。

:::warn 这类照片容易翻车的地方
- 腮红的正片叠底开得太浓：这类角色妆把上限放在 40% 以下，开到 40% 以上（上面眼影的浓度），眼睛下方就变成一片暗红，像没睡好。角色妆要的是"颜色"，先用颜色模式，正片叠底只加一点点。
- 眼影晕得太大，盖过了眼线，眼睛的形状糊了。眼影在眼线外面，不要压住眼线。
:::
