## 先弄懂：补出来的背景为什么会穿帮 {#why}

### 五种穿帮 {#why-fail}

| 穿帮 | 是怎么回事 | 怎么避免 |
|---|---|---|
| 印章感 | 克隆一直用同一个取样点，同一块污渍、同一个花纹出现好几次 | 经常换取样点；复制的补丁翻转一下 |
| 线条断了 | 墙脚线、地砖缝、栏杆在补过的地方断开或错位 | **先补线，再补面** |
| 透视不对 | 补出来的地砖缝方向和旁边的不一样，或者地砖大小不对 | 打开透视指引，补丁用「扭曲」对齐 |
| 明暗、颗粒不一致 | 从亮处取的样补到暗处；从清楚的近处取样补到虚化的远处 | 取样点和要补的地方在同一高度、同一深度 |
| 影子没去 | 路人去掉了，地上还留着他的影子或脚印 | 去干扰物时连影子一起去 |

![克隆的印章感](diagrams/m5/p-clone-repeat.svg "左：同一个取样点一直用，同样的污渍排成一排。右：经常换取样点，看不出规律")

### 先补线，再补面 {#why-lines}

人眼看一张图，最先注意到的是**线**：墙和地面的交界、地砖缝、门框、栏杆。一条线在某处突然断掉或者错开一点，马上就会被发现；一块墙面颜色稍微不均，反而不容易看出来。

所以补一块区域时，**先把穿过它的线接上**，再补线和线之间的平面。

### 按大小和背景选方法 {#why-choose}

| 干扰物 | 背后是什么 | 方法 |
|---|---|---|
| 小（远处的路人、地上的小东西） | 简单的墙、天空、虚化的背景 | [第 1 步](#clone)：克隆 |
| 大（近处的路人、展板、灯架） | 有重复结构的墙面、地砖、栏杆 | [第 2 步](#patch)：复制相似区域，用蒙版拼 |
| 压在地面上的 | 有透视的地砖、台阶 | [第 3 步](#perspective)：按透视补 |
| 贴着画面边缘 | 什么都有 | 直接裁掉，见 [3.7 课](lesson:m3-07) |
| 和人物重叠 | 人的身后 | 先把人抠到单独一层（[2.5 课](lesson:m2-05)），补完背景再放回 |
| 构图太挤，要留白 | — | [第 4 步](#extend)：扩展画布再补 |

### 透视：补出来的地面要顺着线走 {#why-persp}

![补丁和透视](diagrams/m5/p-persp-patch.svg "左：补丁直接贴上，里面的地砖线方向不对，断了。右：补丁按透视线扭曲过，线接上了")

照片里的地砖缝是平行的直线，但因为透视，它们在画面上会**往一个点汇聚**，这个点叫消失点；离镜头越远，地砖越小。原理见 [3.6 课](lesson:m3-06)。

由此得出两条规矩：

1. **补丁从同一深度取**。从画面上同一高度、左边或右边复制一块地面，大小基本对得上；从更近（画面更下面）或更远（更上面）取，地砖大小就不对。
2. **补丁要顺着透视线扭一下**。就算同一高度，左边和右边的地砖缝倾斜方向也不一样，挪过去以后要用变换的「扭曲」把它对齐。

## 动手前：复制原图 {#prepare}

先按 [5.4 课「动手前」](lesson:m5-04#prepare)复制并锁定原图，上面那层改名叫「修补」。

如果有干扰物和人物重叠（比如路人在人物的手臂后面），先用 [2.5 课](lesson:m2-05)的方法把人物抠到单独一层，放在最上面。下面补背景时就不会碰到人。

:::tip 如果摄影师拍了一张空场
同一个机位、人走开以后拍的那张"空场"，是最好的补丁。用 [[操作 > 添加 > 插入照片]] 把它导进来，放在「修补」上面，降低不透明度对齐位置，再加蒙版，只在干扰物的位置露出来。这样补出来的背景是真的，不需要克隆。
:::

## 第 1 步：小件和简单背景：克隆 {#clone}

:::step 先接上穿过干扰物的线
1. 点「修补」层，打开 [[调整 > 克隆]]，画笔选「气笔修饰」里的「中等硬画笔」。
2. 找到穿过干扰物的那条线（比如墙脚线），把圆盘放在**这条线上**、干扰物旁边，长按锁定。
3. 画笔尺寸调到比这条线稍粗，**沿着线**往干扰物那边涂，把线接过去。

看到：墙脚线从左到右是一条完整的线，干扰物还在线的上下两边。
:::

:::step 再补线和线之间的面
1. 画笔换成「软画笔」，尺寸调大，从 20% 左右开始，以笔刷圆圈比干扰物窄一点为准。
2. 圆盘放在干扰物**旁边、同一高度**的墙面上，锁定。同一高度的墙离光源距离差不多，明暗最接近。
3. 从干扰物的外缘往里涂。每涂一小块，就把圆盘挪到别的地方重新锁定，免得同一块纹理反复出现。
4. 地上如果有它的影子，一起补掉。

![大面积克隆](diagrams/m5/u-clone-big.svg "取样点在同一面墙、同一高度；涂一小块就换一次")

看到：路人不见了，墙面是连续的，看不到一块块的补丁或重复的花纹。
:::

:::warn 易错
- 取样点离得太近：圆盘里取到的是干扰物自己，一涂就把干扰物复制了一份。圆盘和画笔之间至少隔一个干扰物的宽度。
- 一直用同一个取样点：印章感。涂几笔就换。
- 涂完没缩小看：放大时看不出的重复，缩小以后很明显。每补完一个干扰物就把画布缩小看一眼。
:::

## 第 2 步：大件干扰物：复制相似区域，用蒙版拼 {#patch}

:::step 复制一块干净的背景
1. 在「修补」层上点选取工具，底部选「矩形」。框住一块和干扰物背后**结构相同**的干净背景，比干扰物大一圈。比如干扰物挡住的是墙面加一截地面，就框一块同样有墙面和地面的地方，墙脚线要在框里。
2. 三指在画布上往下拖，弹出「拷贝并粘贴」菜单，点「复制」。这块背景会复制到一个新图层上，改名为「补丁」。

![复制一块干净的背景](diagrams/m5/u-patch-copy.svg "矩形框住一块干净的墙和地面，三指下拖点复制")

看到：图层面板里多了「补丁」层。
:::

:::step 挪过去，对齐线
1. 点箭头图标（变换工具），底部选「自由变换」。
2. 用一根手指把补丁拖到干扰物上，盖住它。放大到墙脚线那里，让补丁里的墙脚线和原图的对齐。
3. 补丁和旁边的墙一模一样、看得出是复制的话，点底部的「水平翻转」翻一次。
4. 点一下变换图标确认。

![挪过去盖住干扰物](diagrams/m5/u-patch-move.svg "墙脚线对齐；需要时水平翻转一次")

看到：干扰物被盖住了，补丁的边缘还能看出一条硬边。
:::

:::warn 水平翻转的风险
翻转会把补丁里的东西左右反过来：带文字、Logo 的展板会变成反字；光从左边来的墙面，翻过来亮暗方向就反了。有这两种情况就不要翻，换一块地方复制。
:::

:::step 用蒙版把边缘融进去
1. 在「补丁」上轻点两次，打开「图层选项」，点「蒙版」。上面多了一个白色的蒙版层。
2. 选中蒙版层，用黑色的「软画笔」，不透明度拉到上限 100%（软画笔的边本身是虚的，涂出来自然有过渡），在补丁的**四条边**上涂。黑色涂到的地方补丁会被隐藏，露出下面原来的背景。
3. 涂多了，换白色涂回来。
4. 边缘处的线（墙脚线、地砖缝）要特别看一眼，确保接上以后才停。

![给补丁加蒙版](diagrams/m5/u-patch-mask.svg "黑色隐藏、白色显示；在补丁的边缘涂")

看到：补丁的边看不出来了，干扰物的位置是一块自然的墙面。
:::

:::why 为什么用蒙版，不用橡皮
橡皮擦掉就没了，擦多了只能撤销。蒙版只是把它藏起来，黑白随时能改，擦多擦少都能调回来。蒙版的详细用法见 [1.5 课](lesson:m1-05)。
:::

:::step 补完合并，省图层
一个补丁确认没问题后，在「补丁」上打开「图层选项」，点「向下合并」，它会和下面的「修补」合成一层。补丁多的话，一直不合并很快就会碰到图层上限。

看到：图层面板又回到了原图、修补两层。
:::

## 第 3 步：地面上的灯架：按透视补 {#perspective}

:::step 打开透视指引，放好消失点
1. 先找消失点：新建一个临时图层，沿两条地砖缝各画一条直线（画到头停住，线会变直），一直延长到它们相交。交点就是消失点。
2. 打开 [[操作 > 画布]]，打开「绘图指引」开关，点下面的「编辑绘图指引」。
3. 底部选「透视」。在刚才那个交点上轻点一下，放一个透视点。画面上会出现从这个点放射出来的蓝线。
4. 拖动透视点，让蓝线和地砖缝重合。点「完成」。删掉临时图层。

![透视指引](diagrams/m5/u-persp-guide.svg "在地砖线延长的交点上轻点，放一个透视点")

看到：画面上有一组蓝色的透视线，和地砖缝方向一致。导出时这些线不会出现。
:::

:::step 复制同一深度的地面，按透视扭曲
1. 在灯架左边或右边、**同一高度**的地面上，用矩形框一块干净的地砖，三指下拖「复制」。
2. 变换工具，选「自由变换」把它拖到灯架上。
3. 底部换成「扭曲」，一个角一个角地拖，让补丁里的地砖缝和蓝色透视线重合：靠近镜头的下边宽一些，远处的上边窄一些。
4. 加蒙版融边，方法和第 2 步一样。

![扭曲补丁对齐透视](diagrams/m5/u-distort.svg "扭曲：一个角一个角拖，让补丁的边对准透视线")

看到：灯架的位置是完整的地砖，地砖缝和两边的接上了，都指向消失点。
:::

:::step 剩下断开的地砖缝，用直线补
1. 新建一层「地砖缝」，在「图层选项」里打开「辅助绘图」（官方手册的图层选项页叫「辅助绘图」，另一页写作「绘图辅助」，以你界面上的为准）。这样画的线会自动贴着透视线走。
2. 长按画布，吸一下旁边地砖缝的颜色。
3. 用「着墨」里的「技术笔」，尺寸和地砖缝一样细，沿着断开的那段画过去。
4. 画完在图层选项里关掉「辅助绘图」。

看到：每一条地砖缝都是连续的。
:::

## 第 4 步：扩展画布，重新构图 {#extend}

什么时候要扩：人物"顶天立地"，头顶或脚下没有空；人物贴着画面边缘；要把竖图改成横图做封面。构图的原理见 [3.7 课](lesson:m3-07)。

:::step 把画布加大
1. 打开 [[操作 > 画布 > 裁剪并调整大小]]。画面上会出现一个网格，网格的边就是画布的边。
2. 拖网格的**一条边**往外拉，画布往这个方向变大；拖**角**可以两个方向一起变大。底部的宽、高数字会跟着变。
3. 「画布重新取样」保持关闭，否则原图会被缩放。
4. 点「完成」。

![裁剪并调整大小](diagrams/m5/u-crop-extend.svg "往外拖网格的边，画布就变大")

看到：画布变大了，多出来的地方是空白（显示的是背景颜色）。
:::

:::step 用旁边的内容补齐新区域
从靠近新区域的地方复制内容，挪过去，再融边：

- **墙面、天空这类没有细节的面**：用矩形框住靠边的一条，三指下拖「复制」，用「自由变换」拖到空白处，往外拉宽盖满。没有细节的地方拉伸也看不出来。
- **有花纹、展板的墙面**：复制一块，挪过去，必要时水平翻转（注意上面说的文字和光的方向），用蒙版融边。
- **地面**：按第 3 步，先打开透视指引，复制同一深度的地面，用「扭曲」对齐透视线。
- 接缝处最后用克隆修一遍。

看到：画布被填满了，补出来的部分和原图连在一起，线都接上了。
:::

:::step 统一清晰度和颗粒
补出来的部分和旁边比一比：

- **更清楚**：在补丁层上用 [[调整 > 高斯模糊]] 往右滑一点，和旁边一样虚。
- **更干净、没有噪点**：在补丁层上用 [[调整 > 杂色]] 加一点点，和原图的颗粒一致。杂色的用法见 [2.4 课](lesson:m2-04)。

看到：放大到 100%，补出来的部分和原图的清晰度、颗粒看不出差别。
:::

:::warn 易错
- 扩太多：每一边补出来的部分超过原图的 1/4，补的内容越多越容易假。真不够就换一张照片。
- 补出了原图里没有的东西：只补墙、地、天空这些简单的面，不要凭空补人、补道具。
- 扩完忘了重新构图：扩是为了构图，扩完要再用 [3.7 课](lesson:m3-07)的方法检查一遍，多余的再裁掉。
:::

## 修完检查 {#check}

:::check 怎么判断做对了
- **缩小看**：缩到手机屏幕大小，第一眼找不到哪里补过。
- **顺着线看**：沿墙脚线、每条地砖缝、栏杆从头看到尾，没有断开和错位。
- **找重复**：找有没有同一块污渍、同一个花纹出现两次。
- **找影子**：去掉的东西，影子、脚、拖在地上的线有没有也去掉。
- **翻转看**：[[操作 > 画布 > 水平翻转画布]]，换个角度再看一遍。
:::

after: diagrams/m5/case-crowd-after.svg | 修之后：三个路人和灯架都去掉了
:::

**照片情况**：场馆里的全身照，人物站在中间。后面靠墙站着三个路人，右边还有别的摄影师的灯架。墙面是浅色，上面有两块展板，地面是地砖。

**诊断**：四个干扰物都在人物后面，没有和人重叠。左边两个路人离得近、面积大，挡住了一段墙脚线和展板的下沿；右边的路人和灯架比较小，背后是纯墙面。

**修法和数值**（这张示范照片的数值，你的照片会不同，按画面判断）：

1. 右边的路人和灯架：克隆。先沿墙脚线把线接上（「中等硬画笔」），再用「软画笔」尺寸约 30% 补墙面，每涂 3～4 笔换一次取样点。灯架的三条腿踩在地砖上，按第 3 步补地面。
2. 左边两个路人：复制。在画面中间偏右、展板下面框了一块同样有墙脚线的墙面，「复制」，拖到左边盖住两人，墙脚线对齐。这块墙面上没有字，水平翻转了一次。加蒙版，黑色「软画笔」融边。
3. 两个人的脚在地砖上，又从左边同一高度复制了一块地砖，「扭曲」对齐透视线，加蒙版。
4. 补丁确认后「向下合并」到「修补」。

**为什么是这个顺序**：先修小的，再修大的。小的修完，画面上能用来复制的干净区域就多了。

:::warn 这类照片容易翻车的地方
- 展板的下沿也是一条线，只顾着墙脚线、忘了它：所有横穿干扰物的线都要先接上。
- 路人的头发、包带有一点露在人物身边：放大沿着人物轮廓检查一圈。
- 灯架的影子在墙上：顺着光的方向找一找。
:::

### 案例二：灯架踩在地砖上 {#case-floor}

:::compare
before: diagrams/m5/case-floor-before.svg | 修之前：灯架脚踩在地砖上，压着好几条地砖缝
after: diagrams/m5/case-floor-after.svg | 修之后：灯架去掉，地砖线连续
:::

**照片情况**：全身照，画面左前方有一个灯架，三条腿张开踩在地砖上，压住了四五条地砖缝。

**诊断**：灯架上半部分在墙前面，用克隆或复制都行；难的是下半部分在有透视的地面上，必须按透视补。

**修法和数值**（这张示范照片的数值，你的照片会不同，按画面判断）：

1. 找消失点：沿两条地砖缝画直线延长，交点在人物的腰附近。打开透视指引，在那里放一个透视点，拖到蓝线和地砖缝重合。
2. 灯架的灯头和立杆：克隆，墙面同一高度取样。
3. 三条腿：从灯架右边、同一高度复制了一块地砖（比三条腿张开的范围大一圈），挪过来，「扭曲」四个角，让补丁里的地砖缝和蓝线对齐，蒙版融边。
4. 还有两条地砖缝在补丁边缘差了一点没接上：新建一层，在图层选项里打开「辅助绘图」，吸缝的颜色，「技术笔」沿蓝线补画。

**为什么是这个顺序**：先找消失点再补。没有透视线做参照，补丁扭成什么样都"看起来差不多"，缩小以后才发现方向不对。

:::warn 这类照片容易翻车的地方
- 从灯架下方（离镜头更近）复制地砖：地砖太大，和周围对不上。一定从同一高度取。
- 只补了地砖缝，地砖上的反光、污渍对不上：蒙版融边时，让反光那块从原图露出来。
- 灯架的影子也落在地上：一起补掉。
:::

### 案例三：人物顶天立地，扩展画布做二次构图 {#case-extend}

:::compare
before: diagrams/m5/case-extend-before.svg | 修之前：人物顶天立地，四周没有留白
after: diagrams/m5/case-extend-after.svg | 修之后：画布往左、往上扩，补出背景，有了留白
:::

**照片情况**：摄影师拍得太紧，人物头顶几乎碰到画面上边，左右也没什么空间，画面很挤。

**诊断**：头顶和左边都需要留白。往上是墙面和展板，往左是墙和地砖，都是简单的面，适合扩。

**修法和数值**（这张示范照片的数值，你的照片会不同，按画面判断）：

1. [[操作 > 画布 > 裁剪并调整大小]]：左边往外拉约原宽度的 1/4，上边往上拉约原高度的 1/6。
2. 上面新增的部分：框住原图最上面一条墙面，「复制」，往上拖并拉高盖满。展板的上沿被切掉了，用「技术笔」吸展板边框的颜色补画了一条直线。
3. 左边新增的部分：墙面部分框住原图最左边一条墙「复制」，拖过去拉宽；地面部分先打开透视指引（消失点在原来的位置），复制最左边的地砖，「扭曲」对齐蓝线。
4. 接缝用克隆修了一遍；补出来的墙面比原图干净，加了约 3% 的杂色，和原图的颗粒看不出差别就停。
5. 按三分法检查：人物的眼睛落在上面那条三分线附近。

**为什么是这个顺序**：先扩墙面，再扩地面。墙面简单、补得快，补完以后墙脚线的位置定了，地面才知道从哪开始接。

:::warn 这类照片容易翻车的地方
- 左上角那块（上边和左边都扩出来的角）最容易补乱：它离原图最远，没有现成的内容可以复制。先补好上面和左边两条，再用这两条的内容去补角。
- 扩出来的地面透视不对，越往左地砖越乱：每一块补丁都对着蓝线扭曲。
- 补出来的墙太干净，和原图对比明显：加杂色，或者用克隆从原图搬一点污渍过去。
:::

## 下次拍的时候 {#prevent}

| 做法 | 解决什么 |
|---|---|
| 同一机位，等人走开再拍一张空场 | 后期直接用真背景补，最干净 |
| 用长焦和大光圈，把背景虚化掉 | 背景虚了，路人、灯架都不明显，好补 |
| 灯架放在人物正后方被挡住，或者放在画面外 | 灯架穿帮 |
| 构图时四周多留一点 | 后期裁剪比扩展画布容易得多 |
| 拍之前看一眼取景框的四个角 | 边上的垃圾桶、包、脚 |
