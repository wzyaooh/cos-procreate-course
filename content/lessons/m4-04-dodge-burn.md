## 先弄懂：在补什么光 {#why}

### 脸为什么会"平" {#why-flat}

[3.1 课](lesson:m3-01)讲过：物体有亮面、灰面、暗面，我们是靠这些明暗的变化看出体积的。脸也一样：额头、鼻梁、颧骨、下巴是往外凸的骨头，朝着光，所以亮；太阳穴、颧骨下方、鼻子两侧、下颌下面往里收，背着光，所以暗。

有两种光会把这些变化抹掉：

- **阴天、大面积的散射光**：光从四面八方来，每个面都差不多亮。
- **正面闪光灯**：光从镜头的位置直直打过来，正对镜头的面全亮，侧面的面因为离得远、角度斜，只是一起变暗，凸和凹之间的区别没了。

结果都是：脸在灰度里差不多是一整片同样的灰，看起来像一张纸，还显得脸大。加深减淡就是**按骨骼的位置，把本来该有的亮和暗补回去**。

### 中性灰为什么不改变画面 {#why-neutral}

![柔光模式的原理](diagrams/m4/p-overlay.svg "左：柔光模式下，图层颜色和 50% 灰比，决定变亮还是变暗；右：同一块皮肤叠上不同颜色的效果")

「柔光」和「覆盖」这两种混合模式，判断方法是一样的：**拿这一层的颜色和 50% 灰比**。50% 灰也叫中性灰，十六进制 `808080`，红、绿、蓝都是 128，计算：128 ÷ 255 ≈ 50%。

- **正好是中性灰**：下面的画面不变。所以一整层中性灰盖上去、模式改成柔光，画面看起来和没盖一样。
- **比中性灰亮**：下面的画面变亮。越接近白，变亮越多。
- **比中性灰暗**：下面的画面变暗。越接近黑，变暗越多。

Procreate 手册对「覆盖」的说法是：暗色让中间调更深沉、亮色让中间调更明亮；「柔光」是它的柔和版。

所以，在 50% 灰的柔光层上**用 10% 不透明度的白色涂一笔**，那一笔的地方从 50% 灰变成了大约 55% 灰（计算：50% + 10% × (100% − 50%) = 55%，往白偏了一点），下面的皮肤就亮一点点。同一个地方再涂一遍，55% + 10% × (100% − 55%) ≈ 60%，再亮一点。黑色同理。**每一笔都只动一点点，涂几遍就是几层**，这就是为什么加深减淡要用低不透明度：可以慢慢叠，随时停。

:::why 为什么不直接用满不透明度的白和黑
不透明度拉满的白在柔光层上会把皮肤推得很亮、很白，边缘也硬；拉满的黑会让皮肤又暗又脏，而且颜色会变得更浓、发橙。真实的光是一点点过渡的，只有一层层叠，才能叠出渐变。
:::

### 柔光还是覆盖 {#why-mode}

| 模式 | 效果 | 适合 |
|---|---|---|
| 柔光 | 温和，同样的笔画变化小，颜色不太会变浓 | 脸、皮肤，新手首选 |
| 覆盖 | 更强，对比和饱和度都会提高 | 头发、衣服的褶皱，或者需要比较强的立体感时 |

两种都可以，建好以后随时能在图层的混合模式里切换比较。本课按「柔光」写，换成「覆盖」时笔画要更轻。

### 为什么要开着灰度观察层涂 {#why-gray}

在彩色画面里，颜色会骗人：粉色腮红看起来像"亮"，暖色灯光下的阴影看起来像"脏"。加深减淡只管明暗，所以涂的时候打开 [4.1 课](lesson:m4-01#gray)的灰度观察层，只看明暗下笔；隔一会儿关掉，看彩色有没有变脏。

### 面部光影地图 {#map}

![面部光影地图](diagrams/m4/p-light-map.svg "黄色：高光区，用白色提亮；紫色：暗区，用黑色压暗")

**高光区**（用白色提亮）：

| 位置 | 为什么亮 | 怎么涂 |
|---|---|---|
| 额头中间 | 额骨最凸的地方 | 一块椭圆，两侧和上方淡出 |
| 鼻梁 | 鼻梁骨朝正前方 | **一条细线**，从两眼之间到鼻尖上方。涂宽了鼻子会变大 |
| 颧骨上方 | 颧骨最高处 | 从外眼角下方往太阳穴方向斜着的一小条 |
| 下巴 | 下巴尖往前凸 | 一小块，比额头的范围小 |

**暗区**（用黑色压暗）：

| 位置 | 为什么暗 | 怎么涂 |
|---|---|---|
| 太阳穴 | 额骨和颧骨之间凹进去 | 发际线边上，竖着的一条 |
| 颧骨下方 | 颧骨下面往里收 | 从耳朵前面斜着往嘴角方向，扫到脸颊一半就停 |
| 鼻侧 | 鼻梁两侧的斜面 | 鼻梁两边细细的两条，和鼻梁高光挨着，鼻子会变挺 |
| 下颌下方 | 下巴和脖子的交界 | 沿下颌线下面一条，把脸和脖子分开，脸显小 |

### 按主光方向调整 {#why-direction}

上面的地图是正面平光的"通用位置"。实际照片多少有一点方向，先找出来：

- **看鼻子的影子**：影子在鼻子右边，光就从左边来。
- **看眼睛里的反光点**：反光点在瞳孔的哪一侧，光就从哪一侧来。
- **看左右脸哪边更亮**：在灰度观察层里最明显。

找到以后：**迎光一侧**的高光可以再亮一点，暗区少一点；**背光一侧**的暗区可以再深一点，高光少一点。不要逆着原来的光画，比如光明明从左边来，你却在右脸画了更亮的高光，脸会显得光从两边打过来，很假。

## 动手前：确认图层顺序 {#prepare}

这一课接着 [4.3 课](lesson:m4-03#prepare)的图层继续。从下往上应该是：

1. **原图**（锁定）
2. **去瑕疵**
3. **补色**
4. **光影**（这节课新建）
5. **灰度观察**（4.1 课建的，一直在最上面）

光影层要在补色层上面：先把皮肤修干净，再在干净的皮肤上加光影。

## 第 1 步：建一个中性灰图层 {#fill}

:::step 设颜色为中性灰，新建图层并填充
1. 点右上角的颜色圆点，底部点「值」。十六进制填 `808080`（或者饱和度 0%、亮度 50%，算出来是 255 × 50% ≈ 128，和 808080 基本一样）。
2. 选中「补色」层，点「+」新建一层，它会出现在补色层上面。改名「光影」。
3. 点「光影」层两次，打开图层选项，点「填充图层」。

![填充中性灰](diagrams/m4/u-db-fill.svg "颜色设成 808080，新建「光影」层并填充")

看到：画面变成一整片灰色。下一步改模式就好。
:::

:::tip 不填灰行不行
可以。新建一个空图层，直接改成柔光模式，空的地方也不会影响画面。填灰的好处是：缩略图里能看到你涂了哪些地方；涂错的地方可以直接用 `808080` 的灰色涂回去，相当于"擦掉"，比橡皮擦更好控制。
:::

## 第 2 步：改成「柔光」模式 {#mode}

:::step 改混合模式
1. 点「光影」层右边的字母「N」。
2. 在混合模式列表里选「柔光」（它和覆盖、强光、亮光在同一组）。
3. 图层不透明度先保持默认的 100%，最后再调。

![改成柔光](diagrams/m4/u-db-mode.svg "混合模式选柔光，灰色消失")

看到：灰色不见了，画面和第 1 步之前一模一样。如果画面变暗或变亮了，说明颜色不是正好的中性灰，回第 1 步重新填。
:::

## 第 3 步：减淡：用白色涂高光区 {#dodge}

:::step 选画笔和颜色
1. 画笔选「气笔修饰」里的「软画笔」（[4.3 课](lesson:m4-03#paint)讲过在哪）。
2. 左侧栏不透明度从 **5% 左右开始**，扫三五遍才看出变化就对了，最多到 10% 左右；尺寸调到比要涂的区域稍大一点。
3. 颜色选纯白（十六进制 `FFFFFF`）。
4. 打开灰度观察层。

看到：画面是黑白的，当前图层是「光影」，右上角的颜色是白色。
:::

:::step 按地图涂高光
1. 在「光影」层上，从**额头中间**开始，来回轻扫，一个地方扫 3～5 遍。
2. 换小一点的尺寸涂**鼻梁**：从两眼之间往下画一条细线，到鼻尖上方停。
3. 涂**颧骨上方**：从外眼角下方往太阳穴斜着扫。
4. 涂**下巴**：一小块。
5. 迎光的一侧多扫一两遍。

![减淡高光区](diagrams/m4/u-db-dodge.svg "白色、5%～10% 不透明度，在高光区来回轻扫")

看到：灰度里，这几个地方比周围亮了一些，边缘是渐变的，看不出笔触。
:::

:::why 为什么笔刷要比区域大
软画笔的边缘是渐变的，中间最浓、边缘最淡。笔刷比区域大，涂出来是"中间亮、往外慢慢淡出"，就像真实的光。笔刷太小，会涂出一道道的线。
:::

## 第 4 步：加深：用黑色涂暗区 {#burn}

:::step 换黑色涂暗区
1. 颜色换成纯黑（`000000`），其他设置不变。暗区通常比高光再轻一点，不透明度从 5% 左右开始，一般不超过 8%。
2. 涂**颧骨下方**：从耳朵前面斜着往嘴角方向扫，扫到脸颊一半停。
3. 涂**太阳穴**：发际线边上，竖着扫。
4. 涂**鼻侧**：鼻梁两边细细的两条，尺寸要小。
5. 涂**下颌下方**：沿着下颌线下面扫一条，把脸和脖子分开。
6. 背光的一侧多扫一两遍。

![加深暗区](diagrams/m4/u-db-burn.svg "黑色，在暗区来回轻扫；颧骨下方斜着往嘴角方向")

看到：灰度里，脸的轮廓出来了：颧骨下面有一道柔和的阴影，下巴和脖子分开了，鼻子显得更挺。
:::

:::warn 易错：加深的地方变脏
关掉灰度观察层看彩色：加深过的地方发灰、发橙、像脏了一块。原因是黑色在柔光、覆盖模式下除了压暗，还会让颜色变浓。解决办法：降低那一块的力度（用 `808080` 灰色涂回去一点）；或者加深时不用纯黑，而是长按吸取那块皮肤的颜色，在颜色面板里把亮度拉低、饱和度降一点，用这个"深肤色"来涂。
:::

## 第 5 步：检查和收尾 {#check}

:::step 灰度、彩色、翻转各看一次
1. **灰度**：打开灰度观察层，缩小到全图。能分出亮面和暗面了吗？有没有一块块、一道道的痕迹？
2. **开关对比**：反复点「光影」层的勾选框，看修之前和修之后。
3. **彩色**：关掉灰度观察层，看加深的地方有没有变脏，提亮的地方有没有发白。
4. **翻转**：[[操作 > 画布 > 水平翻转画布]]，看左右是不是协调，然后翻回来。
5. **调强弱**：整体太强，降低「光影」层的不透明度，常用 60%～100%。整体太弱，再涂一遍，或者把模式改成「覆盖」试试。

![检查光影](diagrams/m4/u-db-check.svg "打开灰度观察层检查明暗；涂完关掉看彩色")

看到：灰度里脸有了立体感，过渡是渐变的；彩色里皮肤干净，没有脏斑。
:::

:::tip 笔触明显怎么办
笔触一道道的：在「光影」层上用涂抹工具（软画笔）轻轻抹开；或者打开 [[调整 > 高斯模糊]]，手指在画布上从 2% 左右开始往右滑，笔触刚好看不出就停。这个百分比和画布大小有关，同一个百分比在不同尺寸的画布上效果不一样，以看到的效果为准。模糊只作用在「光影」层上，照片本身不会糊。
:::

同样的方法可以用在脖子、锁骨、手臂和衣服褶皱上：凸起的地方提亮，凹进去的地方压暗。衣服的细节在 [5.3 课](lesson:m5-03)里展开。

## 三个完整案例 {#cases}

### 案例一：阴天外景，平光脸 {#case-flat}

（对比图见本课开头。）

**照片情况**：阴天户外，光很柔、没有方向。脸在灰度里几乎是一片均匀的灰，下巴和脖子连在一起。

**诊断**：光没有方向，就按通用地图涂。照片右边的天空稍亮，可以当成光略微从右边来，右侧高光多一点。

**修法和数值**（这张示范照片的数值，你的照片数值会不同，以灰度里看到的立体感为准）：

1. 光影层：808080，柔光，图层不透明度先用默认的 100%。
2. 减淡：白色，笔刷不透明度约 8%。额头 4 遍，鼻梁细线 3 遍，颧骨上方 3 遍（右侧 4 遍），下巴 2 遍。
3. 加深：黑色，约 6%。颧骨下方 4 遍（左侧 5 遍），太阳穴 3 遍，鼻侧 2 遍，下颌下方 5 遍。
4. 检查：灰度里还是偏平，模式改成「覆盖」，图层不透明度约 80%。

**为什么这个顺序**：先亮后暗。平光照片通常整体偏灰，先把高光提出来，才看得出暗区要压多深；先压暗，很容易压过头，整张脸变脏。

:::warn 这类照片容易翻车的地方
- 下颌下方不敢压，脸和脖子还是连成一片，脸显大。这一条可以比其他暗区深。
- 鼻梁的高光涂太宽，鼻子变得又宽又平。鼻梁是一条线，不是一块。
:::

### 案例二：正面闪光灯，中间亮四周灰 {#case-flash}

:::compare
before: diagrams/m4/case-flash-before.svg | 修之前：正面闪光，中间一片亮，四周发灰
after: diagrams/m4/case-flash-after.svg | 修之后：中间收亮，两侧和下颌加暗
:::

**照片情况**：晚上在场馆外，用手机闪光灯正面拍。脸的中间一大片发白，两侧和下巴一圈发灰，后面的背景很暗。

**诊断**：问题不是缺高光，而是"高光太大"：整块正面都是亮的。要先把亮的范围收小，再补暗区。

**修法和数值**（示范照片的数值，你的照片会不同）：

1. 先在 [4.3 课](lesson:m4-03#paint)的补色层上，用约 10% 的正常肤色把脸中间发白的地方压一压，特别是额头和两颊的大亮斑。
2. 光影层（柔光）：减淡只涂鼻梁细线和额头中间一小块，白色约 6%，2 遍。
3. 加深：颧骨下方、太阳穴、下颌下方，黑色约 8%，各 4～5 遍，把脸"收窄"。
4. 检查：灰度里亮的范围从一整块缩成了额头、鼻梁、颧骨三处。

**为什么这个顺序**：闪光照片先"减亮"再"加暗"。在一大片白上再加高光没有意义；先把多余的亮压掉，原本的高光位置才会显出来。

:::warn 这类照片容易翻车的地方
- 用黑色在柔光层上直接压脸中间的大亮斑，压完发灰发脏。大亮斑是"颜色太白"，用补色层的肤色压；光影层只负责明暗的结构。
- 两侧加暗加得太重，脸像戴了面具，四周一圈黑边。加深要往脸中间淡出。
:::

### 案例三：阴阳脸 {#case-messy}

:::compare
before: diagrams/m4/case-messy-before.svg | 修之前：阴阳脸，右半边暗一大截
after: diagrams/m4/case-messy-after.svg | 修之后：暗的一侧提亮，保留方向感
:::

**照片情况**：侧逆光，光从画面左边来，右半边脸整个在阴影里，明暗交界正好在鼻梁上，很硬。

**诊断**：和前两个相反，这张光的方向太强。要做的是"把暗的一侧提起来、把交界线变柔"，而不是把两边修成一样。

**修法和数值**（示范照片的数值，你的照片会不同）：

1. 光影层（柔光）：白色 10%，大号笔刷，在右半边脸上整体扫 4～6 遍，直到灰度里两边的差距缩小一半。
2. 交界线：用中号笔刷，白色约 6%，沿着鼻梁右侧的交界线扫，让它从"一刀切"变成渐变。
3. 右半边暗区里再补一点结构：颧骨上方白色约 6%、2 遍，让暗的一侧也有一点起伏。
4. 左边（迎光侧）不动，或者颧骨下方稍微压一点，保持光从左边来的感觉。

**为什么这个顺序**：先整体提亮暗面，再处理交界，最后补暗面里的结构。如果先修交界线，暗面一提亮，交界的位置又变了，要重修。

:::warn 这类照片容易翻车的地方
- 把右半边提得和左边一样亮，光的方向感完全没了，脸反而变平。留下明显的明暗差，只是不脏、不硬。
- 暗面提亮后发灰：柔光提亮暗部时，颜色会变淡。可以在补色层上用正常肤色补一点颜色回去，或者在最后整体调色时处理。
:::
