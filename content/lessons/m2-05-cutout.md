## 先弄懂：抠图难在哪里 {#why}

### 抠图在做什么 {#why-what}

抠图就是把人物的像素**单独放到一个图层上，人物以外是透明的**。之后要换背景（[7.1 课](lesson:m7-01)）、只液化人物不弯背景（[5.4 课](lesson:m5-04#liquify)）、只给背景做虚化（[2.4 课](lesson:m2-04#dof)），都要先有这样一层。

本课的做法不删原图：用选区把人物**拷贝**到新图层，原图原封不动留在下面。修边缘用蒙版，不直接擦。每一步都能退回去。

### 自动选取的阈值在比较什么 {#why-threshold}

![选区阈值](diagrams/m2/p-threshold.svg "阈值太低，背景没选满；合适，背景刚好选满；太高，连头发和衣服也被选进来")

自动选取的原理是：你点下去的那个点是"样本颜色"，Procreate 从这个点开始往四周找，**和样本颜色差得不多的、连在一起的**像素都选进来，碰到颜色差得多的地方就停。

**选区阈值**就是"差多少以内算差得不多"：

- 阈值低：只选和样本几乎一样的颜色。背景上有一点明暗变化（墙角暗一点）就选不进来。
- 阈值高：差得远一点的颜色也算进来。高过头，浅色的头发、白衬衫会被当成背景一起选走。

所以有一个关键的思路：**纯色背景时，选背景，再反转**。背景只有一种颜色，阈值很好调；人物身上有皮肤、头发、衣服好几种颜色，直接点人物要点很多次，还选不干净。

### 为什么修边缘用蒙版，不用橡皮 {#why-mask}

![蒙版](diagrams/m2/p-mask.svg "蒙版上黑色遮住，白色显示，灰色半透明")

蒙版是贴在图层上的一张黑白图：黑色的地方图层看不见，白色的地方看得见，灰色半透明。它只是"遮住"，没有删掉像素。

修边缘时会反复试：这里多遮一点，那里遮多了又要找回来。用橡皮擦掉的像素回不来，用蒙版只要换白色涂回来就行。蒙版、剪辑蒙版、阿尔法锁定的区别见 [1.5 课](lesson:m1-05)。

### 发丝为什么难 {#why-hair}

![发丝](diagrams/m2/p-hair.svg "左：横着一刀切过发丝，像剪过的；右：顺着发丝方向处理，长短不一、末梢半透明")

一根发丝往往比一个像素还细，照片里它和背景**混在同一个像素里**，所以发丝的像素是半透明的。处理发丝要守住两点：

1. **保留半透明**：发丝末梢本来就是若隐若现的，抠成完全不透明会变粗变硬，抠成完全透明就断了。
2. **顺着发丝的方向**：发丝是一根根往外长的，长短不一。如果横着一笔把发丝外面的背景都擦掉，所有发丝会断在同一条线上，像被剪过。

### 白边是从哪来的 {#why-edge}

![白边原理](diagrams/m2/p-edge.svg "边缘的像素是头发和白墙混出来的颜色；放到深色背景上就是一圈亮边")

人物的边缘不是一刀切的：最外面那一两圈像素，颜色是**人物和原背景混出来的**，在白墙前面拍，边缘就混进了白色。抠图时这圈像素留了下来，放回白墙前看不出来，换到深色背景上就成了一圈亮边，这就是**白边**。原背景是深色的，换到浅色背景上就会出现**黑边**。

所以去白边不是把边缘"擦掉一圈"（擦掉发丝就没了），而是**保留边缘的透明度，只把颜色换成头发或皮肤的颜色**。阿尔法锁定正好能做到：锁住图层的透明度，之后涂颜色只改颜色、不改透明度。

## 抠出人物 {#cutout}

:::step 复制原图，锁住原图
在原图上向左轻滑点「复制」，原图锁定。在副本上做选区（副本叫「抠图用」）。步骤图见 [5.4 课](lesson:m5-04#prepare)。

看到：原图带锁头，「抠图用」是蓝色高亮的当前图层。
:::

:::step 自动选取背景
1. 点左上角的 S 形图标（选取工具），底部选「自动」。
2. 在**背景**上点一下，**手指不要抬起**，按住左右拖动：顶部出现「选区阈值」，往右拖选得越多，往左越少。
3. 选中的部分会显示成反差的颜色。拖到背景刚好全部被选上、头发和衣服还没有被选进去就松手。数值每张照片都不一样，看画面判断。
4. 背景被人物隔成了几块（比如手臂和身体之间那块）：在每一块上都点一下，自动选取会把它们都加进来。

![自动选取](diagrams/m2/u-auto-sel.svg "点背景不抬手，左右拖调阈值")

看到：背景整片变成反差色，人物保持原来的颜色。
:::

:::warn 易错：阈值怎么调都不对
- 往右一点就漏进头发：头发颜色和背景太接近（浅色假发配白墙）。阈值停在头发刚好没被选上的位置，剩下没选上的背景用下一步的手绘补。
- 背景有明显的明暗变化（墙角暗、灯下亮）：分几块点，每块单独调阈值；或者整片用手绘选。
:::

:::step 换手绘，补漏选、去多选
1. 底部换成「手绘」，两指捏开放大到边缘。
2. **漏选的背景**：把它圈出来，点「添加」。
3. **多选进来的人物**（比如被选走的白衬衫领口）：把它圈出来，点「移除」。
4. **头发那一圈多留一点**：头发边缘不用追求准，把发丝外面一圈背景故意留在人物这边（从选区里移除），后面用蒙版一点点修。

![补选区](diagrams/m2/u-sel-fix.svg "手绘模式：圈出漏选的地方点添加，圈出多选的地方点移除")

看到：除了头发外面那一圈，背景都被选上了，人物身上没有一处被选走。
:::

:::step 反转，拷贝到新图层
1. 点「反转」：选区从背景换成人物。
2. 点「拷贝并粘贴」：人物被复制到一个新图层「从选区」上，原图层不变。
3. 新图层改名「人物」。

![反转并拷贝](diagrams/m2/u-invert-copy.svg "反转选区，再拷贝并粘贴")

看到：图层面板里多了一层「人物」；关掉下面所有图层，只剩人物，周围是透明的棋盘格。
:::

:::step 垫一层底色检查
1. 在「人物」下面新建一层，叫「检查底色」。
2. 颜色选深蓝或黑色，打开这层的图层选项，点「填充图层」。
3. 关掉原图和「抠图用」两层（点勾选框）。
4. 看完深色，再选白色或浅灰，重新「填充图层」看一遍。

![垫底色检查](diagrams/m2/u-check-bg.svg "人物下面垫一层深色，关掉原图")

看到：人物放在深色上。边缘有一圈亮边，头发外面还挂着一圈原背景，这些都是下面要修的。
:::

## 用蒙版精修边缘 {#refine}

:::step 给人物加蒙版
点「人物」层，再点一次打开图层选项，点「蒙版」。「人物」上方多出一层「图层蒙版」。

![加蒙版](diagrams/m2/u-mask-add.svg "图层选项里点蒙版")

看到：图层面板里「人物」上面有一行「图层蒙版」，缩略图是全白的（全部显示）。
:::

:::step 修清楚的边：衣服、手臂、道具
1. 点「图层蒙版」那一行，确认选中的是蒙版，不是人物。
2. 放大到边缘。对着清楚的硬边（衣服轮廓、手臂、道具），用「着墨」里的「技术笔」，黑色，不透明度拉到上限（100%），沿着边缘把残留的背景涂掉。
3. 对着本来就有点虚的边（失焦的手、飘动的裙摆），换「软画笔」，让边缘留一点柔和。
4. 涂进了人物：换白色，涂回来。

看到：在深色底上，衣服、手臂的边缘利落，外面没有一圈原背景。
:::

:::step 修发丝：顺着方向，保留半透明
1. 还是在蒙版上。笔换细一点的软画笔，尺寸比一根发丝束稍宽；黑色，**不透明度从 30% 左右开始**（发丝之间的背景压不下去再往上加，一般不超过 60%）。
2. **顺着发丝生长的方向**画：从发丝根部往末梢画，画在发丝和发丝之间的背景上，把那里压暗。
3. 发丝的末梢只扫一两笔，让它半透明，不要涂到完全消失。
4. 某一缕发丝被涂断了：换白色、低不透明度，顺着它涂回来。
5. 换浅色底色检查一遍，再换回深色检查一遍。

![修发丝](diagrams/m2/u-mask-hair.svg "在蒙版上，细笔、半透明的黑色，顺着发丝方向画")

看到：发丝之间的背景淡掉了，发丝长短不一，末梢半透明。在深色底上可能还有一点发白，下一步处理。
:::

:::warn 易错：发丝修得像剪纸
- 发丝外面一刀切齐：横着画了一笔。撤销，顺着发丝方向一缕一缕画。
- 发丝全变成了粗粗的一块：把发丝之间的背景当成头发留了下来。用更细的笔、更低的不透明度，多画几遍。
- 背景太乱，发丝实在分不出来：不要硬抠，把发丝收进来一点抠干净，再按 [5.1 课](lesson:m5-01)在新图层上补画几缕发丝，比硬抠自然。
:::

## 去白边：阿尔法锁定重新上色 {#defringe}

蒙版只能控制透明度，改不了颜色。白边的颜色问题要在人物层自己的像素上修，所以先把蒙版合并进人物层。

:::step 备份，再合并蒙版
1. 在「人物」上向左轻滑点「复制」，复制出来的那份改名「人物 备份」，关掉它的勾选框。复制图层会把蒙版一起复制。
2. 点「人物」上方的「图层蒙版」，打开图层选项，点「向下合并」。蒙版的黑白变成了「人物」层自己的透明度。

![合并蒙版](diagrams/m2/u-mask-merge.svg "先复制备份，再把蒙版向下合并")

看到：「图层蒙版」那一行没了，「人物」层的缩略图周围是透明的。画面看起来和合并前一样。
:::

:::step 阿尔法锁定，给边缘重新上色
1. **两指在「人物」层上向右轻滑**，打开阿尔法锁定，缩略图背景变成棋盘格。也可以在图层选项里点「阿尔法锁定」。
2. 吸取颜色：按住左边侧栏的方形按钮，用笔点**白边旁边、头发里面**的颜色（[2.1 课](lesson:m2-01#measure)用过同样的方法）。
3. 画笔用「软画笔」，不透明度从 10% 左右开始（一般不超过 20%），尺寸比白边宽一点，看到白边变成头发色就停。沿着头发边缘涂。阿尔法锁定下只会改颜色，透明的地方涂不上，半透明的地方透明度也不变。
4. 皮肤边缘的白边：吸旁边皮肤的颜色，同样涂。衣服边缘：吸衣服的颜色。
5. 换浅色底、深色底各检查一遍。

![阿尔法锁定上色](diagrams/m2/u-alpha.svg "两指向右滑打开阿尔法锁定；吸头发的颜色，沿边缘轻涂")

看到：深色底上，那圈亮边变成了头发的颜色，发丝还是半透明的；换到浅色底上也看不出边。
:::

:::tip 黑边也是同样的办法
原照片背景是深色的（夜景、黑幕），抠出来放到浅色背景上会有一圈黑边。同样：阿尔法锁定，吸旁边头发或皮肤的颜色，沿边缘轻涂。
:::

:::danger 千万别
直接用橡皮把边缘擦掉一圈。白边是没了，发丝的末梢和边缘的过渡也跟着没了，人物边缘变硬、变小，一眼像贴纸。
:::

## 背景复杂时怎么抠 {#busy}

漫展场地、树林、人群前面拍的照片，背景颜色杂，自动选取基本用不上：

1. **手绘为主**：选取工具选「手绘」，放大到 200% 左右（看得清边缘就行），沿着人物边缘**轻点**放节点（点出来的是直线段，适合衣服、道具的直边），弯的地方直接用笔描。可以描一段、点「添加」、再描下一段，分段完成。
2. **选人物，不反转**：背景太杂时，直接描人物比描背景容易。
3. **存一下选区**：描完一大圈很费时间，点「存储并加载」，再点「+」把选区存起来。之后要重新选时直接点它加载。
4. **头发收进来一点**：发丝后面背景很乱时，先把发丝外轮廓收进来一点抠干净，飞出去的碎发后面补画（[5.1 课](lesson:m5-01)）。
5. 拷贝并粘贴以后，同样加蒙版、修边缘、去白边，方法和上面一样。

## 两个完整案例 {#cases}

### 案例一：白墙前拍的半身照，换深色背景 {#case-white}

:::compare
before: diagrams/m2/case-halo-before.svg | 修之前：一圈白边
after: diagrams/m2/case-halo-after.svg | 修之后：边缘干净
:::

**照片情况**：在白墙前拍的半身照，粉色假发，两侧有一些飞出来的碎发。要换成深紫色的背景。

**诊断**：背景是纯白，适合自动选取背景再反转。白墙会在边缘留下白边，假发是粉色，白边在深色背景上会很明显。

**修法和数值**（这张示范照片的数值，你的照片数值会不同，按画面判断）：

1. 复制原图，锁定。在副本上：选取 › 自动，点白墙，按住往右拖，拖到墙全部选上、假发没有被选进来。
2. 手臂和身体之间的空隙：点一下加进选区。
3. 手绘：假发两侧碎发外面的那圈墙，圈出来点「移除」，留给蒙版去修。
4. 反转，拷贝并粘贴，改名「人物」。下面垫一层深紫色。
5. 人物加蒙版。衣服边：技术笔、黑色、不透明度拉到上限（100%）修。碎发：软画笔、黑色 40% 左右，顺着发丝方向画发丝之间的白墙。
6. 复制「人物」当备份。蒙版向下合并。
7. 两指右滑阿尔法锁定。吸假发的粉色，软画笔 15% 左右，沿头发边缘轻涂两遍，看到深色底上的白边消失就停；吸皮肤色，涂脖子和手臂的边。
8. 换白色底、浅灰底各检查一次，没问题再换回深紫。

**为什么是这个顺序**：先用蒙版把透明度修好，再合并、再上色。顺序反过来，上了色以后又改蒙版，新露出来的边缘还是白的。

:::warn 这类照片容易翻车的地方
- 阈值拉太高，浅粉色的头发边缘被当成白墙选走了：头发边缘像被啃了一圈。往左拉回来，宁可少选。
- 去白边吸的颜色太深（吸到了头发的阴影）：边缘变成一圈深线。吸靠近边缘、亮度和边缘差不多的头发颜色。
:::

### 案例二：漫展场地的全身照，背景全是人 {#case-busy}

**照片情况**：漫展场地里拍的全身照，人物后面是人群、展台和灯架，颜色很杂。要抠出来换一个干净的背景。

**诊断**：背景颜色和人物有很多重叠（后面的人穿着和 coser 颜色相近的衣服），自动选取用不了。只能手绘。头发后面是人群，发丝分不出来。

**修法和数值**（这张示范照片的做法，你的照片按画面调整）：

1. 复制原图，锁定。选取 › 手绘，放大到 200% 左右。
2. 衣服和道具的直边：轻点放节点；裙摆、手臂的弧线：直接描。分四段（头、上身、裙子、腿）描，每段描完点「添加」。
3. 头发：沿假发的外轮廓**稍微往里**一点描，飞出去的碎发不要了。
4. 描完点「存储并加载」，点「+」存起来。
5. 拷贝并粘贴，改名「人物」，垫深色和浅色底检查。
6. 蒙版修边缘；人群的颜色留在边缘上的，用阿尔法锁定吸旁边的颜色盖掉。
7. 新建一层，按 [5.1 课](lesson:m5-01)的方法沿头发外轮廓补画几缕碎发，头发边缘就不会显得被切过。

**为什么不硬抠发丝**：发丝后面是颜色杂乱的人群，发丝里混进的是各种颜色，抠出来每一缕都带着别人衣服的颜色，修起来比补画还慢，效果还更差。

:::warn 这类照片容易翻车的地方
- 一口气描完整个人，描到一半手滑：分段描、分段添加，描完马上存选区。
- 脚底和地面接触的地方：脚底的阴影也要一起选进来一点，换背景时脚才站得住（投影在 [7.2 课](lesson:m7-02)讲）。
- 换上去的新背景和人物的光线、颜色对不上：那是合成的问题，看 [7.1 课](lesson:m7-01)和 [7.2 课](lesson:m7-02)。
:::
