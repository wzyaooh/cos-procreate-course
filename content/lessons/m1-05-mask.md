## 先弄懂：三者到底改的是什么 {#why}

三个功能都能做到"只在衣服上有效果"，所以经常被混着用。区别在于**它们改的是谁**：

![三者对比](diagrams/m1/p-three.svg "上：图层结构；中：结果都一样；下：怎么打开、能不能改回、修图用途")

### 蒙版：用黑白决定这层哪里显示 {#why-mask}

在一个图层的「图层选项」里点「**蒙版**」，这个图层上面会多出一个绑在一起的「**图层蒙版**」。蒙版只有黑白灰：

![蒙版的黑白灰](diagrams/m1/p-mask-gray.svg "黑：完全藏起来；50% 灰：半透明；白：完全显示")

- **白色**：这层在这里完全显示（新建的蒙版是全白的，所以一开始什么都没变）。
- **黑色**：这层在这里完全藏起来，露出下面的图层。
- **灰色**：半透明，越黑越透。

关键是：**蒙版改的是"显示哪里"，图层本身一个像素都没动**。藏多了，在蒙版上涂白就回来，什么时候都行。

### 剪辑蒙版：上层借用下层的形状 {#why-clip}

在一个图层的「图层选项」里点「**剪辑蒙版**」，这个图层就会**剪辑到紧挨着它的下面那一层**：上层只在下层有像素的地方显示，下层透明的地方，上层也看不见。

可以把下层想成模子，上层是倒进去的颜料。上层随便涂、涂出界也没关系，出界的部分自动看不见。

- 剪辑层是**独立的一个图层**，有自己的混合模式、不透明度，可以单独调、单独删。
- 一个模子上面可以叠**好几层**剪辑层，比如一层换颜色、一层加阴影、一层加高光。
- 最底下的图层不能设成剪辑蒙版（下面没有模子）。

### 阿尔法锁定：只能画在已有像素上 {#why-alpha}

「阿尔法」指图层的透明度信息。打开「**阿尔法锁定**」，等于把这一层透明的地方锁住：**之后只能在已经有像素的地方画，透明的地方画不上去**。打开后图层缩略图的背景会变成棋盘格。

它和剪辑蒙版效果很像，但有一个根本区别：**阿尔法锁定是在这一层本身上画**。画上去的颜色直接替换了原来的像素，没有单独的一层可以删，只能撤销。

### 一句话记住 {#why-summary}

| | 蒙版 | 剪辑蒙版 | 阿尔法锁定 |
|---|---|---|---|
| 改的是 | 这层哪里显示 | 上层只在下层形状里显示 | 这一层自己的像素 |
| 怎么打开 | 图层选项 › 蒙版 | 图层选项 › 剪辑蒙版 | 图层选项 › 阿尔法锁定，或两指在图层上向右轻滑 |
| 多一层吗 | 多一个「图层蒙版」 | 多一个图层 | 不多 |
| 改错了 | 涂白找回 / 涂黑藏起 | 改上层或删掉上层 | 只能撤销 |
| 修图常用来 | 去背景、修抠图边缘、局部效果 | 换色、在形状里加阴影高光 | 给已经抠好的单独一层整体上色 |

### 为什么不要用橡皮擦去背景 {#why-not-erase}

![橡皮和蒙版](diagrams/m1/p-erase-vs-mask.svg "橡皮擦掉是删除；蒙版涂黑只是隐藏")

橡皮擦掉的像素是**真的删掉了**。抠图时擦多了一缕头发，当场还能撤销；修了半小时才发现，或者中途回过图库，就再也找不回来，只能重新导入原图从头抠。用蒙版涂黑效果一模一样，但涂白就能把头发找回来。**凡是"去掉照片的一部分"，都用蒙版。**

### 换色为什么要配「颜色」模式 {#why-color-mode}

三种方法只负责把颜色**限制在衣服的范围里**。颜色本身要用「**颜色**」混合模式叠上去：它换掉色相和饱和度、保留下层的明暗，褶皱和布纹才留得住（原理见 [1.4 课](lesson:m1-04#why-color)）。用「正常」模式涂上去，衣服会变成一块平涂的纸片。

也因为保留的是明暗，**纯白、浅灰的衣服用颜色模式几乎染不上色，纯黑的衣服也染不出鲜艳的颜色**。这两种情况的处理在 [5.6 课](lesson:m5-06)。

## 第 1 步：准备图层，选中衣服 {#prepare}

动手前先复制一份原图、把原图锁定，做法见 [5.4 课「动手前」](lesson:m5-04#prepare)。

:::step 用自动选取选中衣服
1. 点左上角 S 形图标（选取），底部选「**自动**」。
2. 在衣服上**点住不放**，手指左右拖：往右，选中的范围变大；往左，变小。选中的部分会显示成和原色对比明显的颜色。
3. 一次选不全，就再点一下没选到的地方，会加进选区。
4. 选多了（漏到皮肤或背景），往左拖小一点；还不行就换「手绘」，点「移除」把多的圈掉（[1.6 课](lesson:m1-06#select)）。

![自动选取衣服](diagrams/m1/u-sel-dress.svg "点住衣服左右拖调阈值，选好点拷贝并粘贴")

看到：整条裙子被选中，腿、上衣、背景都没被选进去。
:::

:::step 把衣服复制到单独一层
在选取工具底部点「**拷贝并粘贴**」。

看到：图层面板里多了一层「从选区」，里面只有裙子，别的地方是透明的。点掉其他图层的勾检查一下，再勾回来。第 3、4 步都从这一层开始。
:::

## 第 2 步：三种方法，同一个目标 {#methods}

下面三步任选一种都能完成换色。作业要求三种都做一遍，体会差别。

## 第 3 步：方法一——阿尔法锁定 {#alpha}

:::step 锁住透明，填上新颜色
1. 选好新颜色（比如青绿色）。
2. 在「从选区」上轻点两下打开图层选项，先点「**阿尔法锁定**」。
3. 再打开图层选项，点「**填充图层**」。

![阿尔法锁定后填充](diagrams/m1/u-alpha-fill.svg "先阿尔法锁定，再填充图层：只有裙子的形状被填满")

看到：这层变成一块青绿色的裙子剪影，裙子外面仍然是透明的——因为透明的地方被锁住了，填不进去。
:::

:::step 改成颜色模式
点这层右边的 N，混合模式选「**颜色**」。

![两指右滑开关阿尔法锁定](diagrams/m1/u-alpha-swipe.svg "缩略图背后是棋盘格，表示阿尔法锁定开着；两指向右轻滑可以开关")

看到：裙子变成青绿色，褶皱的明暗还在。缩略图背后是棋盘格。
:::

**优点**：最快，只多一层。边缘和选区一模一样。
**缺点**：颜色是直接填进这层的像素里的。想换别的颜色只能重新填；发现选区漏了一块，要关掉阿尔法锁定补画、再锁上再填。

## 第 4 步：方法二——剪辑蒙版 {#clip}

:::step 新建一层，剪辑到衣服上
1. 选中「从选区」，点「+」新建一层，它会出现在「从选区」的正上方。命名「新颜色」。
2. 选好新颜色，打开「新颜色」的图层选项，点「填充图层」。整个画面都被盖住了，别慌。
3. 再打开「新颜色」的图层选项，点「**剪辑蒙版**」。

![设为剪辑蒙版](diagrams/m1/u-clip-create.svg "图层选项 › 剪辑蒙版")

看到：画面恢复了，只有裙子那块是青绿色的平涂。「新颜色」在图层面板里往右缩进，左边有一个向下的小箭头，表示它剪辑到了下面的「从选区」。
:::

:::step 改成颜色模式
点「新颜色」右边的 N，混合模式选「**颜色**」。

![剪辑蒙版的样子](diagrams/m1/u-clip-result.svg "缩进加向下箭头；混合模式改成颜色")

看到：裙子变成青绿色，褶皱还在。
:::

**优点**：颜色是单独一层。想换颜色，重新填充这层就行；嫌太艳，降这层不透明度；还能在上面再叠一层剪辑层（正片叠底加阴影、滤色加高光），都只在裙子里有效。「从选区」本身一点没动。
**缺点**：多占图层；如果模子（「从选区」）的边缘没选好，剪辑出来的颜色边缘也不好，要回去修模子。

:::tip 剪辑层还能画
剪辑层不一定要整层填色。在剪辑层上用软画笔随便涂，涂出裙子的部分都看不见。给裙子加[阴影](lesson:m1-04#case-shadow)时，把阴影层设成剪辑蒙版，就不怕画出界。
:::

## 第 5 步：方法三——蒙版 {#mask}

这个方法不用「从选区」，而是**把整张照片都调色，再用蒙版只露出衣服**。

:::step 复制一份照片，整张调色
1. 在照片图层（没锁的那份）上向左轻滑，点「复制」，命名「换色副本」。
2. 选中「换色副本」，打开 [[调整 > 色相、饱和度和亮度]]，拖「色相」滑块，直到裙子变成你想要的颜色。点一下魔棒图标确认。

看到：整张照片的颜色都变了，皮肤、背景也跟着变了，这是正常的。
:::

:::step 加蒙版，先全部藏起来
1. 打开「换色副本」的图层选项，点「**蒙版**」。上面多出一个白色的「图层蒙版」，画面没变化。
2. 点一下「图层蒙版」让它变成蓝色（当前图层）。
3. 颜色选纯黑，打开蒙版的图层选项，点「填充图层」。

![给图层加蒙版](diagrams/m1/u-mask-create.svg "图层选项 › 蒙版")

看到：画面恢复成原来的颜色——蒙版全黑，换色副本被整个藏起来了。
:::

:::step 用白色把衣服"画出来"
1. 确认当前图层还是「图层蒙版」。
2. 用「气笔修饰 › 中等画笔」，颜色选纯白，不透明度拉到上限（100%），涂裙子。涂到哪，新颜色就露到哪。
3. 想更快更准：先用第 1 步的方法自动选取裙子，**有选区的时候画笔画不出选区**，再在蒙版上涂白，就不会涂出界。
4. 涂出界了，换黑色涂回去。

![在蒙版上涂白](diagrams/m1/u-mask-paint.svg "当前图层是图层蒙版；白色显示、黑色隐藏")

看到：只有裙子变成新颜色。蒙版缩略图里，裙子形状是白的，其余是黑的。
:::

**优点**：完全可逆，涂黑涂白随时改；边缘可以用软画笔、低不透明度做出柔和过渡，适合边缘不清楚的地方（头发搭在衣服上）。
**缺点**：用「色相、饱和度和亮度」整体转色相，很难调到某个准确的颜色；要靠手涂，大面积时比前两种慢。

:::why 为什么在蒙版上颜色会"变灰"
当前图层是蒙版时，颜色面板会忽略色相，只给黑白灰。你选了红色去涂，实际涂上去的是和红色同样亮度的灰。所以涂蒙版直接选纯黑、纯白，最清楚。
:::

## 三种方法怎么选 {#choose}

| 情况 | 用 |
|---|---|
| 只想快速试一个颜色，选区很干净 | 阿尔法锁定 |
| 要反复换颜色，或者还要加阴影、高光 | 剪辑蒙版 |
| 衣服边缘和头发、手搭在一起，边缘要柔 | 蒙版 |
| 去掉背景、修抠图边缘 | 蒙版（永远不用橡皮擦照片） |

## 两个完整案例 {#cases}

### 案例一：按角色设定给百褶裙换色 {#case-dress}

:::compare
before: diagrams/m1/case-dress-before.svg | 修之前：紫色百褶裙
after: diagrams/m1/case-dress-after.svg | 修之后：青绿色，褶皱还在
:::

**照片情况**：coser 买到的裙子是紫色，角色设定是青绿色。裙子是中等深浅的纯色，轮廓清楚，上衣是浅紫色。

**诊断**：裙子颜色单一，自动选取能干净选出来；之后可能还要按设定图微调颜色，选**剪辑蒙版**，颜色层独立，好改。

**修法和数值**（括号里是这张示范照片的读数，你的照片数值会不同，按画面判断）：

1. 复制并锁定原图。
2. 自动选取裙子，阈值调到裙子整条选中、上衣和腿没被选进去（这张图约 30%～40%）。上衣和裙子颜色接近，阈值往右拖一点就会漏到上衣上，要盯着腰带那条线。
3. 拷贝并粘贴，得到「从选区」。
4. 上面新建「新颜色」，吸管从设定图上取青绿色（把设定图用 [[操作 > 添加 > 插入照片]] 放进来，取完色删掉那层），填充图层，设为剪辑蒙版，模式「颜色」。
5. 放大到 200% 左右（看得清边缘一圈像素就行）看腰带和裙摆边缘。有一圈紫色漏出来，说明「从选区」边缘选少了：选中「从选区」，用硬一点的画笔吸管取裙子的颜色补上那一圈（剪辑层会自动跟着变）。
6. 颜色太艳，从 90% 左右开始降「新颜色」的不透明度，看到裙子和照片里其他布料一样鲜就停（这张停在 80%～90%）。

**为什么是这个顺序**：先保证模子准，再上色。颜色可以随时改，模子不准的话怎么调颜色边缘都是错的。

:::warn 这类照片容易翻车的地方
- 自动选取漏到上衣：两件颜色接近时，阈值宁小勿大，没选到的地方再补点。
- 裙子边缘有一圈原色：放大看边缘，用上面第 5 步补模子。
- 颜色换完发灰：原裙子太浅或太深，颜色模式能换的饱和度有限，看 [5.6 课](lesson:m5-06)。
:::

### 案例二：抠图擦多了头发 {#case-edge}

:::compare
before: diagrams/m1/case-edge-before.svg | 修之前：橡皮抠图擦多了一块头发
after: diagrams/m1/case-edge-after.svg | 修之后：蒙版涂白找回，再补几根飞丝
:::

**照片情况**：要把人物换到新背景上（[7.1 课](lesson:m7-01)）。上次用橡皮擦去背景，右边头发擦掉了一块，回过图库，撤销不了。

**诊断**：被橡皮擦掉的像素已经没了，只能**重新导入原图**再抠。这次改用蒙版。

**修法和数值**：

1. 从图库重新导入原图（或者用备份的 .procreate），把人物图层复制一份，命名「人物」。
2. 给「人物」加蒙版。
3. 先用自动选取或手绘选取（[1.6 课](lesson:m1-06)）选中背景，在蒙版上涂黑，大块背景藏掉。
4. 头发边缘：取消选区，换软画笔，不透明度从 30% 左右开始（这张用到 30%～50%，你的照片按画面调），在蒙版上沿头发外缘涂黑，看到头发边缘自然变淡、没有一条硬线就停。
5. 藏多了的头发：换白色，在那块涂一涂，头发就回来了。
6. 最后在「人物」上面新建一层，用 [1.3 课](lesson:m1-03#case-hair)的工作室笔补几根飞丝，让边缘更自然。

**为什么用软画笔修边缘**：头发边缘本来就是半透明的细丝，用硬边涂黑会切出一条整齐的硬线，像剪纸。软边、低不透明度在蒙版上会变成灰色，正好做出半透明的过渡。

:::warn 这类修法容易翻车的地方
- 在「人物」图层上涂黑，而不是在蒙版上：涂上去的是黑颜料，不是隐藏。涂之前看一眼，蓝色的那行应该是「图层蒙版」。
- 把蒙版删了：在蒙版上向左轻滑点删除，藏起来的东西会全部重新显示，抠的工作白做。
- 头发边缘留着原背景的颜色：从亮背景抠到暗背景，边缘会有一圈亮边，需要处理边缘颜色，[2.5 课](lesson:m2-05)细讲。
:::
