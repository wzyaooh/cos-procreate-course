飘落的花瓣、雪花、光点，看起来很简单，难在**不像贴纸**。这节课先讲笔刷是怎么"印"出花瓣的，自己做一支笔刷，再讲怎么按景深分层，让粒子有前有后。

:::tip 这节课的示意图
文中的界面图是按 Procreate 5 的布局画的示意图，不是真机截图，按钮的细节和位置以你 iPad 上的实际界面为准。
:::

:::tip 这节课的数字怎么用
步骤里的尺寸、不透明度、模糊百分比都是**起点值**：从写的数左右开始，看到每步写的效果就停，不用照抄。画笔尺寸的百分比在不同尺寸的画布上画出来的粗细不一样，以看到的粗细为准；高斯模糊这类百分比在像素大小不同的照片上效果也不一定一样，以画面为准。
:::

## 先弄懂 {#why}

### 笔刷是一个个"印"出来的 {#why-stamp}

![笔刷是形状沿路径印出来的](diagrams/m6/p-stamp.svg "间距小，印连成线；间距大，一个个分开；加横向抖动和散布，散开、乱转")

手册的说法是：画笔由**形状**创建外形，里面装着**颗粒**（纹理）；你画一笔，Procreate 就沿着这条路径把形状一个个"印"上去。平时的笔刷印得很密，看起来是一条连续的线。做飘落笔刷，就是把一片花瓣当成形状，让它：

| 想要的效果 | 调哪个设置 | 在画笔工作室的哪一页 |
|---|---|---|
| 一片片分开 | 间距调大 | 描边路径 |
| 不排在一条线上，往两边散 | 横向抖动、线性抖动、间距抖动 | 描边路径 |
| 每片角度不同 | 散布（每次印的时候随机旋转） | 形状 |
| 每笔的起始角度也不同，有的翻面 | 随机化、水平翻转、垂直翻转 | 形状 |
| 有大有小、有深有浅 | 抖动里的尺寸、不透明度 | 动态 |
| 颜色有细微变化 | 图章颜色抖动 | 颜色动态 |

### 形状来源：白色出颜色，黑色透明 {#why-shape}

![形状来源](diagrams/m6/p-shape-src.svg "黑底白花：画出来是花瓣。反了（白底黑花）：画出来是方块中间挖个洞")

形状来源只看明暗：**白色的地方会印出颜色，黑色的地方是透明的**，灰色是半透明。所以形状要画成**黑底白图**。画反了，印出来是一个个方块，花瓣的位置是空的。手册和不少教程都提到，在形状编辑器里**两指轻点预览图**可以反转黑白。

形状要画在画布正中、四周留一点空：形状碰到画布边缘，印出来会被切掉一块。

### 为什么要分三层 {#why-depth}

![景深三层](diagrams/m6/p-depth.svg "从侧面看：近景离镜头近，大而虚；中景在对焦的人物这里，清楚；远景远，小而密")

照片是有景深的：对焦在人物上，人物前后的东西会不同程度地糊。粒子也必须遵守：

- **近景**（镜头和人之间）：离镜头近，所以**大**；不在焦点上，所以**糊**；数量**少**，几片就够，而且多放在画面边角，不挡脸。
- **中景**（人物周围）：和人物在同一个距离，**和人物一样清楚**，大小中等。
- **远景**（人物身后）：远，所以**小**、**多**、**密**；清晰度**跟照片背景一致**，背景清楚就清楚，背景虚了它也要虚一点；颜色淡一点，因为隔着空气。

还有一条：**远景的粒子在人后面**，不能落在人身上。所以远景层要放在抠出来的人物层下面。

只画一层、大小都差不多、都很清楚，看起来就像贴纸：

![只画一层](diagrams/m6/case-64-sakura-flat.svg "只有一层：大小一样、都清楚，没有前后")

## 第 1 步：画一个形状来源 {#shape}

:::step 黑底白花
1. 新建一张正方形画布，比如 1000 × 1000 像素。
2. 背景颜色设成纯黑 000000（方法见 [6.2 课](lesson:m6-02#canvas)）。
3. 选纯白色，用「着墨」里的「技术笔」画轮廓再填满（把颜色从右上角的色块拖进轮廓里就能填色），画一朵五瓣樱花，或者一片单独的花瓣。花瓣尖端那个小缺口要画出来，这是樱花和其他花的区别。
4. 画在正中，四周留出大约画布宽度的 1/10。
5. 三指下拖 › 「全部拷贝」。

![画形状来源](diagrams/m6/u-shape-draw.svg "黑色正方形画布，纯白画在正中，画完全部拷贝")

看到：黑色正方形中间一朵白色的花，边缘没有碰到画布边。
:::

:::tip 雪花用对称画
雪花是六瓣的，但径向对称是八等分。可以用「四象限」画四个方向，再自己补两笔；或者干脆画一个简单的六芒星加几根小枝。Procreate 官方的教学方案里就有用对称指引画雪花的例子（见本课资料）。
:::

## 第 2 步：新建笔刷，导入形状 {#import}

:::step 创建新笔刷
1. 点画笔图标。建议先点画笔库右上角的「+」，选「创建新组合」，建一个自己的组（比如叫「我的特效」）并选中它，新笔刷会放在当前选中的组里。
2. 再点「+」，选「创建新笔刷」。会打开「画笔工作室」。

![创建新笔刷](diagrams/m6/u-new-brush.svg "画笔库右上角「+」› 创建新笔刷")

看到：画笔工作室，左边是属性列表（描边路径、稳定性、锥度、形状……），中间是设置，右边是可以试画的「绘图板」。
:::

:::step 打开形状编辑器
左边点「形状」，在「形状来源」右边点「编辑」，打开形状编辑器。

![形状来源](diagrams/m6/u-shape-src.svg "左边点「形状」；形状来源右边点「编辑」")

看到：弹出「形状编辑器」，中间是当前形状的预览。
:::

:::step 粘贴你画的形状
1. 点左上角「导入」，选「粘贴」：刚才拷贝的黑底白花出现在预览里。
2. 预览里应该是**黑底白花**。如果是白底黑花，两指轻点预览图反转。
3. 点「完成」。

![形状编辑器](diagrams/m6/u-shape-import.svg "导入 › 粘贴；反了就两指轻点反转；完成")

看到：在右边绘图板上画一笔，出现一串粉色（当前颜色）的花瓣，但挤成一条，下一步调开。
:::

## 第 3 步：调成飘落的样子 {#settings}

以下数值是起点，每调一个都在右边绘图板上画一笔看效果。

:::step 描边路径：分开、散开
左边点「描边路径」：

| 设置 | 数值 | 为什么 |
|---|---|---|
| 间距 | 60%～80% | 花瓣一片片分开，不连成线 |
| 间距抖动 | 30%～50% | 间隔有疏有密 |
| 横向抖动 | 60%～100% | 往笔划两边散开，不排成一列 |
| 线性抖动 | 30%～50% | 沿笔划方向前后乱一点 |
| 掉落 | 0% | 不然越画越淡 |

![描边路径](diagrams/m6/u-studio-path.svg "间距和横向抖动是关键")

看到：绘图板上画一笔，花瓣一片片分开，散在笔划两边一片区域里。
:::

:::step 形状：每片转个角度
左边点「形状」：

| 设置 | 数值 | 为什么 |
|---|---|---|
| 散布 | 拉到最大 | 每印一片随机转一个角度 |
| 个数 | 1～2 | 每个位置印一两片 |
| 随机化 | 打开 | 每一笔开始的角度都不同 |
| 水平翻转、垂直翻转 | 打开 | 有的花瓣是"翻过来"的 |

![形状设置](diagrams/m6/u-studio-shape.svg "散布拉满，随机化和翻转打开")

看到：每片花瓣朝向都不一样。
:::

:::step 动态：有大有小、有深有浅
1. 左边点「动态」，「抖动」下的「尺寸」从 40% 左右开始，「不透明度」从 20% 左右开始，绘图板上画出来大小、深浅有明显差别就停。「速度」下的两项保持 0（滑块在中间）。
2. 左边点「颜色动态」，「图章颜色抖动」里的「亮度」调到 10% 左右，「色相」2%～5%：花瓣颜色有细微的深浅变化。
3. 如果花瓣里面出现了纹理，左边点「颗粒」，把颗粒的「深度」调到最小，花瓣就是实心的。
4. 点右上角「完成」。在画笔库里，向左轻滑这支笔刷 › 「重命名」，改成「樱花飘落」。

![动态设置](diagrams/m6/u-studio-dyn.svg "抖动里的尺寸和不透明度")

看到：绘图板上一笔下去，花瓣有大有小、深浅不一、方向各异，像一阵风吹过。
:::

:::warn 笔刷常见问题
- 画出来是方块：形状来源黑白反了，回形状编辑器两指轻点反转。
- 花瓣被切掉一角：形状画到了画布边缘，重画留出空白。
- 花瓣糊糊的：形状来源画布太小（比如 200 像素），用 1000 像素以上重画。
- 改坏了：在画笔工作室左边点「关于此画笔」，里面可以「重置画笔」。
:::

## 第 4 步：按景深分三层画 {#layers}

:::step 准备图层
1. 用 [2.5 课](lesson:m2-05)的方法把人物抠出来，单独一层「人物（抠图）」，放在原图上面。
2. 在「人物」**下面**新建「远景」层；在「人物」**上面**新建「中景」「近景」两层。
3. 三层可以放进一个组（在图层面板选中几层，用「组合」）。

![三层的图层顺序](diagrams/m6/u-depth-layers.svg "远景在人物下面，中景、近景在人物上面")

看到：图层面板从上到下是近景、中景、人物（抠图）、远景、原图。
:::

:::step 远景：小、多、密
1. 选中「远景」，笔刷「樱花飘落」，尺寸调小，从 2% 左右开始，比照片背景里的花朵还小一些为准；颜色比中景浅一点。
2. 在背景里、树冠下面大范围地刷几笔，可以密一些。
3. 照片背景是虚的：给这一层 [[调整 > 高斯模糊]] 从 2% 左右开始，糊到和背景差不多就停。背景清楚就不用糊。

看到：背景里飘着很多细小的花瓣，落在人物身上的那些被人挡住了（因为在人物下面）。
:::

:::step 中景：清楚，围着人物
1. 选中「中景」，尺寸中等，从 5% 左右开始，以一片花瓣和人物的手指差不多宽为准，颜色正常。
2. 在人物周围刷两三笔，数量比远景少。不用模糊，它和人物一样清楚。
3. 有花瓣落在脸上、眼睛上，用橡皮擦掉，或用蒙版擦掉。

看到：人物周围有清楚的花瓣，和人物的清晰度一样。
:::

:::step 近景：大、少、糊
1. 选中「近景」，尺寸开大，从 15% 左右开始，比中景花瓣大好几倍为准。不用刷，**一片一片轻点**，只放 3～6 片，放在画面的边角、人物前方。
2. [[调整 > 高斯模糊]] 从 15% 左右开始，糊到看不清花瓣边缘就停。
3. 想要风的感觉，再做 [[调整 > 动态模糊]]，一指沿着花瓣飘落的方向滑（比如从左上往右下）。
4. 不透明度从 70% 左右开始，大花瓣有一点透、不像实心贴片就停。

![近景高斯模糊](diagrams/m6/u-near-blur.svg "近景层：尺寸开大，少量几片，高斯模糊 15%～30%")

看到：画面边角有几片大而虚的花瓣，像是贴着镜头飘过，画面一下子有了纵深。
:::

## 第 5 步：用「闪光」加光粒子 {#sparkle}

:::step 点出光粒子
1. 新建图层，模式「添加」。
2. 画笔库 › 「亮度」 › 「闪光」。颜色选特效的颜色（比如魔法阵的紫色）。
3. **一个一个轻点**。大的少、小的多；靠近光源（手、魔法阵、剑）密，离远了稀。
4. 同样可以分层：近处几个大的加一点高斯模糊，远处小的保持清楚。

![闪光笔刷](diagrams/m6/u-sparkle.svg "亮度 › 闪光，新图层添加，一个个轻点")

看到：光源周围散着亮晶晶的光点，越靠近光源越密。
:::

## 两个完整案例 {#cases}

### 案例一：樱花树下 {#case-sakura}

:::compare
before: diagrams/m6/case-64-sakura-before.svg | 修之前：没有飘落的花瓣
after: diagrams/m6/case-64-sakura-after.svg | 修之后：远、中、近三层
:::

**照片情况**：樱花树下，人物在画面中间，背景的树冠是虚的。

**诊断**：背景虚，所以远景花瓣也要虚一点；人物清楚，中景花瓣要和人一样清楚。

**修法和数值**（这张示范照片的数值，你的照片会不同，按画面判断）：

1. 笔刷「樱花飘落」：间距 70%，横向抖动 80%，散布最大，尺寸抖动 50%，不透明度抖动 30%（都在第 3 步的起点范围里）。
2. 远景：尺寸 3%，浅粉色，在树冠下面和背景里刷 4～5 笔，高斯模糊 4%（糊到和虚掉的树冠一样就停），在人物下面。
3. 中景：尺寸 6%（以花瓣和手指差不多宽为准），粉色，围着人物刷 2 笔，不模糊。擦掉落在脸上的两片。
4. 近景：尺寸 25%，只点 5 片，左上角两片、右下角三片，高斯模糊 25%（看不清花瓣边缘就停），动态模糊沿左上到右下，不透明度 70%。

**为什么是这个顺序**：从远到近画，先铺满背景，再加主体周围，最后几片近景点睛。近景最后放，才知道哪里还空、哪里不能挡。

:::warn 这类照片容易翻车的地方
- 三层一样大，或者都一样清楚：近景一定要大而糊。
- 近景放在脸前面，挡住了脸：近景只放边角。
- 远景放在人物上面，花瓣"贴"在人身上：远景层拖到人物下面。
- 花瓣的飘落方向乱：动态模糊的方向三层要一致，都是风吹的方向。
:::

### 案例二：雪景 {#case-snow}

:::compare
before: diagrams/m6/case-64-snow-before.svg | 修之前：雪景，但雪没拍出来
after: diagrams/m6/case-64-snow-after.svg | 修之后：远处细雪 + 中景雪花 + 近处糊雪团
:::

**照片情况**：雪地，天是灰的，快门太快，空中的雪没拍出来。

**诊断**：雪比花瓣简单：远处就是小白点，中景可以看出雪花形状，近处是大而糊的白团。

**修法和数值**（这张示范照片的数值，你的照片会不同，按画面判断）：

1. 做两支笔刷：「雪点」（形状来源用一个白色软圆点）和「雪花」（形状来源画一片六角雪花）。
2. 远景：「雪点」尺寸 1%～2%（远处的雪只是细小的白点就停），大量刷满天空，在人物下面，不透明度 80%。
3. 中景：「雪花」尺寸从 3% 左右开始，看得出雪花形状就停，在人物周围刷几笔，清楚。
4. 近景：「雪点」尺寸从 20% 左右开始，点 5～6 个，高斯模糊 20%（变成看不清边的白团就停），不透明度 70%。
5. 雪是往下落的：中景和近景加一点竖向的动态模糊，近景多一点。

**为什么是这个顺序**：雪景的空间感主要靠远景的密度，所以先铺远景，看够不够"下雪"，再加前面两层。

:::warn 这类照片容易翻车的地方
- 雪是纯白、不透明的大圆点，像一张白点贴纸：远景小、近景糊，不透明度都不要拉到上限 100%。
- 雪点的大小都一样：尺寸抖动至少开到 50%。
- 背景天空本来就很白，白雪看不出来：把雪画在树、人物、深色衣服的前面，白雪在深色上才显眼。
:::
