## 先弄懂：褶皱是怎么来的 {#why}

### 布料受力，就会起褶 {#why-force}

布是软的，自己撑不住形状。穿在身上时，它在几个地方受力：

- **挂住的地方**：肩膀、胸口最高点、胯骨。布从这里往下垂。
- **被挤的地方**：手肘内侧、腋下、膝盖后面、弯腰时的腰侧。关节一弯，这一侧的布被挤到一起，堆出一道道褶。
- **被拉的地方**：抬手时从腋下拉到腰、跨步时从胯拉到膝。布被两个点扯着，中间出现斜着走的拉扯褶。

所以**结构褶都有方向**：从受力点放射出来，或者在两个受力点之间拉直。看一道褶指向哪里，就知道是身体的哪个动作造成的。

### 三种褶：留哪些、去哪些 {#why-types}

![三种褶皱](diagrams/m5/p-folds.svg "左：结构褶从受力点放射。中：乱褶短、方向乱、堆在一起。右：死褶笔直、成格子，和身体无关")

| 类型 | 怎么来的 | 样子 | 处理 |
|---|---|---|---|
| 结构褶 | 关节弯曲、抬手跨步 | 有方向，指向手肘、腋下、胯、膝盖 | **留**。它说明了动作和身体的体积，去掉衣服就像贴纸 |
| 乱褶 | 衣服没拉平、扎进裤子里堆的、坐下压的 | 短、方向乱、成堆 | 去掉，或者减弱到看不出 |
| 死褶 | 叠放、收纳时压出来的折痕 | 笔直、成格子、横竖交叉 | 去掉 |

**判断口诀**：这道褶能不能用身体的动作解释？能，就留；不能，就去。拿不准的，减弱一半，不要全去。

### 修褶，修的是明暗 {#why-tone}

![一道褶的明暗起伏](diagrams/m5/p-softlight.svg "横切一道褶：一边是凸起的亮棱，一边是凹下去的暗沟。白色提亮暗沟、黑色压暗亮棱，起伏就变小了")

一道褶在照片上就是**一条暗沟加旁边一条亮棱**。布料本身的织纹、印花，是叠在这层明暗起伏上面的细节。

所以有两种修法：

- **改明暗**：把暗沟提亮、把亮棱压暗，起伏变平，褶就不见了。织纹没被碰过，所以一点都不会糊。这是本课的主要方法。
- **克隆**：用别处的布直接盖掉。适合又细又硬的压痕和线头。面积一大，容易出现重复的图案、或者把织纹抹糊。

改明暗用的是「柔光」图层：在「柔光」层上，**白色让下面变亮，黑色让下面变暗，透明的地方不变**。它比「覆盖」柔和，一笔一笔叠，容易控制。原理和 [4.4 课](lesson:m4-04)的加深减淡一样。

### 道具为什么显得假 {#why-prop}

![塑料和金属](diagrams/m5/p-material.svg "左：塑料的高光大而软，整体对比低。右：金属对比强，高光又细又亮，暗部很深")

cos 道具多数是 EVA 泡沫、树脂、塑料做的，假在两个地方：

1. **做工痕迹**：拼接缝、胶水溢出来的亮斑、喷漆的刷痕。
2. **质感**：塑料表面把光散开，高光是一大片软软的亮；金属表面像镜子，会映出周围的环境，所以**明暗对比很强**，暗部很深、高光又细又亮，而且**边缘特别容易亮**（边缘的弧面正好把光反射到镜头里）。

所以把塑料修成金属，就是：拉大对比、降一点饱和度、在朝光的边缘加细高光。

## 动手前：复制原图 {#prepare}

先按 [5.4 课「动手前」](lesson:m5-04#prepare)复制并锁定原图，上面那层改名叫「修补」。

## 第 1 步：用黑白观察层看清褶皱 {#gray}

:::step 加一层黑白观察层
1. 点「+」在最上面新建一层，改名为「观察（看完删）」。
2. 颜色面板里选纯黑色。在这层上轻点两次打开「图层选项」，点「填充图层」，画面变成全黑。
3. 点这层右边的字母（N），混合模式选「颜色」。

![黑白观察层](diagrams/m5/u-gray-view.svg "填充黑色，模式改成颜色，画面就变成黑白的")

看到：整张照片变成黑白。衣服上哪里亮、哪里暗，比彩色时清楚得多。
:::

:::why 为什么要先看黑白
颜色会干扰判断。一件红衣服，暗沟里偏暗红、亮棱上偏粉红，看着像是颜色不均，其实是明暗不平。去掉颜色以后，只剩明暗，每道褶在哪、有多深一目了然。这层在修的过程中可以随时点右边的勾选框开关。
:::

:::step 标出要留和要去的褶
1. 在「观察」层下面新建一层「标记」。
2. 用任意细笔，绿色圈出要留的结构褶（手肘、腋下、腰侧这些），红色圈出要去的乱褶和压痕。
3. 标完把「标记」层隐藏，修的时候随时打开看。

看到：画面上有几个绿圈和红圈，你心里清楚哪里要动、哪里不动。
:::

## 第 2 步：用柔光图层拉平乱褶 {#softlight}

:::step 新建柔光层
1. 选中「修补」层，点「+」，在它上面新建一层，改名为「褶皱明暗」。
2. 点这层右边的字母，混合模式选「柔光」。图层不透明度保持默认的 100%，深浅靠笔刷的不透明度控制。

![新建柔光层](diagrams/m5/u-softlight.svg "图层从下往上：原图、修补、褶皱明暗（柔光）")

看到：图层右边的字母变了。画面没有变化，因为这层还是空的。
:::

:::step 白色涂暗沟，黑色涂亮棱
1. 点画笔图标，选「气笔修饰」里的「软画笔」。尺寸调到和要修的那道褶差不多宽。
2. 左边侧栏下面的滑块（不透明度）从 5% 左右开始：一笔下去几乎看不出变化才对，靠多叠几笔加深，一般不超过 10%。
3. 颜色选纯白，在**暗沟**里顺着褶的方向涂。
4. 颜色换成纯黑，在**亮棱**上顺着方向涂。
5. 一笔不够就再叠一笔。每涂几笔，打开「观察」层看一眼黑白，直到那道褶的明暗和周围差不多。

![白色提亮暗沟、黑色压暗亮棱](diagrams/m5/u-dodge-burn.svg "不透明度 5%～10%，顺着褶的方向一笔一笔叠")

看到：黑白状态下，乱褶那一片变得平了，明暗是连续的；布料的织纹和印花一点没变。
:::

:::step 笔触明显就稍微模糊一下
涂完放大看，如果能看出一条条笔触的边，在「褶皱明暗」层上打开 [[调整 > 高斯模糊]]，手指往右滑一点，2%～4% 一般就够。这层只有明暗，模糊它不会让布料变糊。

看到：涂过的地方过渡柔和，看不出一笔一笔的痕迹。
:::

:::warn 易错
- 涂到了结构褶上：随时打开「标记」层看，绿圈里不动，最多减弱一点。
- 只用白色提亮、不用黑色压暗：整片衣服会越修越亮、越来越灰。暗沟和亮棱要一起修。
- 不透明度太高：一笔就是一块亮斑。宁可从 5% 左右开始，多叠几次。
- 一次想把褶全部抹平：衣服会变成一块平板。留一点很浅的起伏，看起来更真实。
:::

## 第 3 步：用克隆去死褶、线头、拉链 {#clone}

:::step 压痕：顺着纹理方向克隆
压痕又细又硬，用柔光拉平以后常常还剩一条细线：

1. 点「修补」层，打开 [[调整 > 克隆]]，画笔用「气笔修饰」里的「中等画笔」。
2. 圆盘放在压痕**旁边**，沿着布料的纹理方向挪开一点（有条纹的布，就挪一两条条纹的距离，让条纹对得上）。长按锁定。
3. 画笔尺寸比压痕稍宽，沿着压痕涂。

![克隆去线头和压痕](diagrams/m5/u-fabric-clone.svg "取样点沿着条纹方向错开，条纹对上了接缝就看不出来")

看到：压痕没了，条纹或织纹从上到下是连着的。
:::

:::step 线头、露出来的拉链和魔术贴
- **线头**：克隆，圆盘放在紧挨着线头的布上，画笔尺寸调小，点涂。
- **拉链、魔术贴、别针**：先用克隆把它们盖成布料，再回到「褶皱明暗」层，按原来的褶皱走向补一点明暗，免得那一块平得发亮。

看到：衣服上只剩设计里本来就有的东西。
:::

:::why 什么时候用克隆，什么时候用柔光
看要去掉的东西是**明暗**还是**形状**。褶皱只是明暗起伏，用柔光；线头、拉链、压痕的硬边是多出来的形状，改明暗去不掉，只能用克隆盖。
:::

## 第 4 步：道具的接缝和胶痕 {#seam}

:::step 把道具单独复制一层
1. 点「修补」层，点选取工具，底部选「手绘」。
2. 沿着道具的外轮廓一下一下地轻点，每点一下就多一个节点，节点之间用直线连起来；弧形的边就按住拖着画。最后轻点起点那个灰色小圆圈，选区就闭合了。
3. 点「拷贝并粘贴」，把新图层改名为「道具」。

![手绘选取道具](diagrams/m5/u-prop-sel.svg "沿外轮廓点出折线，拷贝并粘贴成单独一层")

看到：图层面板里多了「道具」层。只开这一层时，画面上只有道具。
:::

:::why 为什么要单独一层
克隆只从当前图层取样。在「道具」层上克隆，取到的只有道具本身，不会把背景或衣服带进来；后面做质感时用的曲线、剪辑图层，也只作用在道具上。
:::

:::step 胶痕：克隆盖掉
在「道具」层打开 [[调整 > 克隆]]。道具表面一般有明暗渐变，所以圆盘要放在胶痕旁边、**同样亮**的位置（沿着渐变的等高线挪），锁定后点涂。

看到：亮亮的胶斑不见了，表面的明暗过渡没有被打断。
:::

:::step 接缝：沿着缝的走向克隆
1. 画笔换成「气笔修饰」里的「中等硬画笔」，道具的边缘比布料硬。
2. 圆盘放在缝的一侧，离缝 1～2 毫米，锁定。
3. **沿着缝**一段一段涂。缝很长的话，每涂一段就换一次取样点，取样点和缝保持同样的距离。
4. 涂完那一条如果比两边亮或暗，在「道具」上面建一层剪辑蒙版的「柔光」层，像第 2 步那样用白、黑补平。

看到：放大到 100% 也看不出缝在哪。
:::

:::tip 设计上就有的分片线要留
盔甲、机甲本来就是一片一片的，片与片之间的分界是设计的一部分，不要修。要修的是**同一片上**不该有的缝。
:::

## 第 5 步：让塑料看起来像金属 {#metal}

:::step 用曲线拉大对比
1. 点「道具」层，打开 [[调整 > 曲线]]。
2. 在曲线靠左下的地方加一个点往下压，靠右上的地方加一个点往上提，拉成一个 S 形。暗的更暗、亮的更亮。
3. 拉到表面的明暗差别明显变大就停，一般比你觉得"够了"再多一点。

![曲线拉成 S 形](diagrams/m5/u-prop-curves.svg "暗部点往下、亮部点往上")

看到：道具的明暗对比变强了，没那么"软"了。
:::

:::step 调饱和度和颜色
打开 [[调整 > 色相、饱和度、亮度]]：

- **银色、铁色**：饱和度往左拉一点，去掉塑料的颜色感，看起来更冷、更硬。
- **金色、铜色**：饱和度不动或稍微加一点；色相往黄、往橙挪。
- 50% 是默认的"不变"位置，往左减、往右加。

看到：颜色更接近你要的金属，不再像喷了漆的塑料。
:::

:::step 剪辑一层暗部、一层高光
1. 在「道具」上面新建「金属暗部」，设成剪辑蒙版，模式「正片叠底」。用比道具深得多的颜色和「软画笔」，不透明度从 20% 左右开始，在道具**中间偏背光的一条**涂一道深色的带子，带子明显变深、旁边还留着亮面就停。金属会映出周围暗的环境，所以中间常有一道很深的暗部。
2. 再建「金属高光」，剪辑蒙版，模式「添加」。用「着墨」里的「技术笔」，颜色选浅色（银色用浅灰白，金色用浅黄），沿**朝着光的那条边**画一条细线。画到头停住不抬笔，线会变直（速创形状）。
3. 铆钉、转角这些凸起的地方，用同一支笔点一个小亮点。

![金属的暗部层和高光层](diagrams/m5/u-prop-hl.svg "两层都剪辑到道具上：暗部正片叠底，高光添加")

看到：道具中间有一道深色、边缘有一条细亮线，铆钉上有小亮点，看起来像是硬的、会反光的东西。
:::

:::warn 易错
- 高光画得到处都是：变成了镜面镀铬，像玩具。只在朝光的边缘和凸起处画。
- 暗部涂满了整块道具：看起来是黑色塑料。暗部只是一条带子，旁边要留出亮的部分。
- 高光画在背光的一侧：和人身上的光方向矛盾，一眼假。先看人脸哪边亮。
- 想做旧金属、铁锈：可以在剪辑图层上叠一点杂色，见 [2.4 课](lesson:m2-04)。
:::

## 修完检查 {#check}

:::check 怎么判断做对了
- 打开黑白观察层：衣服的明暗是平顺的，结构褶还在，没有亮斑和暗斑。
- 关掉观察层，放大到 100%（捏合缩放时屏幕上方会显示百分比），应该看到：布料的织纹连续，没有重复的图案，也没有糊掉的一块。
- 道具放大到 100%，看到的表面没有缝和胶痕。
- 缩小到手机大小：衣服看起来平整但仍然有体积，道具看起来是金属（或者至少不是一眼塑料）。
- 删掉「观察」和「标记」两层再导出。
:::

## 三个完整案例 {#cases}

### 案例一：制服衬衫，腰部乱褶和胸口压痕 {#case-shirt}

:::compare
before: diagrams/m5/case-shirt-before.svg | 修之前：腰上堆了乱褶，胸口有一横一竖两道压痕
after: diagrams/m5/case-shirt-after.svg | 修之后：乱褶和压痕去掉，手肘和腋下的褶留着
:::

**照片情况**：半身照，浅色制服衬衫。衬衫下摆扎进裤腰时没拉平，腰上堆了一圈乱褶；衣服是从包装里拿出来直接穿的，胸口有一横一竖两道压痕。右手弯着放在胸前。

**诊断**：腰部的乱褶和胸口的压痕都不能用动作解释，去掉；手肘内侧的三道褶和腋下的斜褶是弯手臂造成的，留着。

**修法和数值**（这张示范照片的数值，你的照片会不同，按画面判断）：

1. 观察层看黑白，在「标记」层圈出：绿圈两处（手肘、腋下），红圈三处（腰、胸口横线、胸口竖线）。
2. 「褶皱明暗」柔光层，「软画笔」不透明度 8%，腰部乱褶白色提暗沟、黑色压亮棱，每道褶来回叠了 4～6 次，直到黑白下看不出起伏。完成后高斯模糊 3%，看不出笔触就停。
3. 胸口压痕柔光拉平以后还剩一条细硬线，用克隆补：「中等画笔」，取样点沿压痕方向错开约 1 厘米。
4. 手肘的三道褶完全没动，腋下那道颜色有点脏，柔光层上黑色轻扫一遍，加深了一点点。

**为什么是这个顺序**：先柔光后克隆。柔光拉平以后，剩下要克隆的只是一条细线，克隆的面积小，不容易出现重复和糊。

:::warn 这类照片容易翻车的地方
- 浅色衬衫的暗沟一提亮就发灰：白色的不透明度再低一点，多涂几次。
- 腰部的乱褶全抹平以后，腰那一截像一块平板，和手肘的褶对比太强：留一两道很浅的横向起伏。
- 扣子旁边的门襟本来就有一条线，别当成压痕修掉。
:::

### 案例二：EVA 护板的拼接缝和胶痕 {#case-seam}

:::compare
before: diagrams/m5/case-seam-before.svg | 修之前：护板中间一道拼接缝，旁边有三块胶痕
after: diagrams/m5/case-seam-after.svg | 修之后：接缝和胶痕看不出来
:::

**照片情况**：手臂上的灰色护板，用两块 EVA 拼起来，中间一道缝，缝旁边溢出的胶干了以后发亮。

**诊断**：这道缝把同一块板分成了两半，不是设计上的分片线，要修。胶痕是亮斑，用克隆。

**修法和数值**（这张示范照片的数值，你的照片会不同，按画面判断）：

1. 「手绘」选取护板，「拷贝并粘贴」成「道具」层。
2. 胶痕：克隆，「中等硬画笔」，取样点放在胶痕旁边同样亮的位置，三块分别取样。
3. 接缝：克隆，取样点在缝的左边 1.5 毫米处，沿缝分三段涂，每段换一次取样点。
4. 缝两侧本来一边亮一边暗，克隆完中间有一条比两边都亮的带子。在「道具」上建剪辑的柔光层，黑色、不透明度 6%，压了两遍，直到那条带子和两边一样亮。

**为什么是这个顺序**：先去胶痕，再修缝。胶痕就在缝旁边，先修缝的话，取样时容易把胶痕一起取进来，复制到别处。

:::warn 这类照片容易翻车的地方
- 缝是斜的或者弯的，取样点一直不换：越涂越偏，补出来的表面会有一条歪的纹理。每一段都要重新放取样点。
- 护板上有印花或刻线，克隆把它也盖掉了：印花经过的地方要单独取样，让印花接上。
- 修完只在 100% 看了，没缩小看：缩小后能看到一条颜色不一样的带子，就是第 4 步没做。
:::

### 案例三：塑料喷漆护板，改成金属质感 {#case-metal}

:::compare
before: diagrams/m5/case-metal-before.svg | 修之前：灰色喷漆，一看就是塑料
after: diagrams/m5/case-metal-after.svg | 修之后：对比拉开、边缘有细高光，像金属
:::

**照片情况**：同一块护板，接缝修好以后，整体还是灰灰的一片，高光是中间一大块软的亮，像玩具。角色设定里是银色金属。

**诊断**：典型的塑料质感：对比低、高光大而软。需要拉对比、降饱和、加暗部带和边缘高光。

**修法和数值**（这张示范照片的数值，你的照片会不同，按画面判断）：

1. 「道具」层曲线：左下点（约 25% 处）往下压到 15%，右上点（约 75% 处）往上提到 88%，拉成 S 形。
2. 色相、饱和度、亮度：饱和度从默认的 50% 拉到 40%，颜色更冷。
3. 「金属暗部」：正片叠底，深灰蓝色，「软画笔」不透明度 35%，从左上到右下斜着涂一道带子，旁边还留着亮面就停。
4. 「金属高光」：添加，浅灰白，「技术笔」尺寸约 1%，沿朝光的上边缘画一条直线；四颗铆钉各点一个亮点；暗部带子旁边加了一条更细的亮线。
5. 缩小看，高光有点多，把「金属高光」不透明度降到 80%，缩小看高光只在边缘和铆钉上闪就停。

**为什么是这个顺序**：先用曲线和饱和度把整体变"硬"，再用剪辑层加细节。反过来的话，后做的曲线会把画好的暗部和高光一起拉，很难控制。

:::warn 这类照片容易翻车的地方
- 暗部带子和高光方向不一致（暗部是横的、高光是竖的）：金属的反射是一整片环境映上去的，暗部和亮部要大致平行。
- 人身上是暖光，金属上的高光却画成冷白：高光颜色要带一点环境光的颜色。
- 道具很小（比如戒指、耳饰）：只加边缘高光就够了，不要做暗部带。
:::

## 下次拍的时候 {#prevent}

| 做法 | 解决什么 |
|---|---|
| 出门前用挂烫机把衣服熨平，叠的时候卷起来不要折 | 死褶、压痕 |
| 衣服扎进裤腰后，抬一下手再往下拉平 | 腰部的乱褶 |
| 拍之前对着镜子把线头剪掉 | 线头 |
| 道具的缝用补土填平、打磨后再喷漆 | 接缝 |
| 金属道具用电镀漆或金属漆，拍时用侧光 | 塑料感 |
