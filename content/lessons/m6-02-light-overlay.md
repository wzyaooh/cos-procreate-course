网上的"光效素材"其实就是一张**黑底上画着光**的图。这节课自己画这种素材：在纯黑画布上用 Procreate 自带的「亮度」笔刷画，画完叠到照片上。学会了，以后看到任何黑底素材都知道怎么用。

:::tip 这节课的示意图
文中的界面图是按 Procreate 5 的布局画的示意图，不是真机截图，按钮的细节和位置以你 iPad 上的实际界面为准。
:::

:::tip 这节课的数字怎么用
步骤里的尺寸、不透明度、模糊百分比都是**起点值**：从写的数左右开始，看到每步写的效果就停，不用照抄。画笔尺寸的百分比在不同尺寸的画布上画出来的粗细不一样，以看到的粗细为准；高斯模糊这类百分比在像素大小不同的照片上效果也不一定一样，以画面为准。
:::

## 先弄懂 {#why}

### 为什么光要画在黑底上 {#why-black}

光效素材里真正有用的只有"哪里亮、亮多少、什么颜色"。黑色代表"这里没有光"。把光画在黑底上，再用一种**会让黑色失效**的混合模式叠到照片上，就只剩光留下来了。

### 「滤色」「添加」为什么能去掉黑底 {#why-blend}

![滤色和添加的计算](diagrams/m6/p-blend-math.svg "照片这里原来亮度 120。叠一个黑色像素，滤色和添加的结果都还是 120")

用一个通道、0～255 的亮度来算（0 是黑，255 是白）：

- **正常**：上面是什么就显示什么。光效层的黑色就会把照片盖成黑色，所以会看到黑框。
- **添加**：把上下两层的亮度**直接加起来**。黑色是 0，加 0 等于没加，所以黑色不起作用。亮的光加上去就更亮，超过 255 的部分全变成纯白。
- **滤色**：也是"只会变亮"，但算法是让两层都往白靠一点，结果永远不会超过白。黑色同样不起作用。

由此可以得出怎么选：

| | 添加 | 滤色 |
|---|---|---|
| 亮度 | 更亮、更冲，容易出现一片纯白 | 柔和，亮处不容易爆掉 |
| 适合 | 光的核心、强光、光剑、火、闪光 | 大面积的光束、光晕、雾光 |
| 拿不准时 | 先试滤色，不够亮再换添加 | |

手册里对两者的描述也是：「滤色」相当适合调亮图像或打造镁光效果；「添加」类似「滤色」和「颜色减淡」，但可以产生更强烈的效果。

### 为什么黑底必须是纯黑 {#why-pure}

![黑底要纯黑](diagrams/m6/p-graybg.svg "左：纯黑，叠上去只剩光。右：深灰（亮度 30），整块都被提亮了一点，边缘出现一圈框")

从上面的计算看：黑底只要不是 0，比如是 30 的深灰，滤色、添加以后**整块都会亮一点**，照片上就出现一个发灰的方框。所以新建素材画布时，背景颜色要**手动设成十六进制 000000**，不要凭眼睛选一个"看起来很黑"的颜色。

### 光的结构：核心 + 外晕 {#why-core}

![光的结构](diagrams/m6/p-core.svg "从中心往外，亮度一路下降；中间最亮的部分超过了相机能记录的最亮，就变成纯白")

真实的强光被相机拍下来，中心一定是**过曝的纯白**，因为它比相机能记录的最亮还亮。颜色只出现在亮度降下来的那一圈。所以一个可信的光，从中心往外分三段：

1. **核心**：白色或接近白，硬一点、小一点。
2. **内晕**：光的颜色最饱和的一圈。
3. **外晕**：同一个颜色，大而淡，慢慢消失在画面里。

只画一个带颜色的圆，没有白色核心，看起来就是"一个发光的贴纸"。「亮度」组的笔刷画出来本身就是中间偏白、边缘带色，就是这个原因。[6.3 课](lesson:m6-03)手绘光剑也按这三层来画。

### 光效要服从画面里的光源 {#why-direction}

![光效的方向](diagrams/m6/p-flare-axis.svg "左：镜头光斑排在光源和画面中心的连线上。右：光束从窗户照下来，影子也朝同一个方向")

- **光束**：从光源出发，越走越宽。窄头一定在光源那边。照片里人物的影子朝哪边，光就是往哪边走的，光束和影子方向一致。
- **镜头光斑**：是光在镜头的镜片之间反射出来的，所以一串光斑总是排在**光源 → 画面中心**这条线上，并延伸到画面对面。乱放的光斑一看就假。
- **颜色**：窗光、阳光偏暖白；夜里的路灯偏黄橙；霓虹、舞台灯可以是紫、蓝、粉。光效的颜色要和画面里的光源一致。

## 第 1 步：建一张纯黑的素材画布 {#canvas}

:::step 新建画布，背景设成纯黑
1. 回到图库，新建一张画布，尺寸和你的照片一样（不确定就用 3000 × 4000 像素）。
2. 打开图层面板，轻点最下面的「背景颜色」。
3. 颜色面板底部选「值」，在「十六进制」里填 000000。
4. 关掉颜色面板，在「图层 1」上画光。以后每画一种光，就点「+」新建一层，名字改成「光斑」「光束」这样。

![把背景颜色设成纯黑](diagrams/m6/u-black-canvas.svg "背景颜色 › 值 › 十六进制 000000")

看到：整张画布是纯黑的，图层面板最下面「背景颜色」的缩略图是黑色。
:::

## 第 2 步：用「亮度」笔刷画光 {#paint}

:::step 找到「亮度」笔刷组
点右上角的画笔图标，在画笔库左边的画笔组里往下找到「亮度」。手册的介绍是：这套画笔可创造一系列生动的光效，例如脉冲、星云、闪光和散景光等。先选「闪光」。

![亮度笔刷组](diagrams/m6/u-lum-lib.svg "画笔库 › 亮度 › 闪光")

看到：画笔库右边列出了亮度组的画笔，每支都有笔划预览。组里的画笔名字和顺序以你的版本为准。
:::

:::step 画四种光，每种一层
1. **光斑**（「闪光」）：选一个颜色，在画布上**轻点一下**，就出现一个带十字星芒的光点。画笔尺寸调大，光斑就大。
2. **散景**（「散景光」）：拖一笔，会沿路径散出一串大小不一的圆形光斑，像焦外的灯。
3. **光束**（「气笔修饰」里的「软画笔」，暖白色）：从一点画到另一点，画到底笔停住不抬，线会变直（速创形状）。笔刷尺寸从 20% 左右开始，以光束有你想要的宽度为准。画完用 [[调整 > 高斯模糊]] 从 10% 左右开始糊，看不出笔触边缘就停，或用 [[调整 > 透视模糊]] 把它拉成放射状。
4. **光环**（「浅色画笔」）：见下一张步骤卡。

![在黑底上画光](diagrams/m6/u-paint-lights.svg "闪光点一下；散景光拖一笔；光束用软画笔画直线再模糊；光环用浅色画笔画圈")

看到：黑底上有几种光，每种的中心都偏白，边缘带颜色。图层面板里每种光是单独的一层。
:::

:::step 用速创形状画正圆的光环
1. 选「浅色画笔」，在画布上画一个圈。画完**笔尖停住不抬**，大约一秒后会自动变成一个椭圆。
2. 笔还按着，用**另一根手指轻点画布**，椭圆会变成正圆。
3. 抬笔。画布上方出现「编辑形状」，点它可以拖节点微调。

![速创形状画正圆](diagrams/m6/u-ring-quick.svg "画圈停住变椭圆；另一指轻点变正圆")

看到：一个完美的正圆光环，中间细白、外面一圈带颜色的光。
:::

:::tip 先画一套"素材库"
把各种颜色、大小的光斑、光束各画几个，存成一个 .procreate 文件（比如叫「我的光效素材」）。以后修图需要时直接打开拷贝，不用每次重画。
:::

## 第 3 步：把光叠到照片上 {#import}

:::step 拷贝素材
1. 在素材画布上，只留下你要用的那一种光的图层可见（其他光的勾选框点掉），背景颜色保持可见。
2. 三指在画布上往下拖，弹出「拷贝并粘贴」菜单，点「全部拷贝」：所有可见图层会合成一张平面图拷贝下来，黑底和光在一起。

![全部拷贝](diagrams/m6/u-copy-all.svg "三指下拖 › 全部拷贝")

看到：画面上方短暂出现提示，没有其他变化。
:::

:::step 粘贴进照片，改成滤色或添加
1. 回到图库，打开照片。
2. 三指下拖，点「粘贴」。黑底素材会作为一个新图层出现，此时是一大块黑色盖在照片上。
3. 打开图层面板，点这一层右边的字母 N，混合模式先选「滤色」。不够亮再换「添加」。

![改成滤色](diagrams/m6/u-paste-screen.svg "点 N › 滤色；黑色马上消失")

看到：黑色全部消失，只剩光留在照片上，没有任何方框。
:::

:::warn 叠上去以后出现灰框
- 素材的黑底不是纯黑：回到素材画布，按[第 1 步](#canvas)把背景颜色改成 000000，重新拷贝。
- 模式还是「正常」：改成「滤色」或「添加」。
- 用了别人的素材，黑底有压缩出来的杂色块：给这一层加 [[调整 > 曲线]]，把左下角的点往右拖一点，让接近黑的颜色都变成纯黑。
:::

## 第 4 步：让光跟着光源走 {#fit}

:::step 用变换摆方向
1. 选中光效层，点左上角的箭头图标（变换工具）。
2. 先用「等比」缩放到合适大小，一指拖动到光源附近。
3. 光束换成「扭曲」：拖四个角的蓝点，**窄的一头对准光源**（窗户、路灯），宽的一头落到人物和地面上。
4. 地面上的光环、光圈要压扁：用「扭曲」把它压成椭圆，扁的程度和地面的透视一致（看地砖、台阶有多扁）。
5. 底部「插值」选「双立体」，拉伸后边缘更平滑。

![用扭曲摆光束](diagrams/m6/u-distort.svg "扭曲：窄头对准窗户，宽头落到地上")

看到：光束看起来是从窗户照进来的，方向和人物影子的方向一致。
:::

:::step 用蒙版擦掉多余的部分
1. 在光效层上轻点两次，「蒙版」。
2. 选中蒙版，用黑色「软画笔」，不透明度从 30% 左右开始（一下擦太狠，光会出现一道断口），擦掉：
    - 盖在脸上、眼睛上的光；
    - 光束跑出画面主体以外、显得太长的末端；
    - 应该被人挡住的部分（光从人背后来，人身上不该有光束穿过）。
3. 擦多了换白色涂回来。

![用蒙版擦掉多余的光](diagrams/m6/u-mask-light.svg "黑色软画笔在蒙版上擦；擦错了用白色涂回来")

看到：光从光源照过来，经过人物时自然地变弱或被挡住，脸是干净的。
:::

## 第 5 步：调颜色和强度 {#tune}

:::step 让光的颜色和画面一致
1. 选中光效层（不是蒙版），打开 [[调整 > 色相、饱和度、亮度]]。
2. 「色相」往画面里光源的颜色推：窗光往黄橙推，夜里的霓虹往紫蓝推。
3. 「饱和度」不要太高，真实的光大多是带一点颜色的白。
4. 最后用图层面板里的**不透明度**调强弱，一般在 50%～80%。
5. 照片本身有点糊（手机夜景、远景），光效也用高斯模糊糊一点，从 2% 左右开始，和照片的清晰度对上就停。

![调光效的颜色](diagrams/m6/u-hsb-light.svg "色相往光源的颜色推，再用图层不透明度控制强弱")

看到：光和画面像是同一种光，不是"另外贴上去的一种颜色"。
:::

## 两个完整案例 {#cases}

### 案例一：窗边逆光，加光束和光斑 {#case-window}

:::compare
before: diagrams/m6/case-62a-before.svg | 修之前：窗户很亮，空气里看不到光
after: diagrams/m6/case-62a-after.svg | 修之后：光束从窗户照进来，光斑沿对角线排开
:::

**照片情况**：室内，左上角是一扇很亮的窗户，人站在画面右侧，脸朝窗户。整体偏暗，光感不够。

**诊断**：光源明确，在左上角；地上的影子朝右下，所以光往右下走。

**修法和数值**（这张示范照片的数值，你的照片会不同，按画面判断）：

1. 素材画布上用软画笔画三道宽窄不一的暖白光束，高斯模糊 15%，糊到光束边缘看不出笔触就停。全部拷贝，粘贴进照片，模式「滤色」。
2. 「扭曲」把三道光束的窄头收到窗户上，宽头落到人物脚下的地面。
3. 素材画布上用「闪光」点一个光斑，再画三四个淡的小圆（散景光或软画笔）。粘贴进照片，模式「添加」。主光斑放在窗户角上，小圆沿**窗户 → 画面中心 → 右下角**这条线排开。
4. 光束层加蒙版，擦掉盖在脸上的部分。
5. 色相往暖黄推一点，光束层不透明度 70%，光斑层 80%，光感有了、人没被冲白就停。

**为什么是这个顺序**：先摆光束定好方向，光斑才知道排在哪条线上；蒙版最后擦，因为摆位置时光束会移动。

:::warn 这类照片容易翻车的地方
- 光束方向和影子方向不一致：先看照片里的影子再摆。
- 光斑乱放，不在一条线上：用速创形状画一条从光源到对角的辅助线，放完再删。
- 光束太亮把人冲白：用「滤色」，降低不透明度，脸上用蒙版擦。
:::

### 案例二：夜景举手，加光球和散景 {#case-night}

:::compare
before: diagrams/m6/case-62b-before.svg | 修之前：夜景举手，手里什么都没有
after: diagrams/m6/case-62b-after.svg | 修之后：手上光球 + 手腕光环 + 背景散景
:::

**照片情况**：夜景，人物举起一只手，像在召唤什么，但手里是空的。

**诊断**：需要一个"光源"放在手上，再让背景有一点灯光的散景，夜景就不空了。

**修法和数值**（这张示范照片的数值，你的照片会不同，按画面判断）：

1. 素材画布：「闪光」在中心点一个淡紫色的大光斑；新建一层用「浅色画笔」+ 速创形状画一个正圆光环。
2. 光斑粘贴进照片，模式「添加」，放在掌心上方一点。
3. 光环粘贴进照片，模式「添加」，「扭曲」压扁成椭圆，套在手腕上；手腕前面那半圈保留，后面被手挡住的半圈用蒙版擦淡。
4. 另一张素材画「散景光」：暖黄和粉紫两种颜色各拖一笔。粘贴进照片，模式「滤色」，放在人物后面的背景上，高斯模糊 5%，糊到和背景的虚化程度一样就停（背景是焦外，要糊）。
5. 散景层用蒙版擦掉落在人物身上的部分，它在人后面。

**为什么是这个顺序**：先放主光（光球）定下画面最亮的点，散景是配角，最后加，亮度不能超过光球。

:::warn 这类照片容易翻车的地方
- 光球很亮，人和手却是暗的，像贴上去的：这节课先把光加对，人物身上的光在 [6.5 课](lesson:m6-05)补。
- 散景盖在人身上：散景是背景里的灯，必须在人后面。
- 光环套在手腕上没有前后关系，像一张圆形贴纸：后半圈一定要擦淡。
:::
