## 先弄懂：克隆在做什么 {#why}

### 圆盘跟着笔走，距离不变 {#why-offset}

![克隆的取样原理](diagrams/m2/p-clone-offset.svg "圆盘是取样的地方，笔尖是画的地方，两者的距离和方向一直不变")

打开克隆以后，画面上有一个带十字的小圆盘，它是**取样的地方**；你用笔涂的地方，就是**画上去的地方**。笔一落下，Procreate 就记住圆盘和笔尖之间的距离和方向：笔往右走一厘米，圆盘也往右走一厘米，把它经过的像素原样画到笔尖下面。

所以克隆复制的不是"圆盘里那一小块"，而是**圆盘走过的那一整条路径**。理解了这一点，后面几条规矩就都好懂了。

### 取样点为什么不能太近，也不能太远 {#why-distance}

![取样距离](diagrams/m2/p-clone-near.svg "太近：同一个图案重复；合适：同一条明暗带上隔开一点；太远：明暗颜色对不上")

- **太近**：笔往圆盘那边涂的时候，圆盘会走进你**刚刚补过的地方**，把刚画上去的像素再复制一遍。结果是同一小块纹理一排排地重复出现，缩小看像印章。圆盘离得太近还容易直接取到瑕疵本身。
- **太远**：脸是立体的，离光近的地方亮、侧面暗。从脸侧面的暗处取样补到颧骨的亮处，就会补出一块深色的斑。
- **合适**：取样点和瑕疵在**同一条明暗带**上（离光源差不多远、皮肤朝向差不多），隔开 **2～4 个瑕疵的宽度**（经验值：补出了重复图案就挪远一点，补出了深浅不一样的斑就挪近一点）。修一片区域时，每修几处就换一次取样点，同一块皮肤不要用太多次。

### 锁定和不锁定 {#why-lock}

![锁定和不锁定](diagrams/m2/p-clone-lift.svg "左：不锁定时，抬笔后圆盘停在上一笔的终点；右：锁定后每一笔都从同一个点开始")

- **不锁定**（默认）：圆盘跟着上一笔走到哪就停在哪。抬笔以后换个地方再落笔，取样位置已经变了，**纹理就接不上**。所以修布料条纹、地砖、头发边这种有方向的纹理时，**一段尽量一笔涂完**，中途不要抬笔。
- **锁定**：长按圆盘，它会放大一下，顶部提示已锁定。以后每一笔都从这个固定的点开始取样。适合**点修很多个小瑕疵**：每次都用同一块干净皮肤，不用每修一处就拖一次圆盘。缺点是用多了，同一块皮肤会被印到很多地方。

### 克隆只在当前图层里取样 {#why-layer}

克隆只能取到**当前选中的那一个图层**的像素，也只画在这一层上。这带来两个结果：

1. **不能在空白的新图层上克隆**。新图层里什么都没有，取到的也是空的。所以要先把原图复制一层，在副本上修。
2. 如果人物已经单独抠在一层上（2.5 课），在人物层上克隆就只能取到人物，取不到背景；补背景要切到背景层去做。

### 用什么笔刷，强度多少 {#why-brush}

克隆可以用画笔库里的任何一支笔，笔的形状决定补上去的那一块边缘是什么样：

| 修什么 | 用什么笔 | 为什么 |
|---|---|---|
| 皮肤上的痘痘、斑点 | 「气笔修饰」里的「软画笔」 | 边缘是渐变的，补上去的皮肤和周围融在一起，看不出圆圈 |
| 布料边、道具边、地砖缝旁边 | 硬边的笔，比如「着墨」里的「技术笔」 | 软边会把边缘的线条糊掉；硬边能贴着线修 |

「强度」决定补上去的那一块有多不透明：

- **100%（上限）**：完全盖住，去痘痘、污渍、杂物用这个。
- **30%～60%**（经验起点值，从 40% 左右开始，看到瑕疵淡到"还在、但不抢眼"就停）：半透明地叠上去，用来**淡化**而不是去掉，比如黑眼圈、法令纹、衣服上的折痕（这些留一点才自然，[4.3 课](lesson:m4-03)细讲）。

## 动手前：复制一层 {#prepare}

:::step 在副本上修
1. 打开图层面板，在原图上向左轻滑，点「复制」；再在原图上向左滑，点「锁定」。
2. 点副本，再点一次，「重命名」为「克隆 去瑕疵」。确认它是蓝色高亮的当前图层。

![在副本上克隆](diagrams/m2/u-clone-layer.svg "复制原图，锁住原图，在副本上克隆")

看到：两层，下面的原图带锁头；当前图层是「克隆 去瑕疵」。
:::

## 第 1 步：打开克隆，放好圆盘 {#start}

:::step 进入克隆，放圆盘
1. 两指捏开把画布放大，让痘痘在屏幕上有指甲盖那么大。放大才能看清边缘，也能把画笔尺寸设得准。
2. 打开 [[调整 > 克隆]]，画面中间出现带十字的圆盘。
3. 用手指把圆盘拖到痘痘**旁边**干净的皮肤上：同一条明暗带，隔开 2～4 个痘痘宽。
4. 底部「画笔尺寸」调到比痘痘大一圈，大约是痘痘的 1.5 倍；「强度」先用 100%。
5. 用 Apple Pencil 在痘痘上轻轻点一两下，或者涂一个小圈。

![放圆盘、涂瑕疵](diagrams/m2/u-clone-disc.svg "圆盘放在旁边干净的皮肤上，笔涂在痘痘上；底部两个滑块")

看到：痘痘被旁边的皮肤盖住，补上去的那一块颜色、明暗和周围一样，边缘看不出圆圈。
:::

:::warn 易错：补出了一块颜色不一样的圆
- 补的那块比周围深：取样点在更暗的地方，比如更靠近脸的侧面。把圆盘挪到和瑕疵一样亮的位置。
- 能看出一个圆圈的边：笔是硬边的，换软画笔（下一步）。
- 补上去的地方特别光滑：取样的那块皮肤本身磨过皮或者有点糊，换一块有纹理的地方取样。
:::

## 第 2 步：换成软画笔 {#brush}

:::step 选克隆笔刷
1. 在克隆界面里，点右上角的画笔图标，打开画笔库。
2. 选「气笔修饰」里的「软画笔」。
3. 回到画布继续涂。这时候画笔图标代表的就是"用哪支笔来克隆"，不会变成普通画画。

![选克隆笔刷](diagrams/m2/u-clone-brush.svg "在克隆界面里点画笔图标，选软画笔")

看到：再补一处，补上去的那块边缘是渐变的，和皮肤融在一起。
:::

## 第 3 步：点修一片小瑕疵：锁定圆盘 {#lock}

:::step 锁定取样点
1. 把圆盘放在一块面积大一点、干净的皮肤上，比如颧骨下面一片没有痘痘的地方。
2. **手指按住圆盘不放**，等它放大一下，顶部提示克隆已锁定，松开。
3. 依次点修附近的痘痘：每一笔都从这块干净皮肤开始取样。
4. 修完这一片（五六处），长按圆盘解锁，挪到下一片区域重新取样、重新锁定。

![锁定圆盘](diagrams/m2/u-clone-lock.svg "按住圆盘，等它放大一下就锁定了；再长按一次解锁")

看到：附近的几处痘痘都去掉了，不用每修一处就挪一次圆盘。
:::

:::why 为什么一片只修五六处就要换取样点
锁定以后，每一笔都复制同一块皮肤。修的次数多了，同一个毛孔、同一颗小痣会出现在脸上好几个地方，缩小看就像图章。换取样点就是为了让补上去的皮肤都不一样。
:::

## 第 4 步：修有纹理的地方：不锁定，一笔到底 {#texture}

布料、地砖、木纹、头发边这些地方有方向，修的时候要让纹理接得上。

:::step 顺着纹理一笔涂完
1. 长按圆盘解锁。
2. 把圆盘放在**同一条纹理线上**、离污渍有一段距离的地方。修布料上的污渍，就放在同一道褶皱的上方或下方；修地砖缝旁边的纸屑，就放在同一排地砖的另一块上。
3. 笔尖落在污渍的一头，**顺着纹理的方向**一笔涂到另一头，中途不抬笔。
4. 画笔尺寸只比污渍宽一点。贴着布料边、地砖缝修的时候，换成硬边的笔，例如「着墨」里的「技术笔」。

![顺着纹理修](diagrams/m2/u-clone-texture.svg "圆盘放在同一道褶皱上，从污渍一头顺着褶皱一笔涂到另一头")

看到：污渍去掉，褶皱的明暗、地砖缝的直线在补过的地方是连着的。
:::

:::warn 易错：纹理断了或错位了
- 中途抬了笔，第二笔接不上：两指轻点撤销，重新一笔涂完。
- 地砖缝补完歪了一点：取样点不在同一排上。斜线（透视的地砖缝）要沿着斜线的方向找取样点，不是水平移过去。
:::

## 第 5 步：修完检查 {#check}

:::step 三种方法检查
1. **两指快速捏合**，让画布缩回全图大小，看有没有同一个图案出现两次以上。
2. [[操作 > 画布 > 水平翻转画布]]，换个方向再看一遍，看完翻回来。
3. 在图层面板里反复点「克隆 去瑕疵」的勾选框，和原图来回对比。

看到：第一眼看不出哪里修过。
:::

## 三个完整案例 {#cases}

### 案例一：近景大头照，脸上有 8 处痘痘 {#case-acne}

:::compare
before: diagrams/m2/case-acne-before.svg | 修之前：8 处痘痘
after: diagrams/m2/case-acne-after.svg | 修之后：皮肤纹理还在
:::

**照片情况**：漫展上用手机近距离拍的半身照，左右脸颊各有几颗痘痘，额头一颗，下巴附近两颗痘印。

**诊断**：都是小而分散的点状瑕疵，周围皮肤干净，适合**锁定圆盘点修**。左右脸颊的亮度不一样（光从左边来），不能用同一个取样点。

**修法和数值**（这张示范照片的做法，你的照片数值会不同，按画面判断）：

1. 复制原图，副本改名「克隆 去瑕疵」，原图锁定。
2. 放大到痘痘有指甲盖大，软画笔，画笔尺寸约为痘痘的 1.5 倍，强度拉到上限（100%）。
3. 左脸：圆盘放在左颧骨下方一片干净皮肤上，长按锁定，点修左脸三颗。
4. 解锁，圆盘挪到右脸**同样亮度**的地方，重新锁定，点修右脸两颗。
5. 额头和下巴：分别在额头、下巴上就近取样，各自锁定再修。
6. 两颗痘印比较淡，强度降到 50% 左右，点一下淡化，看到痘印还留一点点痕迹就停，这样更真实。
7. 缩小看全图，水平翻转检查。

**为什么是这个顺序**：按区域分开修，每个区域用自己的取样点，明暗才对得上；先去明显的痘痘，最后才处理淡的痘印，强度单独调。

:::warn 这类照片容易翻车的地方
- 一个取样点修了整张脸：同一块皮肤被印到十几个地方，缩小看很假。每个区域换一次。
- 把雀斑、痣也一起修掉了：先问 coser，这些可能是人家想留的特征（[0.3 课](lesson:m0-03#brief)）。
- 修完皮肤还是不匀：那是肤色问题，不是瑕疵，用 [4.3 课](lesson:m4-03)的补肤色方法。
:::

### 案例二：白披风上的饮料渍，正好压在褶皱上 {#case-stain}

:::compare
before: diagrams/m2/case-stain-before.svg | 修之前：白披风上有一块饮料渍
after: diagrams/m2/case-stain-after.svg | 修之后：污渍去掉，褶皱的明暗连着
:::

**照片情况**：白色披风上有一块浅褐色的饮料渍，旁边还溅了两个小点，污渍正好压在一道竖向褶皱的阴影边上。

**诊断**：污渍下面有褶皱的明暗变化，点修会把褶皱补断。要**不锁定、顺着褶皱方向一笔涂**。

**修法和数值**（这张示范照片的做法，你的照片数值会不同，按画面判断）：

1. 复制原图，副本改名「克隆 披风污渍」。
2. 软画笔，画笔尺寸比污渍略宽，强度拉到上限（100%）。
3. 圆盘放在**同一道褶皱**正上方、离污渍约两个污渍高的地方，不锁定。
4. 笔尖从污渍上端落下，顺着褶皱往下一笔涂过污渍，不抬笔。
5. 两个小溅点：分别在旁边同样亮度的白布上取样，点修。
6. 褶皱阴影的边缘被糊了一点：换「技术笔」，尺寸调小，沿着阴影的边缘再取样补一笔。

**为什么是这个顺序**：先用软笔把大块污渍去掉，再用硬笔把被软笔糊掉的阴影边修利落。

:::warn 这类照片容易翻车的地方
- 从平整的白布上取样补到褶皱上：褶皱的阴影断了，看起来像贴了一块补丁。
- 白色布料上补出灰色的一块：取样点在阴影里了。白布的亮部和暗部差得很多，取样点一定要在同样亮的地方。
- 褶皱本身想去掉：那是另一类问题，用 [5.3 课](lesson:m5-03)的方法。
:::

### 案例三：全身照地上有地标胶带和纸屑 {#case-floor}

:::compare
before: diagrams/m2/case-floor-before.svg | 修之前：地上有地标胶带和纸屑
after: diagrams/m2/case-floor-after.svg | 修之后：胶带和纸屑去掉，地砖缝还是直的
:::

**照片情况**：漫展场地拍的全身照，地上有一段黄色地标胶带、一张小纸片、一个黑点。地砖缝是透视的斜线。

**诊断**：地砖有规律的格子，修错了很容易被看出来；胶带压在一条砖缝上，要连砖缝一起补回来。

**修法和数值**：

1. 复制原图，副本改名「克隆 地面」。
2. 胶带：先用软画笔、大一点的尺寸，在**同一排地砖**上旁边那块取样，不锁定，顺着胶带方向一笔涂掉胶带。
3. 砖缝被补断了：换「技术笔」，尺寸调到和砖缝差不多粗。圆盘放在同一条砖缝**沿着斜线方向**往前一段的地方，从缝的一头一笔描到另一头。
4. 纸片和黑点：就近在同一块地砖上取样，点修。
5. 缩小看全图：有没有两块地砖一模一样、挨在一起。

**为什么是这个顺序**：先去大块杂物，再修被破坏的直线。直线是最容易暴露的地方，单独用硬笔处理。

:::warn 这类照片容易翻车的地方
- 圆盘放得太近：同一块地砖的污点、反光被复制了一排。地面面积大，取样点可以离远一点，但要在同一排、同样亮。
- 砖缝补歪：水平移过去取样，斜线就对不上了。沿着线的方向找取样点。
- 要去掉的是整个路人、灯架：面积太大，用 [5.5 课](lesson:m5-05)的大面积修补方法。
:::

## 克隆不适合做的事 {#not-for}

| 问题 | 为什么克隆不合适 | 去哪里学 |
|---|---|---|
| 整片皮肤不匀、发红 | 克隆复制的是纹理，不改整体颜色 | [4.3 课](lesson:m4-03) |
| 一大片背景要换掉（路人、灯架） | 一点点克隆太慢，重复纹理很难避免 | [5.5 课](lesson:m5-05) |
| 假发上的碎发、杂毛 | 发丝很细很密，要配合涂抹和补画 | [5.1 课](lesson:m5-01) |
| 衣服乱褶 | 褶皱是明暗问题，要压平明暗 | [5.3 课](lesson:m5-03) |
