## 先弄懂：为什么修之前要先诊断 {#why}

![四步诊断各管什么](diagrams/m4/p-four-checks.svg "四步各管一类问题：整体、歪斜、明暗、颜色和细节")

新手最常见的修法是"看到哪里不顺眼就修哪里"：先去痘，修着修着发现肤色发黄，回头调色，痘印的颜色又对不上了。诊断就是在动手之前把问题一次找全，排好先后，避免来回返工。

### 眼睛会"看习惯" {#why-habit}

盯着一张图看几分钟，大脑就会把它当成"正常"的样子，歪的看成直的，偏黄的看成白的。放大修局部时更严重：你只看得到眼前那一小块，看不到它和整张图的关系。

所以诊断里的前两步，都是在**故意打破这种习惯**：

- **缩小看全图**：让你重新用"刷到这张图的路人"的眼光看它。别人在手机上看你的图，就是这么小、只看几秒。
- **水平翻转画布**：同一张图左右一翻，对大脑来说像是一张新图。原来看习惯的歪头、左右脸不一样大、身体往一边倒，一下就露出来了。Procreate 手册也专门提到，水平翻转画布是发现构图和比例问题的好方法。

### 为什么要单独看明暗 {#why-gray}

一张脸立不立体、干不干净，靠的是明暗：额头、鼻梁亮，脸颊外侧、下颌下面暗，脸才有体积（[3.1 课](lesson:m3-01)讲过三大面五大调）。可是彩色画面里，颜色会干扰你对明暗的判断，比如粉色假发和黄色灯光很抢眼，你就注意不到脸是平的。

把颜色去掉、只留明暗，这些问题就藏不住了：

- 脸是不是一整片同样的亮度（平光）
- 左右脸是不是一边亮一边暗（阴阳脸）
- 皮肤上有没有一块块深浅不一的斑（痘印、泛红、粉底不匀）
- 主体和背景是不是一样亮，人"浮"不出来

**灰度观察层**就是用来干这个的：一层黑色、模式设成「颜色」，下面整张图只剩明暗（原理见 [3.1 课](lesson:m3-01#gray)）。它不改动任何像素，关掉就恢复彩色，可以一直留在图层最上面随时开关。

### 为什么要对照设定图 {#why-ref}

cos 照片和普通人像不一样，修得好不好，有一半看"像不像这个角色"。漫展灯光会把假发、美瞳、服装的颜色都带偏，coser 的妆在照片里也常常被灯光吃掉。不放设定图在旁边比，很难判断"这个红是对的还是偏了"。

### 为什么要写清单、还要排顺序 {#why-list}

[0.3 课](lesson:m0-03#why-order)讲过整体流程的顺序：先调整体，再修细节。精修内部也是一样的道理：

1. **整体光和色先定**（[4.2 课](lesson:m4-02)）：曝光和白平衡一变，皮肤颜色、明暗关系都会跟着变。先修皮肤再调色，补过的颜色就对不上了。
2. **形要在细节之前**（[5.4 课](lesson:m5-04)、[4.5 课](lesson:m4-05#face)）：液化和变换会移动、拉伸像素。先去痘再液化，补过的地方会被拉变形。
3. **去穿帮在皮肤之前**（[5.5 课](lesson:m5-05)）：去路人、去灯架要大面积克隆，先做完，画面结构就定了。
4. **皮肤 → 光影 → 妆面**（[4.3](lesson:m4-03)、[4.4](lesson:m4-04)、[4.5](lesson:m4-05)）：皮肤干净了，才看得清原本的明暗；光影定了，修容、腮红才知道往哪放。
5. **角色色和特效最后**（[5.6 课](lesson:m5-06)、[M6](page:m6/)）：它们会改变局部的颜色和亮度，放在最后不用反复改。

## 动手前：复制并锁定原图 {#prepare}

方法和 [5.4 课](lesson:m5-04#prepare)一样：在原图层上向左轻滑，点「复制」；在下面那层（原图）上再向左滑一次，点「锁定」。诊断本身不改像素，但接下来要在图上画标记，原图锁住更安心。

## 第 1 步：缩小看全图 {#fit}

:::step 让画布适应屏幕，再缩到手机大小
1. 两指放在画布上**快速捏合**再松开，画布会自动缩放到正好占满屏幕。
2. 再用两指慢慢捏小，直到画面大约是手机屏幕那么大（竖图高度大约 12～15 厘米）。
3. 只看 3 秒，然后移开视线，马上写下第一眼注意到的 1～3 件事。不要分析，写感觉就行，比如"好黄""脸好平""头有点歪""背景好乱"。

![缩小看全图](diagrams/m4/u-fit.svg "两指快速捏合适应屏幕，再缩小到手机屏幕大小")

看到：画面缩成手机大小，你写下了第一眼的 1～3 个问题。
:::

:::why 为什么只看 3 秒
第一眼注意到的问题，就是别人刷到这张图时最先注意到的问题，优先级最高。看久了就会开始"找细节"，比如盯着一颗痘，反而忘了整张图偏黄这种大问题。
:::

## 第 2 步：水平翻转画布 {#flip}

:::step 翻转画布
1. 点左上角的扳手图标（操作），选「画布」。
2. 点「水平翻转画布」。
3. 翻转后同样先看 3 秒，再重点检查：头是不是往一边歪、两只眼睛是不是一样高一样大、嘴角是不是一边高、肩膀是不是一高一低、门框柱子这些竖线是不是歪。
4. 检查完，再点一次「水平翻转画布」翻回来。

![水平翻转画布](diagrams/m4/u-flip.svg "操作 › 画布 › 水平翻转画布")

看到：画面左右翻过来了。原来没注意到的歪斜、不对称，翻过来以后显得更明显。
:::

:::warn 易错：翻转以后忘了翻回来
翻转画布只是"换个方向看"，不影响导出的图。但你如果在翻转状态下修了半天，会搞不清左右，比如清单上写的"左眼"到底是哪只。约定一下：**清单里的左右，一律按没翻转时、你看画面的左右来写**。
:::

## 第 3 步：打开灰度观察层 {#gray}

灰度观察层的做法只在 [3.1 课第 2 步](lesson:m3-01#gray)讲：最上面新建一层、填纯黑、混合模式改成「颜色」，画面就变成黑白。每张要诊断的照片都照着做一层，放在图层面板**最上面**，点它右边的勾选框就能在彩色和黑白之间切换。

**在灰度里看什么**：

| 看哪里 | 有问题的样子 | 说明 | 去看 |
|---|---|---|---|
| 整张脸 | 一整片差不多的灰，看不出额头、鼻梁、颧骨哪里亮 | 平光，脸没有立体感 | [4.4 课](lesson:m4-04) |
| 左右脸 | 一边明显比另一边暗，交界很硬 | 阴阳脸 | [4.4 课](lesson:m4-04#case-messy) |
| 皮肤 | 一块块深色的点和斑，彩色里不太明显 | 痘印、泛红、粉底不匀 | [4.3 课](lesson:m4-03) |
| 眼周 | 眼睛下面一圈深灰 | 黑眼圈、眼线晕开 | [4.3 课](lesson:m4-03)、[4.5 课](lesson:m4-05) |
| 人和背景 | 人和背景一样亮，人"浮"不出来 | 主体不突出 | [4.2 课](lesson:m4-02)（局部调整） |
| 脖子和下巴 | 下巴和脖子连成一片 | 下颌没有阴影，脸显大 | [4.4 课](lesson:m4-04#map) |

:::danger 千万别
导出之前忘了关灰度观察层，交出去一张黑白照片。每次导出前看一眼图层面板，确认「灰度观察」的勾是关着的。
:::

## 第 4 步：对照设定图 {#ref}

:::step 在参考窗口里放设定图
1. 打开 [[操作 > 画布 > 参考]]，把开关打开。画面上会浮出一个小窗口。
2. 窗口下面有「画布」「图像」「面容」三个按钮，点「图像」，从相册里选这个角色的设定图或立绘。
3. 拖动窗口上方中间的灰色小条可以移动窗口，拖右下角或左下角可以改大小。在窗口里也可以两指缩放。
4. 逐项对比：假发颜色、瞳色、唇色和妆、服装主色、配饰。

![参考窗口放设定图](diagrams/m4/u-reference.svg "参考窗口选「图像」，放角色设定图")

看到：画面一角浮着设定图，可以一边看照片一边对照颜色。
:::

**对照时问自己**：

- 假发的颜色、发色深浅和设定一样吗？漫展灯光下粉色常偏橙、蓝色常偏紫。
- 瞳色对吗？美瞳在照片里常常变暗、变灰。
- 唇色、眼妆对吗？很多角色的唇色很有特点，照片里常被灯光冲淡。
- 服装主色对吗？红色、紫色最容易被相机拍偏。
- 有没有设定里有、照片里看不清的细节（发饰、泪痣、纹样），要不要补？

和 coser 确认过"不能改"的地方（[0.3 课](lesson:m0-03#brief)沟通表）也在这一步一起核对，写进清单里提醒自己。

## 第 5 步：写修图清单 {#list}

把前四步记下的问题合在一起，去掉重复的，按下面的顺序排：

| 顺序 | 类别 | 典型问题 | 去看 |
|---|---|---|---|
| 1 | 整体光和色 | 偏黄、偏暗、过曝、偏紫 | [4.2](lesson:m4-02) |
| 2 | 形 | 头身比、歪头、五官不对称、脸型 | [5.4](lesson:m5-04)、[4.5](lesson:m4-05#face) |
| 3 | 穿帮 | 路人、灯架、杂物 | [5.5](lesson:m5-05) |
| 4 | 皮肤 | 痘、痘印、泛红、油光 | [4.3](lesson:m4-03) |
| 5 | 光影 | 平光、阴阳脸 | [4.4](lesson:m4-04) |
| 6 | 妆面 | 眼线、唇色、腮红、眉毛 | [4.5](lesson:m4-05) |
| 7 | cos 细节 | 假发杂毛、美瞳、服装褶皱 | [5.1](lesson:m5-01)、[5.2](lesson:m5-02)、[5.3](lesson:m5-03) |
| 8 | 角色色和特效 | 假发、服装颜色和设定不一样，要加光效 | [5.6](lesson:m5-06)、[M6](page:m6/) |

**每一条怎么写**：在哪里 + 什么问题 + 怎么修。比如：

- 不好："皮肤不好。"
- 好："右脸颊 3 颗痘、鼻翼两侧泛红 → 克隆去痘，低透明度喷枪补色（4.3）。"

:::tip 在图上标出来
新建一层「标记」，用亮绿色的细笔把每个问题圈出来，旁边写上清单里的序号。修完一条，就在清单上划掉一条。标记层修完删掉，或者导出前关掉。
:::

## 修图时一直开着参考窗口 {#keep-ref}

诊断完，把参考窗口切回「画布」模式：窗口里实时显示整张图。你放大修一颗痘、一根眉毛时，余光能看到整张图的变化，避免"局部修得很细，整体却修歪了"。要对颜色时再切回「图像」看设定图。

点一下参考窗口可以隐藏它周围的按钮，画面更干净；再点一下恢复。

## 两个完整案例 {#cases}

### 案例一：漫展室内场照 {#case-venue}

![诊断标记](diagrams/m4/case-venue-mark.svg "在标记层上圈出问题、写上序号")

**照片情况**：室内展馆，顶上是暖色的灯，背景有展板和路人。coser 半身，正面拍。

**四步各发现了什么**：

| 步骤 | 发现 |
|---|---|
| 1. 缩小看全图 | 第一眼：整张很黄；脸有点平 |
| 2. 水平翻转 | 头往画面左边歪；假发两侧各有几根杂毛翘出来 |
| 3. 灰度观察 | 脸几乎是一片灰，没有明暗；右脸颊和鼻翼一片斑点 |
| 4. 对照设定图 | 设定是紫色眼睛、红唇，照片里美瞳偏蓝、唇色很淡 |

**修图清单**：

1. 整张偏黄：Lightroom 用白平衡选择器吸白色展板，色温往蓝推（4.2，[案例一](lesson:m4-02#case-venue)）。
2. 头往左歪约 5°：选区圈头和脖子，用变换轻转回来（5.4 的方法）。
3. 背景两个路人：克隆盖掉（5.5）。
4. 右脸颊 4 颗痘、鼻翼两侧泛红：克隆去痘，补色层压泛红（4.3）。
5. 脸平：柔光图层加深减淡，重点是额头、鼻梁、颧骨和下颌（4.4）。
6. 唇色太淡：颜色模式图层，按设定图的红色补（4.5）。
7. 假发两侧杂毛：克隆和涂抹清理（5.1）。
8. 美瞳偏蓝：按设定图改成紫色（5.2、5.6）。

**为什么是这个顺序**：偏黄最先改，因为后面判断肤色、唇色、瞳色都要在正确的白平衡下看；歪头和路人属于"形"和"穿帮"，要大面积改像素，放在皮肤之前；唇色和瞳色是对照设定图的颜色问题，放在光影之后，免得光影一改，颜色又要重调。

:::warn 这类照片容易翻车的地方
- 只看彩色，觉得脸"还行"，跳过了光影。灰度一开才发现脸是平的，修完整张图还是没有精神。
- 歪头没在翻转时发现，先修了皮肤和光影，最后才转头，转完下巴和脖子接缝处的修补又要重做。
- 美瞳、唇色凭记忆改，改完和设定不一样。颜色一定要开着参考窗口对。
:::

### 案例二：外景逆光 {#case-backlit}

:::compare
before: diagrams/m4/case-backlit-color.svg | 彩色原图
after: diagrams/m4/case-backlit-gray.svg | 灰度观察层
:::

**照片情况**：户外，太阳在人后面偏右。天空很亮，人整体偏暗。

**四步各发现了什么**：

| 步骤 | 发现 |
|---|---|
| 1. 缩小看全图 | 第一眼：人发暗，天空很亮 |
| 2. 水平翻转 | 左眼比右眼低一点；左眼眼线晕开了一块 |
| 3. 灰度观察 | 右半边脸比左半边暗一大截，交界线很硬（阴阳脸）；天空几乎是纯白 |
| 4. 对照设定图 | 颜色基本对，唇色可以再红一点 |

**修图清单**：

1. 人偏暗、天空过曝：Lightroom 压高光、提阴影；脸单独提亮（4.2，[案例二](lesson:m4-02#case-sky)）。
2. 左眼低：选区 + 变换轻微上移（4.5，[案例二](lesson:m4-05#case-asym)）。
3. 阴阳脸：暗的一侧用柔光图层提亮，交界处柔化（4.4，[案例三](lesson:m4-04#case-messy)）。
4. 左眼眼线晕开：克隆盖掉晕开的部分，重画眼线（4.5）。
5. 唇色补一点红（4.5）。

**为什么是这个顺序**：逆光的明暗问题要分两次处理。整体的亮暗在 Lightroom 里调，因为它能利用原图里还留着的暗部细节（RAW 更好）；左右脸的明暗差是局部问题，到 Procreate 里用加深减淡处理。

:::warn 这类照片容易翻车的地方
- 在 Lightroom 里把阴影拉到 +100 想一次救回脸，结果暗部发灰、出噪点。整体只提到"能看清"，剩下的交给 4.4。
- 把阴阳脸完全抹平。逆光本来就是一侧亮一侧暗，修到"暗的一侧不脏、交界不硬"就够了，完全一样亮反而不像逆光。
:::
