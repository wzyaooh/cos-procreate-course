使用说明

这个网站怎么用、作业用的照片去哪找、学习进度怎么备份。

学习方法

看 PS 教程时找不到对应功能，查 PS 和 Procreate 对照表。学完全部课程以后，做毕业作品。

  1. 按顺序学。M0 到 M2 是工具，M3 是理论，M4 以后是实战。M3 可以和 M4、M5 交替学。
  2. 每课都做作业。作业写了验收标准，达到了再往下学。
  3. 记一本错题本。每修一张图，记下哪里崩了、对应哪个知识点。一个月翻一次，哪类问题最多，就回去补哪节课。
  4. 留好过程文件。每次都保存 .procreate 分层文件和修图前后对比，方便回头看自己是怎么修的。

课程里的数字怎么用

课里的数字分三类，用法不一样：

类型例子怎么用
有出处的打印按 300 DPI 算、发到网上用 sRGB、软件的默认值、平台的上传规定可以照着用。出处写在旁边或本课的参考资料里；平台规定会变，以平台最新说明为准
算出来的头被放大多少倍、取色器的 HSB 换成 RGB、头身比课里写了算法，你可以用自己的照片照着算一遍
经验起点值模糊、液化、不透明度、羽化、笔刷尺寸的百分比只是起点：从写的数左右开始，看到课里写的效果就停。同一个百分比在不同尺寸的画布上效果不一样，不要照抄数字

案例里的具体读数（比如"取样 H24 S34 B88""色温 −15"）是那张示范照片的，你的照片数值会不同，按取色读数和画面判断。

找图清单

网站不提供练习图，作业用的照片需要你自己找。可以从这些地方找：

  • 自己的返图：最推荐，修完还能直接用。
  • 朋友或合作 coser 的照片：先问过本人；修好的图要发布，也要对方同意。
  • 免版权图库：Unsplash、Pexels、Wikimedia Commons。用之前看一眼授权条款，Commons 上的图大多要求署名。
  • 网上别人的作品：可以拿来练手，但不要发布你修改后的版本。

在 iPad 上添加到主屏幕

进度存在浏览器里。iPad 上的 Safari 有一条规则：如果连续 7 天用 Safari 却没打开过某个网站，可能会清掉这个网站存的数据（WebKit 官方说明）。添加到主屏幕后从图标打开，不受这条规则影响，而且没有地址栏，看课更宽。

  1. 用 Safari 打开本站首页。
  2. 点地址栏旁边的「分享」按钮（方框加向上箭头）。
  3. 往下找到「添加到主屏幕」，点「添加」。
  4. 以后从主屏幕上的粉色圆形图标打开。

注意：主屏幕上的网站和 Safari 里的网站，进度是分开存的。已经在 Safari 里学了一段的，先在下面导出进度，再从主屏幕图标打开、导入。

发现错误怎么办

课程按 Procreate 官方中文手册编写，但界面会随版本更新变化。发现某一步和你的 iPad 对不上、数字有问题、链接失效，欢迎到 GitHub Issues 反馈，写清楚是哪一课哪一步、你的 Procreate 版本。也可以直接修改课程文件提交 Pull Request，写法见仓库里的 CONTRIBUTING.md。
